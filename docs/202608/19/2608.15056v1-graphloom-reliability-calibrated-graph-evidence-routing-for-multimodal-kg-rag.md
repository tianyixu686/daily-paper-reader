## 摘要
多模态检索增强生成（RAG）系统通常依赖冗长的非结构化上下文或过度扩展的证据图，这可能会引入噪声证据、削弱多跳推理能力，并增加无依据生成的风险。我们提出了GraphLoom，一个可靠性校准的多模态知识图谱RAG框架，用于实现紧凑且忠实的证据路由。给定一个问题及其相关的多模态输入，GraphLoom从 grounded 场景描述、提取的关系三元组和外部常识知识构建实例级多模态知识图谱。GraphLoom并非将所有检索到的证据注入生成器，而是执行具有有界扩展的可靠性感知子图检索，并通过层级图记忆槽和冻结语言模型中的联合图-序列注意力，选择性地路由高效用证据。为了在复杂推理场景中提升鲁棒性，GraphLoom进一步将交错检索与预算受限的纠正性检索相结合，在噪声检索条件下实现自适应多跳证据精炼。我们在ScienceQA、MultiModalQA和OK-VQA上评估了GraphLoom，包括近似噪声外部知识检索的大规模干扰证据池。实验结果表明，与强多模态RAG、图检索和开源视觉-语言基线相比，GraphLoom在答案质量和证据忠实度上持续取得改进，并在MultiModalQA上提升了检索质量，在噪声证据池下保持稳定性能。基于MiniCheck验证、人工评估和延迟分析的额外分析表明，可靠性校准的图证据路由为长上下文多模态证据注入提供了一种有效替代方案。

## Abstract
Multimodal retrieval-augmented generation (RAG) systems often rely on long unstructured contexts or aggressively expanded evidence graphs, which can introduce noisy evidence, weaken multi-hop reasoning, and increase unsupported generation. We present GraphLoom, a reliability-calibrated multimodal knowledge-graph RAG framework for compact and faithful evidence routing. Given a question and its associated multimodal input, GraphLoom constructs an instance-level multimodal knowledge graph from grounded scene descriptions, extracted relational triples, and external commonsense knowledge. Instead of injecting all retrieved evidence into the generator, GraphLoom performs reliability-aware subgraph retrieval with bounded expansion and selectively routes high-utility evidence through hierarchical graph memory slots and joint graph-sequence attention in a frozen language model. To improve robustness in complex reasoning settings, GraphLoom further combines interleaved retrieval with budgeted corrective retrieval, enabling adaptive multi-hop evidence refinement under noisy retrieval conditions. We evaluate GraphLoom on ScienceQA, MultiModalQA, and OK-VQA, including large distractor evidence pools that approximate noisy external knowledge retrieval. Experimental results show consistent gains in answer quality and evidence faithfulness over strong multimodal RAG, graph-retrieval, and open-source vision-language baselines, with improved retrieval quality on MultiModalQA and stable performance under noisy evidence pools. Additional analyses using MiniCheck-based verification, human evaluation, and latency profiling show that reliability-calibrated graph evidence routing provides an effective alternative to long-context multimodal evidence injection.

## 2. 论文提出的方法论

### 2.1 核心设计思想

GraphLoom的核心理念是**将证据构建与在线证据使用分离**：离线（可缓存）构建实例级多模态知识图谱，在线进行受控的检索—路由—注入—生成。与传统的"检索即读（retrieve-and-read）"思路不同，GraphLoom在解码过程中的**每一步**对证据槽进行选择和路由。

### 2.2 关键流程（完整流水线）

1. **增强多模态KG构建（§3.1）**
   - 图像由Qwen3-VL-Instruct生成精简的场景描述；
   - REBEL模型从描述中提取结构化三元组 (s, r, o)，并附有归一化置信度 `conf_ext(t)`；
   - 置信度过滤：`conf_ext(t) ≥ τ_edge`（默认τ_edge = 0.5）；
   - 外部KG增强：两跳邻域内从VG150（视觉关系）和ConceptNet（常识知识）引入相关关系，要求评分≥τ_KB = 0.7。

2. **有界子图检索（§3.2）**
   - 候选池：`C(Q,I) = E+_MMKG ∪ E_ext`（标准设置下E_ext = ∅，噪声设置下加入干扰三元组）；
   - 采用Qwen3-VL-Embedding计算多模态相似度：`score(t,Q,I) = cos(f_embed(I,Q), f_embed(text(t)))`；
   - 检索预算：有限跳数、有界扩展度；最终满足`|E_sub(Q)| ≤ N_max`。

3. **交错多跳检索（§3.3）**
   - 从初始子图中选择桥接节点（度≥2，按介数中心性排名）；
   - 生成至多15个token的中间查询；
   - 只执行一轮附加检索，合并边集后按原问题条件得分保留Top-N_max。

4. **证据记忆组织（§3.4）**
   - **全局多模态前缀**：融合文本嵌入与视觉嵌入，池化为固定长度L_p = 32的前缀K/V对；
   - **HieraSlot结构化槽记忆**：每个三元组生成两个互补槽——实体槽（key=实体，value=关系⊕对象）和关系槽（key=关系，value=主体⊕对象）；2M个三元组生成2M个槽。

5. **可靠性校准路由（§3.5）**
   - 对每个槽计算效用分数`u_j`和可靠性分数`ĉ_j`；
   - 最终路由分数：`ρ_j = u_j + β·logit(ĉ_j)`；
   - 每步只选择Top-k槽（k = 4）注入注意力机制。

6. **KG-JSA++联合图-序列注意力（§3.6）**
   - 将融合前缀与活跃槽拼接到前缀记忆；
   - 稀疏化自注意力KV缓存（保留最近token + sink tokens + 高相似度token）；
   - 槽位置获得可靠性感知注意力偏置：`B_pref[j] = γ·logit(ĉ_j)`；
   - 对拼接的前缀和稀疏自上下文做统一softmax；
   - 每步注意力复杂度从O(t)降至`O(L_p + |A_t| + |I_t|)`。

7. **纠正性检索与修订（§3.7）**
   - 轻量充分性评估器：`E_eval = σ(MLP(g_graph ⊕ g_query ⊕ g_history))`；
   - 若`E_eval < τ_eval`，执行至多一次有预算纠正行动（扩展提升/查询改写/语言化修复）；
   - 生成后验证-修订：将草稿答案分解为原子主张，用DeBERTa-v3 NLI验证，不支持的片段触发针对性重新检索和受约束修订提示。

8. **答案预测（§3.8）**
   - 多选题：长度归一化对数似然；
   - 开放式：自回归解码；
   - 证据不足时发出`[NO_EVIDENCE]`信号，此类输出计入错误而非隐瞒。

### 2.3 训练目标

`L = λ_gen·L_gen + λ_cal·L_cal + λ_cf·L_cf + λ_align·L_align`
- L_gen：标签平滑负对数似然（答案生成）；
- L_cal：路由器置信度的二分类交叉熵（可靠性校准）；
- L_cf：正负槽对的边际损失（对比槽效用）；
- L_align：路由器分布与解码器注意力分布的KL散度（路由器-注意力对齐）。
- 可训练模块仅约160万参数（融合投影0.8M + HieraSlot投影0.3M + 可靠性路由器0.5M），所有骨干模型冻结。

## 6. 论文的主要结论与发现

1. **总体性能**：GraphLoom在ScienceQA上达92.5%准确率、MMQA上达55.2 EM / 66.5 F1、OK-VQA上达70.5%准确率，为**受控开源方法中的最优结果**；
2. **在知识密集任务上增益更大**：ScienceQA（已有强VLM表现）提升有限，但MMQA和OK-VQA（需要外部知识、多模态证据对齐或多跳推理）提升显著；
3. **组件贡献排序**：KG-JSA++ > 可靠性校准路由器 > 交错/纠正性检索 > 修订；移除路由器使H-Rate从10.5升至17.3，移除KG-JSA++造成最大质量下降；
4. **外部知识的重要补充**：同时移除VG150和ConceptNet使MMQA EM下降2.4点、H-Rate上升4.8点；
5. **噪声鲁棒性**：候选池扩至100万干扰三元组时，MMQA F1仅下降1.4点，生成成本不随池规模增长；
6. **阈值稳定性**：±20%阈值扰动下EM和F1变化不超过0.8点；
7. **忠实性显著改善**：独立H-Rate为10.5%（最低），人工评估无幻觉比例为68.5%（最高）；
8. **效率可观**：在线延迟119ms/查询，解码时注意力FLOPs在t=512时相对全因果注意力减少约76%；
9. **路由器校准有效**：校准后ECE从0.087降至0.032。

## 7. 优点

- **方法设计创新**：将多模态KG-RAG重构为受控证据管理问题，将"检索什么"和"解码中如何用"统一在一个可靠性校准框架下；
- **证据使用精细控制**：HieraSlot双通道（实体槽/关系槽）+ 每步Top-k路由，避免长上下文注入的噪声问题；
- **效率设计合理**：有界检索预算、稀疏自注意力、固定活跃槽数——解码器注意力成本不随生成长度线性增长；
- **评估严谨性高**：区分完整流水线延迟与缓存在线延迟；采用独立验证器避免循环评估；包含人工评估、阈值鲁棒性分析和噪声池测试等多维评估；
- **训练经济性**：仅训练约160万参数（融合投影+槽投影+路由器），所有骨干冻结，训练开销低；
- **可扩展性明确**：从实例图到百万级干扰池保持稳定，在线生成的解码代价不随池规模增长；
- **对证据不足做了安全设计**：提供`[NO_EVIDENCE]`回退机制，且不将弃权视为提升，保障了评估的诚实性。
