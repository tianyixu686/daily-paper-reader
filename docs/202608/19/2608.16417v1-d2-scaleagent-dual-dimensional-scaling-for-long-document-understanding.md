## 摘要
多模态检索增强生成（RAG）是视觉丰富的长文档理解的关键技术。现有的多模态RAG方法逐渐向多智能体系统发展：它们首先根据查询检索相关页面，然后迭代地理解这些页面中的信息。然而，这些方法通常依赖固定工作流，缺乏在测试时动态扩展计算的能力，往往导致证据不足。为了解决这个问题，我们提出了D2-ScaleAgent，一个智能体框架，引入了用于检索和推理的双维度缩放范式。D2-ScaleAgent的核心是一个基于查询内在难度的Verifier智能体驱动的动态路由循环，以不断更新的证据库为中心，作为智能体的动态工作记忆：当需要扩展检索时，智能体向外路由（检索缩放），将查询分解为属性并执行并行页面检索，然后进行自适应剪枝以确保全面的证据覆盖。当需要细粒度推理时，智能体向内路由（推理缩放），动态选择不同粒度和数量的子智能体从页面中提取证据。最后，D2-ScaleAgent在证据链上实现逻辑闭合。大量实验表明，D2-ScaleAgent在MMLongBench-Doc、LongDocURL等长且视觉丰富的文档基准上表现有效。

## Abstract
Multi-modal retrieval-augmented generation (RAG) is a key technique for visually rich long document understanding. Existing multi-modal RAG methods are progressively advancing toward multi-agent systems: they first retrieve relevant pages based on a query, and then iteratively understand information within those pages. However, these methods typically rely on fixed workflows and lack the ability to dynamically scale computation at test time, often leading to insufficient evidence. To address this, we propose D2-ScaleAgent, an agentic framework that introduces a dual-dimensional scaling paradigm for retrieval and reasoning. The core of D2-ScaleAgent is a Verifier agent-driven dynamic routing loop based on the intrinsic difficulty of the query, centered around a continuously updated evidence bank that serves as the agent's dynamic working memory: when retrieval needs to be expanded, the agent routes outward (retrieval scaling), decomposing the query into attributes and performing parallel page retrieval, followed by adaptive pruning to ensure comprehensive evidence coverage. When fine-grained reasoning is required, the agent routes inward (reasoning scaling), dynamically selecting sub-agents with varying granularity and count to extract evidence from pages. Finally, D2-ScaleAgent achieves logical closure over the evidence chain. Extensive experiments demonstrate that D2-ScaleAgent is effective on long and visually rich document benchmarks like MMLongBench-Doc, LongDocURL, etc.

- 论文指出，长文档理解失败的根本原因不是模型推理模板有缺陷，而是**"证据不足问题"（Evidence Insufficiency Problem）**。作者将其细分为两个维度：
  - **广度不足（Breadth Insufficiency）**：检索覆盖面不全，需要向外扩展到更广泛的文档上下文；
  - **深度不足（Depth Insufficiency）**：局部理解停留在粗浅层面，需要向内进行更细粒度的深挖。

**整体含义：**
论文主张长文档理解不应沿固定路径执行，而应基于检测到的证据缺口，在两个维度上动态缩放计算，从而使系统能够自适应地补齐证据链。

### 2. 论文提出的方法论

**核心思想：** D2-ScaleAgent 摒弃了静态"检索-再阅读"流程，构建了一个以 **Verifier 智能体驱动的闭环系统**，围绕持续更新的**证据库（Evidence Bank）**进行动态路由。

**核心公式与状态表示（用文字说明）：**

- **全局证据库（Evidence Bank）**：系统维护一个统一认知状态 Bt，包含五个变量——页面级证据、区域级证据、原子级证据、当前证据完整性分数 s_comp^t、当前证据缺口 g^t。这张证据库充当智能体的动态工作记忆。

- **属性引导的检索缩放（向外路由）** —— 解决广度不足，分三阶段：
  1. **查询属性分解**：利用LLM将原始查询分解为多视角的属性查询集合 Q = {(q0,w0), (q1,w1), …}，其中 wm 为置信权重，全部权重归一化之和为1。
  2. **多轮候选累积**：对每个属性查询并行检索，不断扩充全局候选页池 C(j)，并通过"基于排名的加权融合分数"对跨视角结果进行综合排序——优先级给予在多视角下持续获得支持的高价值证据。
  3. **自适应剪枝与收敛**：用相对阈值 α 提取高价值证据集，量化跨轮稳定性 Stab_j，当稳定性持续超过阈值 τ 时自动终止扩展，输出全局检索集。

- **缺口感知的推理缩放（向内路由）** —— 解决深度不足，包含三级成本分层子代理：
  - **Global Surveyor（全局勘察者）**：低成本宏观扫描，建立方向性语义先验，输出页面级证据；
  - **Region Locator（区域定位器）**：中等成本，隔离关键区域并生成结构化摘要，输出高度相关页面子集和区域级证据；
  - **Fine-grained Extractor（细粒度提取器）**：高成本，基于动态生成的提取规范对关键区域进行高分辨率精确读取，提取可验证的原子事实。

- **Verifier 智能体驱动的路由循环**：
  - Verifier 在每个推理步骤评估证据库的认知完整性，输出完整性分数和具体缺口；
  - 若缺口属于深度不足 → 路由向内，从推理工具包中分配具体认知操作（Surveyor/Locator/Extractor）；
  - 若缺口属于广度不足 → 将缺口转化为新检索意图，路由向外，触发检索缩放；
  - 循环严格在满足终止条件时停止：完整性分数 ≥ δ 且证据缺口为空（逻辑闭合）。

**系统流程（文字描述）：** 初始检索 → 初始化证据库 → Verifier 评估 → 向内/向外路由 → 多粒度证据持续累积 → 证据库更新 → 迭代直至逻辑闭合 → 基于饱和证据生成最终答案。

- 检索性能方面：D2-ScaleAgent 在 Recall、Precision、nDCG、MRR 上全面超越强基线，验证了"属性分解+迭代扩展"检索策略的有效性。
- 计算资源随查询难度动态分配：MMLongBench-Doc 因结构复杂和证据分散，需要更多验证与路由调用（21.4K tokens、16.22s）；ViDoSeek 因证据相对集中，开销更低（15.9K tokens、11.89s）。

### 7. 优点

- **问题定义深刻**：将长文档理解失败归因于"证据不足"，并分解为广度和深度两个维度，为方法论设计提供了清晰且可操作的理论框架。
- **动态计算分配范式**：区别于现有固定工作流方法，"双维度缩放"实现了真正的测试时自适应计算路由，检索边界和推理深度均由证据缺口驱动而非预设常数。
- **证据库作为统一记忆中枢**：多粒度证据（页面级/区域级/原子级）在全局证据库中持续累积与更新，为Verifier提供了完整的认知状态评估基础，形成检索与推理间的深度协同。
- **检索侧创新**：属性分解+多视角并行检索+基于排名权重的融合剪枝，克服了传统Top-K检索在复杂视觉文档上的刚性限制，通过跨轮稳定性自适应决定收敛时点。
- **推理侧成本分层设计**：Surveyor→Locator→Extractor三级认知工具包，按需调用不同成本的子代理，避免不必要的高成本计算。
- **实验设计全面**：跨4个基础模型、6个数据集、2个评估维度（生成+检索）的验证，加上oracle上限标定和计算成本剖析，使结论具有较高可信度；case study直观展示了两类不足的差异化解决路径。

### 8. 不足与局限

- **计算效率与延迟**：论文自认最大局限——动态路由需要多轮属性检索和按需调用子代理，执行时间显著长于单次推理模型（MMLongBench-Doc端到端16.22s/查询），对实时应用或延迟敏感场景不友好。
- **基线对比不够全面**：缺少与 M3DocRAG、MHier-RAG、DocAgent 等更多最新方法的直接对比；方法间的计算成本差异也未做统一控制，实验公平性可能受到质疑。
- **消融覆盖不完整**：详细消融仅报告了MMLongBench-Doc（以及附录中的PaperTab、UniDoc-Bench），未在全部6个数据集上逐一验证组件贡献。
- **VQA反超现象**：在 Gemini-3-flash-preview 上，纯VQA在MMLongBench-Doc和LongDocURL上甚至优于D2-ScaleAgent，表明框架对底层模型的鲁棒性有限（较弱的 Qwen 模型上表现最好，最强模型上相对优势缩小甚至反转），其价值主要体现在增强中等能力模型的证据获取上。
- **oracle上限仍有差距**：全模型52.0 vs. 证据上限54.9，说明检索与推理机制仍有进一步优化的空间。
- **依赖LLM路由的可靠性**：Verifier的判断质量是整个闭环的关键瓶颈，若Verifier对证据完整性评估出现系统性偏差，可能导致过早停止（证据不足）或持续空转（计算浪费）。
- **框架复杂度较高**：涉及多个子代理、多个阈值超参数（α=0.7、τ=0.8、δ=8等），实际应用时的调优成本与配置难度较大，泛化部署门槛较高。
