## 摘要
视觉文档检索是多模态检索增强生成的关键组成部分，旨在从文档集合中识别与查询相关的页面，其中证据分布于文本、布局、图表和视觉结构中。近期朝着更细粒度监督的努力主要依赖于文本描述或局部视觉区域作为证据代理。然而，此类监督信号可能忽视复杂的视觉结构，或提供不完整、不准确的底层证据表示。为解决这些局限，我们提出ConceptFormer，一种用于视觉文档检索的潜在概念表示学习框架。ConceptFormer将查询相关证据建模为连续的、由查询条件化的潜在概念，显式桥接局部视觉证据与语义相关性，无需文本中间表示或直接依赖原始视觉标注。在训练过程中，ConceptFormer利用强大的视觉-语言模型动态确定潜在概念标记的数量，并使用这些概念作为中间表示来弥合查询与文档之间的语义鸿沟，从而指导嵌入空间的学习。在多个视觉文档检索基准上的实验表明，ConceptFormer在平均NDCG@10上分别比最强的视觉检索基线和基于OCR的文本检索基线实现了16.7%和22.1%的相对提升。进一步分析揭示，潜在概念有效地将局部视觉证据与语义相关性连接起来，使检索器能够捕捉细粒度文本线索和复杂的文档级视觉结构，同时保持强大的检索对齐。代码和数据可在https://github.com/Neuir/ConceptFormer获取。

## Abstract
Visual document retrieval is a critical component of multimodal retrieval-augmented generation, aiming to identify query-relevant pages from document collections where evidence is distributed across text, layout, charts, and visual structures. Recent efforts toward finer-grained supervision primarily rely on textual descriptions or localized visual regions as evidence proxies. However, such supervision signals may either overlook complex visual structures or provide incomplete and inaccurate representations of the underlying evidence. To address these limitations, we propose ConceptFormer, a latent concept representation learning framework for visual document retrieval. ConceptFormer models query-relevant evidence as continuous, query-conditioned latent concepts that explicitly bridge localized visual evidence and semantic relevance, without requiring either textual intermediate representations or direct reliance on raw visual annotations. During training, ConceptFormer employs a strong vision-language model to dynamically determine the number of latent concept tokens and uses these concepts as an intermediate representation to bridge the semantic gap between queries and documents, thereby guiding the learning of the embedding space. Experiments on diverse visual document retrieval benchmarks demonstrate that ConceptFormer achieves 16.7\% and 22.1\% relative improvements in average NDCG@10 over the strongest visual retrieval baseline and the strongest OCR-based text retrieval baseline, respectively. Further analysis reveals that latent concepts effectively connect localized visual evidence with semantic relevance, enabling the retriever to capture both fine-grained textual cues and complex document-level visual structures while preserving strong retrieval alignment. Codes and data are available at https://github.com/Neuir/ConceptFormer.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：在训练阶段引入一个“潜在概念空间”，该空间由查询-文档对共同决定，将查询相关的局部证据编码为一系列潜在概念 token，并使其诱导的排序分布与原始查询诱导的排序分布对齐，从而引导检索器学习更贴近查询相关证据的文档表示。推理阶段仍保持标准检索流程，不额外生成潜在概念。

- **关键技术细节与流程**：

  1. **标准检索与对比学习基础（Preliminaries）**：
     - 查询和文档分别经编码器得到向量：\(\mathbf{q}_i = f_q(q_i)\)，\(\mathbf{d}_j = f_d(d_j)\)。
     - 相关性用余弦相似度衡量：\(s(q_i, d_j) = \text{sim}(\mathbf{q}_i, \mathbf{d}_j)\)。
     - 标准训练目标为 InfoNCE 式对比损失：
       \[
       \mathcal{L}_{\text{cons}} = -\frac{1}{B}\sum_{i=1}^{B}\log P(d_i^+ | q_i, \tilde{D}_i)
       \]
       其中 \(P(d|q,\tilde{D})\) 是基于相似度的排序分布，\(\tilde{D}\) 为候选集。

  2. **证据提取与概念容量分配（Matryoshka Representations / 自适应容量）**：
     - 使用强视觉-语言模型（如 Qwen3.6-Plus）作为**训练时证据提议器（Evidence Proposer）**，对每个正例查询-文档对生成证据描述 \(R_i\)，并解析成结构化边界框 \(\{(x_1, y_1, x_2, y_2)\}\)。
     - 将边界框投影到检索器（如 Qwen2.5-VL）的视觉 patch 网格上，计算被覆盖的 patch 数量，作为每个证据区域的局部概念规模 \(t_{i,n}=|\mathcal{I}_{i,n}|\)。
     - 自适应潜在概念长度定义为 \(T_i = \sum_n t_{i,n}\)，即为每个查询-文档对动态分配概念 token 数量。
     - 分配潜在概念 token 序列 \(\ell_i = [\ell_{i,1}, ..., \ell_{i,T_i}]\)，每个 token 使用特殊标记 `<|lcon|>`。

  3. **潜在概念的生成与对齐**：
     - 将潜在概念 token 注入检索器上下文，得到每个概念 token 的隐藏状态：
       \[
       \mathbf{c}_{i,k} = \pi_\theta(q_i, d_i^+, \langle\text{lcon\_start}\rangle, \ell_{i,1:k})
       \]
     - 对所有概念状态进行平均池化，得到潜在概念表示：
       \[
       \hat{\mathbf{c}}_i = \text{MeanPool}(\mathbf{c}_{i,1}, ..., \mathbf{c}_{i,T_i})
       \]
     - 由查询表示诱导的排序分布 \(P(d|q_i, \tilde{D}_i)\) 作为教师，用 KL 散度让其与由潜在概念表示诱导的排序分布 \(P(d|\hat{\mathbf{c}}_i, \tilde{D}_i)\) 对齐：
       \[
       \mathcal{L}_{\text{align}} = \frac{1}{B}\sum_i \sum_{d \in \tilde{D}_i} P(d|q_i,\tilde{D}_i) \log \frac{P(d|q_i,\tilde{D}_i)}{P(d|\hat{\mathbf{c}}_i,\tilde{D}_i)}
       \]
     - 总损失：
       \[
       \mathcal{L} = \mathcal{L}_{\text{cons}} + \lambda \mathcal{L}_{\text{align}}
       \]
       其中 \(\lambda=0.2\) 为对齐损失权重。

  4. **推理阶段**：仅使用标准查询编码与文档编码，不生成潜在概念，不增加额外推断开销。

## 6. 论文的主要结论与发现

- **性能提升显著**：ConceptFormer（Qwen 骨干）在平均 NDCG@10 上比最强视觉检索基线（VDocRetriever）相对提升 16.7%，比最强 OCR 文本检索基线（NV-Embed-v2）相对提升 22.1%。
- **潜在概念优于现有监督代理**：相比文本概念代理和视觉概念代理，潜在概念在查询判别性、页面判别性和检索对齐三个维度上均更强，能够更有效地桥接局部证据与语义相关性。
- **自适应容量优于固定容量**：查询相关证据的规模差异很大（中位数 50，90 分位 224），固定长度的概念 token 无法取得最优效果，动态分配概念容量避免了冗余并保持了充分表示能力。
- **潜在概念帮助整合多类型证据**：案例分析显示，ConceptFormer 能同时激活全局上下文区域（如事件标题）和细粒度局部数值区域（如图表中的得分），而文本或视觉单独对齐只能激活其中一种。
- **框架具有较好兼容性**：在较弱的 Phi3V 骨干上也能超过现有最强视觉检索器，表明改进主要来自方法本身而非单纯扩大模型规模。

## 7. 优点

- **新颖的监督信号设计**：将查询相关证据建模为连续潜在概念，而非固定粒度的文本描述或局部区域，避免了两类代理信号的局限。
- **自适应概念容量**：利用证据区域覆盖的视觉 token 数动态决定概念长度，能灵活应对不同类型的证据规模（从局部数字到整张图表/地图）。
- **训练-推理解耦**：训练时使用强 VLM 引导潜概念学习，推理时保持标准检索流程，不增加在线计算开销。
- **与不同 VLM 骨架兼容**：在 Phi3V 和 Qwen2.5-VL 上均有效，具有通用性。
- **实验设计全面**：通过消融、几何分析、长度分布分析和案例研究，从多角度验证了方法的关键设计合理性。
- **可复现性**：公开代码和数据（GitHub 链接），并提供了详细的训练细节、数据集来源和基线 checkpoint。

## 8. 不足与局限

- **训练依赖强外部 VLM**：训练阶段需要 Qwen3.6-Plus 生成证据区域，这些区域的质量直接影响概念容量分配和监督信号质量，存在对专有模型或大模型服务的依赖。
- **证据提议可能引入噪声**：证据提取指令虽设计了详细规则，但自动生成的边界框可能存在错误、遗漏或过大的区域，导致潜在概念容量分配不准确。
- **计算成本较高**：训练使用 4×A100 GPU，且需要额外调用大模型进行证据提议，对资源要求高于普通对比学习。
- **应用领域有限**：实验集中在文档图像（PDF 截图、网页、图表）上，对自然图像、视频等更多模态的通用性尚未验证。
- **评估集规模不均衡**：部分测试集（如 ChartQA 150 个查询、OWID Charts 131 个查询）较小，可能削弱统计稳健性；虽然做了置换检验，但小样本上的结论仍需更大规模验证。
- **潜在概念的可解释性有限**：尽管通过可视化分析了激活区域，但潜在概念本身是连续向量，用户难以精确解读每个概念语义，相比文本代理可解释性较弱。
