## 摘要
多模态大语言模型（MLLMs）由于大规模多模态预训练而展现出强大的泛化和推理能力。然而，在下游任务上微调这些模型常常导致灾难性遗忘，即新学习的任务特定知识会削弱先前获得的能力。这一问题的出现是因为针对新任务的梯度更新会覆盖对先前知识至关重要的参数，从而限制了MLLMs的实际部署。为了解决这一挑战，我们提出了激活加权自适应保留（AWARe），一种通过基于激活模式动态控制参数更新来缓解灾难性遗忘的微调方法。AWARe为参数分配基于激活的重要性分数，选择性地冻结那些对保留先前能力至关重要的参数，同时允许较不重要的参数适应新任务。重要的是，AWARe无需修改模型架构即可运行，确保与现有推理引擎的兼容性。大量实验表明，与现有方法相比，AWARe在实现更优下游性能的同时有效保留了上游能力。代码可在https://github.com/kaln27/AWARe获取。

## Abstract
Multimodal Large Language Models (MLLMs) exhibit strong generalization and reasoning abilities due to large-scale multimodal pre-training. However, fine-tuning these models on downstream tasks often leads to catastrophic forgetting, where newly learned task-specific knowledge degrades previously acquired capabilities. This issue arises because gradient updates for new tasks overwrite parameters critical to prior knowledge, limiting the practical deployment of MLLMs. To address this challenge, we propose Activation-Weighted Adaptive REtention (AWARe), a fine-tuning method that mitigates catastrophic forgetting by dynamically controlling parameter updates based on activation patterns. AWARe assigns activation-based importance scores to parameters, selectively freezing those essential for preserving prior capabilities while allowing less important parameters to adapt to new tasks. Importantly, AWARe operates without modifying model architectures, ensuring compatibility with existing inference engines. Extensive experiments demonstrate that AWARe effectively preserves upstream capabilities while achieving superior downstream performance compared to existing methods. Code is available at https://github.com/kaln27/AWARe.

## 1. 核心问题与研究动机

多模态大语言模型（MLLMs）在预训练阶段获得了强大的跨模态理解与推理能力，但在下游任务上进行微调时，常遭遇**灾难性遗忘（Catastrophic Forgetting, CF）** 问题：新任务特定知识的梯度更新会覆盖对先前能力至关重要的参数，导致模型在上游任务上的表现显著退化。这一问题严重制约了MLLMs的实际部署。

现有缓解策略存在明显局限：
- **经验回放/重放类方法**面临高计算开销，难以扩展至数十亿参数的MLLMs；
- **正则化方法**依赖二阶统计量，计算代价高昂；
- **PEFT方法（如LoRA、DoRA）**虽减少可训练参数数量，但并不能天然阻止预训练知识被侵蚀；
- **选择性微调方法（如SPIDER、Model Tailor）**多依赖静态权重范数或梯度幅值，忽略前向传播中神经元激活的动态特性。

论文的核心思想来源于激活感知的权重重要性估计——受**AWQ（激活感知权重量化）** 和**Wanda（基于激活统计的剪枝）** 的启发：激活模式能提供数据驱动的、动态的、表征功能重要性优于纯权重幅值的度量视角。

## 2. 方法论：AWARe框架

### 2.1 核心思想

AWARe的目标是将MLLM参数划分为两部分：
- **固定参数集（θ_fixed）**：捕获并保留核心既有特征，在微调中冻结；
- **可塑参数集（θ_active）**：用于学习新任务知识，保持可训练性。

整个框架不修改模型架构，训练结束时可完全移除包装层，**不影响现有推理引擎的兼容性**。

### 2.2 两阶段流程

**阶段一：基于激活的显著性估计（Knowledge Profiling）**
1. 从上游任务采样校准集 S_cal（如各任务200个样本）；
2. 对目标线性层（权重 W ∈ R^{d_out × d_in}）进行一次前向传播，获得激活张量 A ∈ R^{B×L×d_out}；
3. 按公式计算每个输出神经元的显著性得分：
   - 第一步：沿序列维度计算 L2 范数：a'_{i,k} = sqrt(Σ_j a²_{i,j,k})；
   - 第二步：沿隐藏维度进行**逐样本L2归一化**，消除不同样本间激活尺度差异造成的偏差：a''_{i,k} = a'_{i,k} / ‖a'_i‖₂；
   - 第三步：对批量维度取平均：s_k = (1/B) Σ_i a''_{i,k}。
4. 对全部目标层的神经元显著性得分进行**全局排序**，标记top-ρ比例的神经元索引集合 I（ρ为保留比例，默认30%）。

**阶段二：约束微调（Constrained Fine-tuning）**
1. 根据索引集合构造**逐行二进制梯度掩码**：M_grad(k,:) = 0 若 k ∈ I；否则为1；
2. 在前向传播和反向传播中，使用掩码后的梯度更新权重：W(t+1) = W(t) - η·(∇W_L_down ⊙ M_grad)；
3. 训练时使用AwareLinear包装器将线性层分解为“冻结”与“活跃”两部分，训练后移除，保持原模型结构不变。

### 2.3 目标层选择

AWARe仅应用于以下线性投影层：
- 自注意力机制中的 **q_proj、k_proj、v_proj**；
- 多模态投影器中的 **mm_projector**。

原因：更新自注意力投影层相比MLP层引起的预训练知识遗忘显著更少；MLP层保有大部分基础通用知识，全部保持冻结。

## 3. 实验设计

### 3.1 基础模型与数据集

**基础模型**：LLaVA-v1.5-7B（主要）、Qwen2.5-VL-7B（扩展验证）。

**单任务下游适配设置**：
- 上游任务（需保留能力）：OKVQA、OCRVQA、GQA、TextVQA；
- 下游新任务：**IconQA**（图表VQA）和 **COCO-Caption**（图像描述，CIDEr指标）。

**持续指令微调设置（MLLM-DCL benchmark）**：五任务序列——遥感（RS）、医学VQA（Med）、自动驾驶（AD）、科学推理（Sci）、金融理解（Fin）。

**Qwen2.5-VL扩展实验**：上游评估任务为 HallusionBench、Micro-VQA、DocVQA、VStarBench、AI2D；下游任务为DCL-Med和DCL-AD。

### 3.2 对比方法

**单任务适配**：Full-FT、LoRA、DoRA、DARE、Orth-Reg、Model Tailor、LoRASculpt、SPIDER。

**持续指令微调**：ModalPrompt、HiDe-LLaVA、LoRA-FT、MoELoRA、CL-MoE、O-LoRA、SEFE、DISCO。

### 3.3 评价指标

- **R（知识保留率）**：微调后上游精度与零样本精度之比的平均；
- **E（学习效率）**：下游任务精度与全量微调精度之比；
- **H（调和平均）**：H = 2·R·E/(R+E)，综合衡量稳定-可塑平衡。
- **MLLM-DCL**：使用MFT（平均微调精度）、MFN（平均最终精度）、MAA（平均平均精度）、BWT（后向迁移）四项标准指标。

## 6. 主要结论与发现

1. **AWARe在稳定-可塑权衡上全面优于现有方法**：在IconQA任务上H=103.2，COCO-Caption上H=108.0，均超过所有对比基线；在MLLM-DCL上Avg和Last也均最优。
2. **激活显著性优于权重范数与随机选择**：激活归一化度量能识别结构性关键神经元，效果显著优于静态权重幅值准则。
3. **冻结30%自注意力高激活神经元通常足够保留上游知识**，同时保持下游竞争力；比例超过50%会明显损伤可塑性，小比例（1%）则保护不足。
4. **MM投影器是适配新任务的关键**：冻结它导致目标任务性能下降约10分。
5. **MLP块包含核心通用知识，不宜更新**：甚至加上激活保护也会引发严重遗忘（上游低于30分），支持了**目标层选择是正确的**。
6. **AWARe对校准数据具有鲁棒性**：使用MMMU通用数据集作为代理校准集效果依然很好；200个样本、不同随机种子结果波动极小。
7. **跨模型架构有效**：从LLaVA-v1.5扩展到Qwen2.5-VL，AWARe仍保持最佳上游保持与竞争性下游表现。

## 8. 不足与局限

- **依赖校准数据**：如何选择校准集可能影响冻结区域的质量。虽然MMMU作为替代有效，但论文承认校准数据质量与覆盖度仍可影响效果；自定义/罕见域中的上游数据不可达时效果可能打折扣。
- **应用面覆盖有限**：论文验证集中于LLaVA-v1.5和Qwen2.5-VL，以及有限的几类下游任务；对更大规模模型（如70B）、更多样化领域（音频/视频输入）和更长任务序列的泛化性有待进一步验证。
- **保留比例ρ为超参数**：应对极大分布偏移时需要手动调节ρ以平衡稳定与可塑；缺少自适应调节ρ的方法论。
- **只微调了少量目标层**：MM投影器、自注意力之外的层（如跨注意力、冻结嵌入层）的选择依据主要来自先前研究，缺少第一手系统性评估——尽管图5提供了部分解释。
- **算力资源未披露**：未明确报告GPU型号、数量、单次实验训练时间及能量消耗；虽然参数效率高，但这种缺失限制了从性价比角度对方法进行全面评价。
- **遗忘的评估方式仍有提升空间**：所有上游任务指标均为整体平均精度，未按任务难度/数据类型细分——在真实世界中，不同能力的相对重要性并不相等。
