## 摘要
我们研究持续预训练（CPT）作为将通用大语言模型适应于数学、指令、代码和自然文本等专业领域的机制。利用权重矩阵的奇异值分解，我们发现CPT使奇异值谱基本保持不变，适应性主要源于奇异向量的改变。对注意力头投影矩阵的分析揭示了强烈的、依赖领域的头异质性，我们利用这一点定义了头重要性准则：在不造成可测量质量损失的情况下，最多可移除60%的头更新。有选择地将低重要性的头回退到预训练状态，相比完全训练的基线，基准准确率可提高高达4%。最后，我们识别了领域连通性——CPT检查点之间的线性插值可产生平滑的领域质量插值，而不会在任一领域上出现显著退化——并发布了Diffract，一个用于对数十亿参数模型进行可扩展谱分析的开源工具包。

## Abstract
We study continual pre-training (CPT) as a mechanism for adapting general-purpose large language models to specialized domains: mathematics, instruction, code, and natural text. Using singular value decomposition of weight matrices, we find that CPT leaves singular value spectra largely invariant, with adaptation driven mainly by changes in singular vectors. An analysis of attention-head projection matrices reveals strong, domain-dependent head heterogeneity, which we exploit to define a head importance criterion: up to 60% of head updates can be removed without measurable quality loss. Selectively rewinding low-importance heads to their pre-trained state improves benchmark accuracy by up to 4% versus the fully trained baseline. Finally, we identify domain connectivity - linear interpolation between CPT checkpoints yields smooth domain-quality interpolation without notable degradation on either domain - and release Diffract, an open-source toolkit for scalable spectral analysis of billion-parameter models.

## 2. 方法论

**核心思想：** 将模型权重矩阵视为谱对象，通过对权重矩阵及其 CPT 增量（∆W = W_domain − W_pre-train）进行奇异值分解，分离"奇异值谱"与"奇异向量方向"两个维度的变化，以揭示领域适配的本质。

**关键技术细节：**

- **SVD 基础框架**：对权重矩阵 W ∈ R^(m×n) 进行分解 W = UΣV^T，计算 Frobenius 范数、谱范数、稳定秩 R_s(W)、有效秩 R_e(W) 等谱度量。
- **奇异向量一致性分析**：计算 W_pre-train 与 W_domain 之间左奇异向量的余弦相似度矩阵 A_u = |U_i^T U_j|，分为逐向量模式（可定位谱峰附近的向量变化）和聚合模式（量化每个注意力头/MLP 层的整体变化程度）。
- **谱分布拟合**：用 Marchenko–Pastur（MP）分布拟合谱主体，用幂律（PL）模型拟合重尾区域，以 Kolmogorov–Smirnov（KS）距离衡量拟合质量。
- **头重要性准则**：针对每个注意力头 (l, h)，计算目标域 CPT 增量与参考域（文本域）CPT 增量的归一化 Frobenius 范数之差：
  s_{l,h} = scale[0,1](‖W_domain^l,h − W_pre-train^l,h‖_F) − scale[0,1](‖W_reference^l,h − W_pre-train^l,h‖_F)
  据此排序头的重要性，并逐步将低重要性头回卷（rewind）到预训练状态。
- **CPT 增量 SVD 截断**：对 ∆W 做 SVD，将最小奇异值置零后重建截断增量，评估可删除的冗余比例。
- **领域连通性测试**：对同一预训练检查点经不同领域 CPT 得到的两个检查点做线性插值 W_interp(ω) = (1−ω)W_dom1 + ωW_dom2，评估中间模型的性能。

## 6. 主要结论与发现

- **CPT 基本保持奇异值谱不变**：实验证明将预训练模型的奇异值谱移植到 CPT 模型不损害质量，说明领域适配主要由奇异向量变化驱动，且这些变化集中在奇异值谱的峰附近。
- **预训练阶段注意力头谱结构复杂化**：20B 时形成幂律尾（符合 HTSR 理论），100B 后出现多峰、离群值等复杂结构，显著偏离 MP/PL 模型；MLP 则始终接近 HTSR。预训练 token 预算越大，谱结构越复杂，CPT 适配越快。
- **头异质性现象**：预训练 budget 增大后，部分注意力头在所有领域 CPT 下都显著变化，另一些头以领域特异方式变化；20B 小预算模型则变化均匀。
- **头重要性准则有效**：以文本域 CPT 为参考、比较目标域增量的归一化 Frobenius 范数差异，可有效识别低重要性头。选择性回卷低重要性头可在 7B 数学 CPT 上提升最高 4% GSM8K 准确率；可移除最多 60% 的头更新而无显著质量损失。
- **CPT 增量具有规模相关的冗余性**：7B 模型可截断 50% 奇异值、13B 可截断 70% 而无明显 GSM8K 下降；1B 模型退化更快。
- **领域连通性**：不同领域 CPT 检查点之间线性插值平滑，插值质量随预训练 token 预算和模型规模增大从凹转为凸；但线性插值不如直接在混合数据上训练。
- 发布了 Diffract 开源工具包，支持十亿参数模型的谱分析与可视化。

## 7. 优点

- **填补研究空白**：首次系统地从谱视角研究 CPT 的机制，不同于以往聚焦 SFT 的分析。
- **发现多个新现象**：头异质性、领域连通性、复杂谱结构与 CPT 效率的关联，均具原创性。
- **实用性强**：头重要性准则和选择性回卷可直接提升 CPT 质量或压缩更新量，有明确工程价值。
- **跨规模、跨领域验证**：覆盖 1B–32B、数学/指令/文本/代码，并利用官方外部检查点（OLMo 2 13B/32B CPT）重复验证，增强了结论可信度。
- **消融体系严谨**：以贪心排序作为近似" ground truth"对比各类谱启发式，统计鲁棒性分析（bootstrap、RNG 种子重复）严谨。
- **开源可复现**：同时发布分析工具（Diffract）和训练代码（diffract-training），并提供详细附录说明。

## 8. 不足与局限

- **架构普适性有限**：所有实验均基于 OLMo 2 家族，作者明确表示结论应视为在 OLMo 系内的稳健性证据，而非跨现代 LLM 的普适规律。
- **优化器覆盖单一**：仅使用 AdamW/OLMo 2 配方，未做优化器消融。
- **基准覆盖有限**：尽管包含 GSM8K、MATH-500、DROP、SQuAD、HumanEval 等，但对多领域能力的评估仍不全面（例如代码 CPT 效果极弱，HumanEval pass@1 仅从 0.04 提升到 0.09）。
- **规模研究不均**：从零预训练仅做了 1B，7B/13B 依赖官方检查点；32B 仅验证了头回卷，未做全部分析；领域连通性未在所有模型/领域组合上验证（如 code 域插值仅在 1B 上做）。

- **应用限制**：线性插值效果不如直接在混合数据上训练，表明任务向量式线性合并方法在 CPT 场景存在明显挑战。
- **理论工具受限**：注意力头谱结构显著偏离 HTSR 模型，现有随机矩阵理论框架不足以解释该复杂结构，需更精细的理论刻画。
