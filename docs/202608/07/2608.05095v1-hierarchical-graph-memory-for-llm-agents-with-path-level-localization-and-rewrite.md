## 摘要
长期推理的智能体需要一种能够随着新事实和外部反馈的持续到来而高效且有效地随时间更新的记忆。最近，图记忆已被采用，以提供多跳检索和推理的结构化组织。然而，现有方法将所有记忆存储在一个平面图中，累积的历史记忆可能引入不相关的上下文，并增加检索过程中证据选择的成本。此外，它们通常独立地更新记忆单元，需要重复的单元级重写以覆盖相关变化。为了解决这些问题，我们提出了HiGram，一种具有路径级定位和重写的演化层次化图记忆框架。具体来说，我们首先提出了一种层次化图记忆，它将记忆组织成由上层节点和MemoryUnit组成的从粗到细的架构，从而减少了检索过程中不相关信息量。我们进一步提出了基于MicroGraph的路径级定位，它利用查询和更新条件化的MicroGraph在重写之前识别支持子图和证据路径。最后，我们提出了一种协调重写方法，该方法联合修订单元内记忆和单元间依赖关系，使得在定位的证据路径中能够更新有效的依赖结构。在长期会话问答和冲突感知记忆评估的基准上的实验表明，我们的方法在答案质量和标记效率上比基线有显著提升。此外，我们的方法在动态、静态和条件冲突下提高了答案准确性和查询有效的证据选择。

## Abstract
Agents for long term reasoning require a memory that can be efficiently and effectively updated over time, as new facts and external feedback continue to arrive. Recently, graph memory has been adopted to offer structural organization for multi-hop retrieval and reasoning. However, existing methods store all memories in a flat graph, and accumulated historical memories can introduce irrelevant contexts and increase the cost of evidence selection during retrieval. Moreover, they typically update memory units independently, requiring repeated unit-wise rewrite to cover related changes. To address these issues, we propose HiGram, an evolving hierarchical graph memory framework with path-level localization and rewriting. Specifically, we first propose a hierarchical graph memory, which organizes the memory into coarse-to-fine architecture composed of upper-level nodes and MemoryUnits, thereby reducing the amount of irrelevant information during retrieval. We further propose MicroGraph-based path-level localization, which leverages query and update conditioned MicroGraphs to identify support subgraph and evidence path before rewrite. Finally, we propose a coordinated rewriting method that jointly revises intra-unit memory and inter-unit dependencies, enable valid dependency structures updating in the localized evidence path. Experiments on benchmarks for long-term conversational question answering and conflict-aware memory evaluation demonstrate that our method demonstrate substantial improvements over baselines in answer quality and token efficiency. Besides, our method improves answer accuracy and query-valid evidence selection under dynamic, static, and conditional conflicts.

## 1. 核心问题与研究动机

### 问题背景
- 长期推理智能体（LLM Agent）需要一种能够随新事实和外部反馈持续演化的记忆机制，以支持跨会话的长期交互与推理。
- 现有基于图记忆的方法虽然能为多跳检索和推理提供结构化组织，但仍存在两大核心缺陷：
  - **扁平结构问题**：所有记忆存储于单一平面图中，检索需要遍历整体图，历史记忆累积后易引入大量不相关上下文，增加证据筛选成本。
  - **独立更新问题**：现有方法通常独立更新单个记忆单元，而答案往往由多个互相连接的证据路径支撑，独立更新易遗漏相关证据，导致重复改写和大量 token 消耗。

### 核心洞察
- 现有方法存在“记忆组织与更新的粒度”和“推理所需证据结构粒度”之间的**不匹配**。
- 检索操作作用于持续扩展的整体图，而答案通常仅依赖局部小范围证据；更新的影响可能沿证据路径传播。
- 因此，记忆系统应**先定位查询相关子图，再识别受更新影响的证据路径，最后在受限区域内联合修订记忆状态及其依赖关系**。

## 2. 方法论：HiGram 框架

### 总体架构
HiGram 包含三个核心阶段：

### 阶段一：层次化记忆组织（Hierarchical Memory Organization）
- 将记忆组织为层次化图结构 Gt = (Vt, Et)，节点集分为**上层节点**和**MemoryUnit（记忆单元）**：
  - **上层节点**：包括主语节点（Vsub）、宾语类别节点（Vcat）、上下文节点（Vctx），提供粗粒度抽象，实现快速区域定位。
  - **MemoryUnit（Mt）**：存储细粒度事实信息，包含主语、关系、宾语、宾语类别、时间、上下文、置信度、状态（激活/被取代/过期/待定）等属性。
- 边集包含三种类型：上层节点与 MemoryUnit 的连接边，以及 MemoryUnit 之间的**依赖边**（Edep）。
- 过期、被取代等非活跃单元保留在图中以维持修订历史，但不参与当前检索。

### 阶段二：基于 MicroGraph 的路径级定位（Path-level Localization）
- **MicroGraph 构建**：每个 MicroGraph 由“主语节点 + 宾语类别节点”对定义，表示全局图记忆中的局部区域，不新增额外记忆内容。
- **锚点提取**：从查询和更新文本构造临时 MemoryUnit，提取其主语和宾语类别作为锚点。
- **候选 MicroGraph 筛选**：根据锚点与 MicroGraph 的匹配度排序，选取 Top-Kg 个 MicroGraph，形成**支持子图** GS,t。
- **路径级定位**：在支持子图内枚举最多 Kp 条候选证据路径（连接 MemoryUnit 的链），根据与临时 MemoryUnit 的语义一致性、时序有效性、上下文匹配度等打分函数 ϕH，选出**受影响证据路径** P̂t，作为后续重写的限定区域。

### 阶段三：协同重写（Coordinated Rewriting）
- **单元内重写（Intra-unit Rewrite）**：将临时 MemoryUnit 与证据路径中的现有 MemoryUnit 匹配，更新内部状态和有效时间信息；新记忆作为激活单元提交，旧记忆保留状态转换历史。
- **单元间重写（Inter-unit Rewrite）**：识别受影响单元的依赖单元集合 Dt(mi)，检查依赖关系在更新后是否仍然成立；不成立的依赖被标记为过期并排除，更新单元不自动继承原依赖关系。
- **关键原则**：目的是维护一致性的证据结构，而非覆盖历史记忆；区域外的 MemoryUnit 和关系保持不变。

## 6. 主要结论与发现

1. **答案质量与 token 效率可兼得**：HiGram 在 LoCoMo 上取得最佳平均 F1、BLEU 和 LLM-J，同时 token 消耗仅为全上下文方法的 7.2%（GPT-5.4）和 ReadAgent 的 15.8%（GPT-4o）。
2. **时间性与对抗性问答增益显著**：HiGram 在 Temporal 类别上双模型均排第一，对抗性问题在 GPT-5.4 下也最优，说明时间有效性范围和局部证据路径能有效限制过期和无关记忆的干扰。
3. **冲突一致性大幅提升**：在 MemConflict 上，HiGram 在静态和条件冲突上显著领先，动态冲突下虽 AA 非最高但 UOCS 最优，表明其主要优势在于跨更新顺序的一致性保持。
4. **证据选择质量突出**：HiGram 在 SEH@3 和 SRS 两项证据选择指标上均排名第一。
5. **层次结构与路径定位相互作用**：消融表明，MicroGraph 组织大幅降低 token 消耗（移除后增加 68.6%），支持子图则保障多跳和时间性推理所需的结构化证据。
6. **协同更新优于插入和孤立更新**：HiGram 在动态和静态冲突上都优于 Append-only 和 Relation-level 更新策略，避免了顾此失彼的权衡。

## 7. 方法亮点与优势

- **问题定位精准**：明确指出图记忆中“组织/更新粒度”与“推理证据粒度”的不匹配，动机清晰且具有说服力。
- **架构设计优雅**：“粗到细”的三级定位（上层节点 → MicroGraph → 证据路径）符合“先粗筛再精定位”的检索直觉，工程上易于实现。
- **更新机制新颖**：协调重写同时处理单元内部状态和单元间依赖，解决了现有方法“更新孤立事实但忽略依赖传播”的关键痛点。
- **不覆盖历史、保留演化轨迹**：通过 active/superseded/outdated/pending 状态保存记忆修订历史，避免信息丢失并支持回溯。
- **多维度实验验证**：从答案质量、token 效率、冲突一致性、证据排序、消融分析、超参数敏感性等角度全面验证，证据链较为完整。
- **结果一致性强**：在两种不同 LLM 骨干上表现一致，说明方法优势不依赖特定模型。
