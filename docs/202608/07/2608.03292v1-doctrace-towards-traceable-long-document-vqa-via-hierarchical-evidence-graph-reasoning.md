## 摘要
长文档视觉问答（LongDocVQA）要求多模态大语言模型（MLLMs）定位、整合并推理分布在多页中的异构文档元素。现有方法，包括端到端MLLMs、检索增强生成（RAG）流水线和文档代理，通常缺乏显式机制来表示和验证推理过程中基础证据是如何逐步组合的，从而限制了答案的准确性和可追溯性。在本文中，我们将LongDocVQA视为显式的证据图推理问题，而非隐式的答案预测。为此，我们提出DocTrace，一个分层框架，逐步执行证据定位、结构化文档解析和证据图推理，以实现显式的证据来源追踪。为了有效学习这些能力，我们开发了一个两阶段训练框架：联合监督微调（SFT）首先初始化证据定位和图推理能力，随后使用专用奖励的任务特定组相对策略优化（GRPO）进一步优化这些能力。在MMLongBench-Doc、LongDocURL和SlideVQA上的大量实验表明，DocTrace持续优于现有的开源基线和专有MLLMs。与Qwen3-VL-8B-Instruct骨干相比，DocTrace在三个基准上分别实现了14.4、11.3和11.7个百分点的绝对提升。除了具有竞争力的性能外，DocTrace构建了具有显式节点级来源的可追溯证据图，为长文档理解实现透明且可验证的推理。

## Abstract
Long Document Visual Question Answering (LongDocVQA) requires Multimodal Large Language Models (MLLMs) to locate, integrate, and reason over heterogeneous document elements distributed across multiple pages. Existing approaches, including end-to-end MLLMs, retrieval-augmented generation (RAG) pipelines, and document agents, often lack explicit mechanisms to represent and verify how grounded evidence is progressively composed during reasoning, limiting both answer accuracy and traceability. In this paper, we cast LongDocVQA as an explicit evidence graph reasoning problem rather than implicit answer prediction. To this end, we propose DocTrace, a hierarchical framework that progressively performs evidence localization, structured document parsing, and evidence graph reasoning to enable explicit evidence provenance. To effectively learn these capabilities, we develop a two-stage training framework: joint Supervised Fine-Tuning (SFT) first initializes evidence localization and graph reasoning abilities, followed by task-specific Group Relative Policy Optimization (GRPO) with dedicated rewards to further optimize these capabilities. Extensive experiments on MMLongBench-Doc, LongDocURL, and SlideVQA demonstrate that DocTrace consistently outperforms both existing open-source baselines and proprietary MLLMs. Compared with the Qwen3-VL-8B-Instruct backbone, DocTrace achieves absolute improvements of 14.4, 11.3, and 11.7 points on the three benchmarks, respectively. Beyond competitive performance, DocTrace constructs traceable evidence graphs with explicit node-level provenance, enabling transparent and verifiable reasoning for long document understanding.

- **核心痛点**：在金融审计、医疗分析等高危场景中，仅给出正确答案不够，用户还需能**审查答案的可追溯性**，即每一步结论如何从基础证据推导而来。现有方法（端到端MLLM、RAG流水线、文档智能体）均缺乏对证据逐步组合关系的显式建模：
  - **端到端MLLM**：证据聚合隐含在隐层表征中，不可检视；
  - **RAG方法**：将检索到的证据视为无序上下文，不建模证据间的组合逻辑；
  - **文档智能体**：推理以交互轨迹为导向，而非显式表示证据依赖关系。
- **核心主张**：论文将LongDocVQA从“隐式答案预测”重构为**显式证据图推理问题**，主张证据组合应作为显式推理对象进行建模，以同时提升答案准确性和可追溯性。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想：分层粗到细的证据图推理

DocTrace采用三级流水线，将长文档推理空间逐步收敛，并显式构建证据组合关系：

1. **Stage 1：证据定位（Evidence Localization）**
   - 输入：低分辨率全文档页面图像 + 问题Q；
   - 输出：证据页索引集合 P_evid = f_θ_loc(D_low, Q)；
   - 作用：在512px分辨率下轻量扫描全文档，筛选问题相关页面，避免全文档高分辨率处理带来的上下文溢出。

2. **Stage 2：结构化文档解析（Structured Document Parsing）**
   - 对定位出的证据页在1568px原生分辨率下使用PaddleOCR-VL-1.5进行细粒度解析；
   - 每个元素表示为 bᵢ = (tᵢ, xᵢ, cᵢ)，其中tᵢ为语义类型（文本、表格、图表等），xᵢ为边界框，cᵢ为提取内容；
   - 所有元素构成证据池 B = {b₁, b₂, ..., b_M}，作为图推理的原子证据单元。

3. **Stage 3：证据图推理（Evidence Graph Reasoning）**
   - 显式构建有向无环图（DAG）G = (V, E)：
     - **证据节点**：来自证据池的实体文档元素；
     - **派生节点**：由一个或多个证据节点组合得到的中间推理结论；
     - **有向依赖边**：描述证据如何逐步组合直至推导出最终答案。
   - 推理形式化：P(A, G | B, Q) = P(G | B, Q) · P(A | G, Q)，即先构建证据图，再基于图生成最终答案，由此实现**节点级证据溯源**。

### 2.2 训练范式：两阶段训练

**（a）训练数据自动构建**

由于现有基准只提供问答对而无中间推理监督，论文建立“教师-验证者”流程自动生成监督信号：
- 将训练样本分为四类场景：单页可答、多页可答、无关不可答、细节缺失不可答；
- Gemini 3.1 Pro生成证据页和证据图，GPT-5.5独立验证证据充分性、逻辑一致性与答案正确性；
- 仅保留通过全部验证的样本，最终构建包含36,819条样本的训练语料。

**（b）联合SFT（Joint SFT）**

- 多任务联合优化：低分辨率下预测证据页索引 + 高分辨率下生成证据图与最终答案；
- 为后续GRPO提供强初始化。

**（c）任务特定GRPO（Task-specific GRPO）**

分两阶段顺序强化学习，配备三类奖励：

- **定位奖励（R_stage1）**：距离感知的软Fβ奖励，对接近真实页的预测给予部分分数（β=2.0，侧重召回），显著优于二元精确匹配；
- **图忠实度奖励（R_graph）**：综合评估证据接地性（hit）、图完整性（completeness）、结构有效性（structure，确保可执行DAG与合法引用）和依赖拓扑一致性（topology）；
- **答案正确性奖励（R_answer）**：精确匹配与LLM语义等价验证相结合（α=0.5）；对不可答问题鼓励拒答、惩罚幻觉。

Stage 3总奖励：R_stage3 = λR_graph + (1−λ)R_answer，λ=0.3。

## 6. 主要结论与发现

1. **性能大幅超越**：DocTrace（GRPO）在MMLongBench-Doc上达到52.9（较骨干+14.4，超过最强开源MM-Doc-R1 3.2点、超过GPT-4.1 7.3点）；LongDocURL达56.4（+11.3）；SlideVQA达85.1 F1（+11.7，超过Doc-V\* 7.9点）。
2. **两阶段训练有效互补**：SFT带来主要提升（+11.8/+8.1/+10.4），任务特定GRPO进一步稳定增益；Stage 1 GRPO侧重提升证据召回，Stage 3 GRPO侧重改善证据利用与不可答问题拒答。
3. **长文档扩展性稳健**：从60页延长至120页+时，基线准确率从49.5跌至34.0，而DocTrace保持稳定；条件在“证据成功定位”上的答案准确率几乎不随文档长度变化，瓶颈主要在证据定位而非推理。
4. **显式证据图可追溯性良好**：证据接地率99.5%、图完整性99.6%，反事实实验表明被引证据对预测具有功能性必要性（82.8% vs 9.6%）。
5. **消融支持核心设计**：去除结构化解析或证据图推理均显著下降（-3.7和-3.1）；普通CoT虽提升单页表现但跨页与拒答能力明显不足；SoM（视觉标记）对多页推理至关重要（-5.2点）。
6. **效率显著提升**：相比端到端基线，DocTrace端到端延迟减少2.1倍（15.04s→7.33s），prefill tokens减少2.3倍。
7. **主要瓶颈定位**：错误主要源于Stage 1证据定位不完全（多页问题覆盖率仅46.5%）；不可答问题的幻觉全部源于Stage 1的错误判定，据此提出改进方向。

## 7. 优点

- **视角创新**：将LongDocVQA从隐式答案预测重构为显式证据图推理问题，填补了证据依赖关系建模的空白；
- **可追溯性设计完整**：节点级证据溯源不是事后附加，而是内置于推理结构与训练目标中；
- **训练方案工程性强**：自动数据构建（教师-验证者）、四类场景分类、GRPO候选筛选（丢弃完全对/完全错的样本）等方法设计细致，有效缓解了有监督信号缺失问题；
- **奖励设计精细**：距离感知软Fβ定位奖励（支持部分信用）、多维图忠实度奖励（接地性/完整性/结构/拓扑）等设计具有开创性；
- **分析深度突出**：反事实因果评估、逐阶段错误归因、上下文溢出率分析、效率对比等均超出一般论文的实证深度；
- **效率与性能兼得**：分层设计使高分辨率推理集中在证据页，因而在提升准确度的同时反而降低推理成本。

## 8. 不足与局限

- **训练数据依赖闭源模型**：监督信号由Gemini 3.1 Pro和GPT-5.5生成，引入商业模型的潜在偏差与错误，且存在高昂API成本；
- **评估分面隔离风险**：训练数据包含SlideVQA，测试也在SlideVQA上进行，难以完全排除评估污染；
- **基线公平性存疑**：部分基线结果引自原论文而非统一复现环境，存在实现细节和推理成本的比较偏差；
- **大规模数据构建成本**：36,819条训练语料需多次调用闭源模型生成与双重验证，训练流程复杂、复现门槛较高；
- **证据图评估的因果说明局限**：反事实试验只能证明被引用证据对预测具有行为层面的重要性，并不能证明模型内部真正遵循显式证据图进行推理；
- **骨干单一**：只在Qwen3-VL-8B上验证，未测试在更大模型或其他架构（如70B级）上的泛化性；
- **训练时长未披露**：未报告具体训练时长，影响复现者的成本预估；
- **应用限制**：推理管线依赖外部OCR/文档解析模型，解析错误会向上传播；对高度复杂版面或极端视觉噪声文档的鲁棒性未充分测试。
