## 摘要
多跳问答是检索增强生成（RAG）中的一个基本挑战，因为推导答案需要整合分散的证据。迭代RAG（iRAG）被广泛用于解决这一挑战，但现有方法存在两个局限性。首先，大多数方法仍然用单粒度证据支持每个推理步骤，难以平衡信息密度和上下文噪声。其次，现有方法通常只在聚合跨中间步骤检索到的证据后才回答原始问题，因此冗余证据和中间检索错误可能会累积并降低最终答案的质量。为了解决这些局限性，我们提出了MEGRAG，一个答案感知框架，将多跳推理表示为路径结构的多粒度证据图。离线时，MEGRAG通过跨粒度索引将段落与其句子和提取的三元组链接起来。在线时，它为当前查询检索段落并选择对齐的证据，从紧凑的三元组开始，根据需要添加句子或段落上下文。MEGRAG利用生成的中间答案和先前的推理来决定初始查询是否已解决。如果没有，它识别缺失信息并制定聚焦的下一个查询；否则，它停止检索并返回答案。大量实验表明，MEGRAG在各种RAG基线上取得了持续的改进。

## Abstract
Multi-hop question answering is a fundamental challenge in retrieval-augmented generation (RAG), because deriving an answer requires integrating dispersed evidence. Iterative RAG (iRAG) is widely used for this challenge, but existing methods have two limitations. First, most methods still support each reasoning step with single-granularity evidence, making it difficult to balance information density and contextual noise. Second, existing methods often answer the original question only after aggregating evidence retrieved across intermediate steps, so redundant evidence and intermediate retrieval errors may accumulate and degrade the final answer. To address these limitations, we propose MEGRAG, an answer-aware framework that represents multi-hop reasoning as a path-structured multi-granular evidence graph. Offline, MEGRAG links passages to their sentences and extracted triples through a cross-granularity index. Online, it retrieves passages for the current query and selects aligned evidence, starting with compact triples and adding sentence or passage context as needed. MEGRAG uses the resulting intermediate answer and prior reasoning to decide whether the Initial Query has been resolved. If not, it identifies the missing information and formulates a focused next query; otherwise, it stops retrieval and returns the answer. Extensive experiments demonstrate consistent gains over a diverse set of RAG baselines.

## 一、论文核心问题与研究动机

多跳问答（Multi-hop QA）要求模型在多个分散证据源之间建立联系，逐步推理出最终答案。传统RAG在单跳问题上表现优秀，但在多跳场景下存在明显短板：

1. **局部线索捕获**：单次检索仅针对初始查询排序，容易遗漏那些只有在部分推理后相关性才显现的中间证据。
2. **迭代RAG的两个关键局限**（论文的直接动机）：
   - **单粒度证据问题**：大多数现有方法在每一步推理中只使用单一粒度的证据（如纯段落、纯句子或纯三元组），难以同时兼顾信息密度与上下文噪声——细粒度证据缺乏足够上下文，粗粒度证据又容易引入无关信息。
   - **后聚合回答问题**：多数迭代方法先完成所有中间步骤的证据检索与聚合，最后才回答原始问题，导致冗余证据和中间检索错误在推理链中累积，破坏最终答案质量。

论文引用人类选择性、目标导向的推理过程作为灵感：人只寻求足以支持判断的证据，用中间结论来识别未知信息并引导后续查询。

## 二、方法论 MEGRAG

### 2.1 核心思想

MEGRAG（Multi-Granular Evidence Graphs）是一个答案感知（Answer-Aware）的RAG框架，将多跳推理表示为一个**路径结构的多粒度证据图**。框架的核心分工是：

- **离线**：构建可复用的跨粒度证据空间（段落-句子-三元组三层视图）；
- **在线**：针对具体问题执行问题特定的检索、证据选择、推理与停止决策。

### 2.2 关键技术细节

**(1) 多粒度证据空间（离线）**

构建 `E = {EP, ES, ET, I}`，其中：
- **EP / ES / ET**：分别表示段落级、句子级、三元组级证据视图；
- **I**：跨粒度证据索引，将句子和三元组记录链接回其来源段落。
- 使用 NV-Embed-v2 做段落稠密检索，句子和三元组通过索引对齐获取，而非独立检索。

三者互补：段落保留广泛上下文（实体消歧、跨句推理），句子保留局部约束（别名、时间线索、否定、比较），三元组提供紧凑的关系事实（由大模型 OpenIE 提取）。

**(2) 路径结构的问题特定证据图（在线）**

- 初始化：当前查询 `q1 = x`（初始查询）。
- 第 i 步节点：`vi = (qi, Zi, bi, hi, mi, yi, si)`：
  - `Zi`：选择的证据（三元组+句子+段落组合）；
  - `bi`：基于证据的**当前查询**的中间答案；
  - `hi`：已解析的推理路径；
  - `mi`：剩余信息需求；
  - `yi`：初始查询的答案（仅在 si=1 时非空）；
  - `si ∈ {0,1}`：停止决策。
- 继续边：`e_cont = (vi, ri, vi+1)`，其中 ri 记录目标条件化的转换关系（如何从当前查询延伸到下一查询以回答初始查询）；
- 终止边：`e_stop = (vi, STOP)`。

**(3) 候选收集**

每个步骤编码当前查询 qi，向量化检索 top-NP 段落，通过索引 I 收集关联的句子和三元组（去重后各保留 NS 和 NT 个），形成三个对齐的证据视图。

**(4) 自适应证据选择（sufficiency-guided）**

按**细到粗**的顺序评估证据充分性：
```
CTi → CTi ∪ CSi → CTi ∪ CSi ∪ CPi
```
首先判断三元组是否足以回答当前查询；若不足，依次添加句子、段落，停在第一个被判定为充分的粒度。这样既压缩了证据量，又不假设固定粒度对所有问题或步骤成立。

**(5) 答案感知迭代推理**

- 根据 Zi 产生中间答案 bi，更新已解析路径 hi；
- 将中间答案与先前推理（图摘要 Hi）结合，判断初始查询是否已解决：
  - **未解决**：记录缺失信息 mi，生成聚焦的下一查询 qi+1 和转换关系 ri，mi ≠ none，yi = ∅，si = 0；
  - **已解决**：mi = none，返回 yi，si = 1，qi+1 = ∅，添加终止边。
- 预算耗尽时（sB=0）：仅用所有有序已选证据 (Z1,...,ZB) 调用最终解析器，标记为预算耗尽。

**(6) 图构建蒸馏（Graph Construction Distillation）**

- 教师模型（Qwen3-Max）为 3,000 个训练问题生成完整轨迹；
- 学生模型（Qwen3-8B）通过 LoRA 微调，在每一步复现教师的完整决策：
  ```
  LGCD = -Σ_ξ Σ_i log pθ(oi | x, qi, Hi, Ci)
  ```
- 蒸馏使学生学会选择证据、产生中间答案、判断初始查询是否已解决、生成下一查询。

## 六、主要结论与发现

1. **主结果全面领先**：MEGRAG 在全部 12 列比较（2 骨干 × 3 数据集 × F1/EM）中获得最高观测值；最大增益出现在 MuSiQue（需更长组合链），Qwen3-8B 下 F1 超最强基线 8.34 点；
2. **多粒度自适应选择有效**：没有单一固定粒度占优（段落最强于 2WikiMultiHopQA/HotpotQA，句子最强于 MuSiQue），MEGRAG 超过各数据集最强固定粒度变体 1.45–6.23 F1；
3. **答案感知停止有效**：HotpotQA 89.3% 问题 1 步结束，节省 71.88% LLM 调用和 74.10% token，代价仅 −1.46 F1；MuSiQue 更常继续检索，节省 58.10%/59.50% 的调用/token 且 ΔF1 = +0.04；
4. **转换关系有价值**：去除 ri 导致 MuSiQue F1 −1.61，打乱后 −2.91，说明后续决策依赖转换关系的内容而非仅其存在；
5. **蒸馏重要但非必需**：去除 SFT 在 Qwen3-8B 上 F1 下降 6.33–18.41；但 prompt-only 的 Qwen3-Max 仍保持领先，证明推理过程本身的有效性；
6. **结构化历史贡献显著**：去除后 MuSiQue F1 下降 5.81；
7. **更长链仍具挑战**：MuSiQue 四跳问题 F1 降至 37.9，即便 MEGRAG 动用了更多检索步数和更丰富的证据。

## 七、方法亮点

1. **多粒度证据的按需组合**：从三元组开始逐级扩展至句子和段落，在信息密度与上下文完整性之间做自适应权衡，避免固定粒度偏差；
2. **"当前查询"与"初始查询"的显式区分**：每步先回答当前查询，再用中间答案判断初始查询是否已解决——这是对 iRAG 范式的重要改进，直接缓解错误累积；
3. **路径结构化证据图 + 目标条件化转换关系**：明确记录每个中间答案如何揭示下一个信息需求，使推理过程透明可解释；
4. **离线/在线分离的优雅设计**：离线组织可复用证据视图，在线做问题特定推理，避免对全语料知识图谱的依赖；
5. **鲁棒性验证充分**：多检索器、多骨干、多预算、单跳迁移等多维度验证，增强结论的可信度；
6. **高效停止**：在准确性和计算成本之间取得有利权衡，且不牺牲准确率（MuSiQue 上甚至略增 F1）。

## 八、不足与局限

1. **无回溯能力**：单一路径结构意味着一旦中间状态出错，后续推理无法回溯修正（论文明确承认）；
2. **检索范围受限**：无法恢复超出段落检索范围之外的证据，三元组自动提取可能包含错误或遗漏修饰成分；
3. **训练依赖**：轻量学生模型需要任务特定的教师轨迹（Qwen3-Max 作为教师）；虽然 prompt-only 教师模型无需微调，但蒸馏路径有额外数据成本；
4. **评估范围有限**：主实验使用 benchmark 特定候选语料、英语事实型 QA，未覆盖多语言、开放域或非事实型推理场景；
5. **统计显著性有限**：Qwen3-Max 下部分 EM 差异未达显著水平，报告为观测排序而非统一显著结论；
6. **延迟报告不完整**：报告的端到端延迟排除了一次性离线成本（OpenIE、嵌入、索引），且综合延迟高于多个图基基线；
7. **确定性图更新**：每个节点至多一个后继，本质上是"路径"推理而非通用图搜索或消息传递框架，适用范围有边界；
8. **其他设计选择未充分探讨**：三元组优先的固定选择顺序、蒸馏轨迹的过滤标准等是否有更优变体，留作未来工作。

## 结语

MEGRAG 通过"多粒度证据 + 答案感知停止 + 路径结构图"三位一体的设计，为多跳 RAG 提供了新的有效范式。其在三项多跳基准上的全面领先建议了自适应证据粒度与中间答案驱动控制对于缓解证据噪声和错误累积的重要性。尽管存在无回溯、评估范围窄、训练依赖等局限，论文在方法论的系统性、实验验证的多维度和分析深度上均表现扎实，尤其是指出并解决了现有 iRAG 中"证据粒度固定"和"先聚合后回答"两个此前较少被联合审视的问题。
