## 摘要
多模态大语言模型（MLLMs）在视觉理解与推理方面取得了进展，但其静态参数化知识限制了它们解决知识密集型和动态演变的开放世界问题的能力。为突破这一局限，多模态深度搜索已成为开放世界信息访问的关键方向，从单轮事实检索向由视觉证据引导的长时程、多轮搜索演进。然而，现有方法通常将视觉局限于输入或答案阶段，忽视其在中间推理中的作用，且缺乏针对长时程交互的设计。因此，视觉证据很少能驱动持续检索，限制了交互深度和推理跨度。为解决这些问题，我们提出DeepVoyager-VL，一种用于视觉在环搜索的长时程多模态深度搜索框架。具体而言，我们构建多模态事件图以驱动数据合成，生成具有中间视觉依赖和长推理链的问题。然后，我们设计一个用于主动视觉获取和按需图像加载的智能体框架。最后，我们在合成数据上对模型进行微调，无需强化学习。跨十个多模态搜索基准的大量实验证明了我们方法的有效性。

## Abstract
Multimodal large language models (MLLMs) have advanced visual understanding and reasoning, yet their static parametric knowledge limits their ability to address knowledge-intensive and dynamically evolving open-world problems. To move beyond this limitation, multimodal deep search has emerged as a key direction for open-world information access, evolving from single-turn factual retrieval toward long-horizon, multi-turn search guided by visual evidence. However, existing methods typically confine vision to the input or answer stage, overlooking its role in intermediate reasoning, and lack designs tailored to long-horizon interaction. Consequently, visual evidence rarely drives continued retrieval, constraining both interaction depth and reasoning span. To address these limitations, we propose DeepVoyager-VL, a long-horizon multimodal deep-search framework for vision-in-the-loop search. Specifically, we construct a multimodal event graph to drive data synthesis, yielding problems with intermediate visual dependencies and long reasoning chains. We then design an agent framework for active visual acquisition and on-demand image loading. Finally, we fine-tune models on the synthesized data without reinforcement learning. Extensive experiments across ten multimodal search benchmarks demonstrate the effectiveness of our method.

## 1. 核心问题与整体含义（研究动机与背景）

多模态大语言模型（MLLMs）在视觉理解和推理方面已取得显著进展，但其知识完全固化在静态参数中，难以应对知识密集型、动态演变的开放世界问题。深度搜索智能体通过迭代推理和工具使用收集外部证据来弥补这一局限，但现有方法存在一个关键结构性缺陷：

- **视觉证据被边缘化**：现有多模态搜索方法将视觉要么放在输入阶段（通过实体替换）、要么集中在搜索前阶段（文本搜索前先做一次视觉探索）、要么嫁接在答案附近。三种范式的共同问题是——**推理链都先用文本构建**，中途获得的视觉观察几乎不会决定后续的检索动作，视觉证据无法真正"驱动"搜索。
- **长时程交互缺乏设计**：长交互中，盲目加载所有候选图片会消耗过多多模态上下文，而仅保留文本摘要又会丢失后续所需的细节。现有上下文管理机制多是被动式的（在证据已进入上下文之后处理），缺少对"何时、加载什么视觉证据"的主动决策。

为此，论文提出 **视觉在环搜索（Vision-in-the-Loop Search）** 范式：新获取的视觉证据应当解决某个中间变量，进而实例化后续查询——视觉成为驱动检索的关键一环，而非输入或终端模态。DeepVoyager-VL 正是实现这一范式的长时程多模态深度搜索框架。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体框架

DeepVoyager-VL 包含五个阶段，分为数据合成（阶段1–2）、难度感知的轨迹筛选（阶段3–4）和监督式智能体训练（阶段5）。

**形式化定义**：给定查询 x = (q, Is)，智能体与开放网络环境交互；若存在 1 ≤ t < t' ≤ T 使视觉观察 oᵥᵗ 决定后续行动 aᵗ'（即 oᵥᵗ ⇝ aᵗ'），且满足反事实视觉必要性（移除视觉证据后答案不唯一），则该轨迹属于"视觉在环"。

### 2.2 视觉在环数据合成（EventVoyage-VL）

核心设计原则是**结构先于语言**（Structure-before-Language）——先确定证据依赖和答案，再进行问答语言化。具体过程：

1. **多模态事件图构建与富化**：从 Wikipedia 和多领域新闻中抽取实体与事件，构建图 G₀ = (V, E, M)。时空共现的记录形成宏事件，重复的实体对交互形成关系束。
2. **智能体视觉证据富化**：用搜索智能体为图添加图像，每个图像存储检索上下文 K_ret(I) 和视觉内容证据 F_vis(I)，并强制执行 K_ret(I) ∩ Alias(y) = ∅ 防止答案泄漏。
3. **子图提取与程序合成**：从图中提取视觉共现网络、时间事件链、空间共址结构、多关系稠密模体等结构，组成推理程序 Π = (D, U, L, Is, Ir, y)。关键约束包括：相邻原语的接口兼容（out(gᵢ) = in(gᵢ₊₁)）、至少一个内部接口由视觉解析，以及每个主约束的必要性（|U_L| = 1, |U_L\{ℓ}| > 1）。
4. **QA 实现与质量控制**：多模态生成器将程序言语化为问题，验证器检查程序完整性、约束最小性、泄漏、重复、图文对齐等，并通过反事实移除测试检验视觉必要性。

### 2.3 长时程多模态搜索智能体

智能体框架的关键设计是**"分级证据接口"**与**"主动视觉获取"**：

- **候选发现与视觉观察解耦**：搜索工具（文本搜索、图像搜索、反向图像搜索）只返回轻量的 URL–标题等引用信息；而 FETCH IMAGE 和 CROP IMAGE 是仅有的两种将视觉 token 物化到策略上下文中的操作。这一设计使"可发现性"与"可观察性"分离，候选添加仅增加引用，视觉内容按需加载。
- **目标条件化压缩**：网页访问、图像搜索、反向图像搜索的输出进入策略上下文前，由辅助 VLM 仅提取与目标相关的结论、来源线索和图像引用。查询相关摘要引导导航，但可回答问题的图像仍需显式加载。
- **视觉寄存器**：跨轮次保存已获取的视觉观察（输入图像、提取图像、裁剪区域），支持后续视觉操作与检索，形成累积式的视觉工作记忆。

**算法流程（Algorithm 1）**：智能体每轮生成推理与动作；若动作为答案则返回；否则执行工具获得观察：视觉工具更新视觉寄存器，目标条件化工具（WebVisit、ImageSearch、ReverseImageSearch）的输出先经 GoalExtract 压缩再入上下文，循环至预算上限。

### 2.4 数据筛选与训练

- **难度分层**：先用直答探针排除无需工具即可回答的问题，再用工具增强的 rollout 将剩余问题分为中/硬两级。**难度估计与轨迹生成分离**，避免低质量探针行为污染监督信号。
- **教师轨迹生成与验证**：用更强模型重新生成轨迹，LLM 评判器和协议验证器确保轨迹正确、合法、可重放。
- **监督微调**：仅微调语言主干，冻结视觉编码器和多模态融合层。损失仅监督助手推理、工具调用和答案 token，无强化学习阶段。优化目标是带损失掩码的 SFT 交叉熵。

## 6. 主要结论与发现

1. **显著性能提升**：轨迹 SFT 使 8B 模型平均性能提升 55.2%（35.3→54.8），30B-A3B 提升 44.0%（40.7→58.6）；在规模匹配的开源多模态深度搜索智能体中，30B 模型在十个基准中的九个取得最佳，8B 模型在八个取得最佳。
2. **增益集中在搜索密集任务**：相对智能体工作流基线，30B 在前四个基准平均提升 10.3 分，而 BrowseComp-VL 至 VisBrowse-Bench 的六个基准平均提升 23.1 分；最大增益出现在 BrowseComp-V³（+23.7）和 VisBrowse-Bench（+30.7），正是需要反复获取和消费视觉证据的长程任务。
3. **VIL 数据具有增量价值**：在 20K 多源轨迹基线之上，仅 7K VIL 轨迹带来 8B 模型 5.4 分、30B 模型 6.5 分的额外提升，且收益在图像密集任务上最大。
4. **框架组件互补**：移除任一组件（Summary/Image Search/Fetch Image/Crop Image）都使平均性能下降 2.5–4.0 分，其中 Summary 贡献最大（尤其在 FVQA），裁剪在 VDR-Bench 最关键。
5. **数据特征符合设计目标**：EventVoyage-VL 数据中视觉工具调用占比 64.3%（OpenSearch-VL 为 40.6%、Vision-DeepResearch 为 30.3%、REDSearcher-MM 仅 10.1%），轨迹长度峰值在 16–20 轮区间，显著长于现有数据集（1–5 或 6–10 轮），体现视觉在环与长时程特征。

## 7. 优点

- **"结构先于语言"的数据合成范式**：将现有方法（实体替换、前置视觉探索、答案侧嫁接）的根本缺陷——"先文本后视觉"——直接反转，从多模态事件图出发构建推理程序，确保中间视觉依赖是逻辑必需而非装饰，并有反事实验证保证视觉必要性
- **可发现性与可观察性解耦**：轻量引用与全量视觉加载分离，使上下文增长服从证据需要而非工具返回量，是多模态长时程交互中一个优雅且实用的设计
- **难度估计与轨迹生成分离**：低能力模型的探针行为不进入监督语料，避免污染；这一设计提升了训练数据的质量
- **无需强化学习**：仅监督微调即可达到 SOTA 水平，训练稳定、成本较低，规避了 RL 的不稳定性和奖励设计难题
- **框架泛化性好**：在三种不同基座模型（含商业模型）上均取得最高平均分，说明框架本身具有推广价值
- **轨迹行为分析严谨**：控制模型与环境变量，仅改变数据源，清晰展示了数据驱动行为差异
