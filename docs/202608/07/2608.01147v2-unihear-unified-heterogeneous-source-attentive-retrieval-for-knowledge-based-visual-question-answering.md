## 摘要
基于知识的视觉问答（KB-VQA）需要从外部源检索实体知识以回答基于视觉的问题。现有的检索增强系统存在两个关键限制。第一，依赖单一检索模态会造成单源检索瓶颈，遗漏仅能通过互补源访问的真实实体。第二，双塔点式重排序器面临检索源盲重排序问题，因为它们忽略了检索来源和候选级检索先验，导致冗余的模态依赖。为了解决这些挑战，我们提出了UniHEAR，一个用于异构源实体检索和重排序的统一轻量级框架。UniHEAR为每个候选实体构建粗检索描述符，并引入检索引导的注意力模态门控，以根据该描述符调节模态注意力权重，并通过粗检索先验的熵加权源融合进行补充。一种结合对比学习与辅助模态保留损失的混合训练策略，在单一模型内统一了实体级和章节级检索。在E-VQA和InfoSeek上的大量实验表明，UniHEAR实现了最先进的检索和VQA性能，在Recall@1上比最强基线分别提高了6.7和1.2个百分点，同时保持了轻量级的重排序架构。代码和模型可在https://github.com/iven-luo/UniHEAR获取。

## Abstract
Knowledge-Based Visual Question Answering (KB-VQA) requires retrieving entity knowledge from external sources to answer visually grounded questions. Existing retrieval-augmented systems suffer from two critical limitations. First, relying on a single retrieval modality creates a Single-Source Retrieval Bottleneck, missing ground-truth entities that are only accessible through complementary sources. Second, dual-tower pointwise rerankers suffer from Retrieval-Source-Blind Reranking, as they overlook retrieval origins and candidate-level retrieval priors, leading to redundant modality reliance. To address these challenges, we propose UniHEAR, a unified lightweight framework for heterogeneous-source entity retrieval and reranking. UniHEAR constructs a Coarse Retrieval Descriptor for each candidate entity, and introduces Retrieval-Guided Attentive Modality Gating to condition modality attention weights on this descriptor, complemented by Entropy-Weighted Source Fusion of coarse retrieval priors. A hybrid training strategy combining contrastive learning with an auxiliary modality-preserving loss unifies entity-level and section-level retrieval within a single model. Extensive experiments on E-VQA and InfoSeek demonstrate that UniHEAR achieves state-of-the-art retrieval and VQA performance, improving Recall@1 by 6.7 and 1.2 points over the strongest baselines while maintaining a lightweight reranking architecture. Code and model are available at https://github.com/iven-luo/UniHEAR.

### 1. 论文的核心问题与整体含义

- **研究背景**：知识型视觉问答（KB-VQA）要求模型在理解图像的同时，从外部知识源（如维基百科）检索实体知识来回答超出视觉内容的问题。现有主流方案采用检索增强生成（RAG）的三阶段流程：粗检索→细粒度重排序→答案生成。
- **核心问题一：单一来源检索瓶颈（Single-Source Retrieval Bottleneck）**。当前系统通常只依赖单一检索模态，如仅做图像到图像（I2I）或仅做图像到文本（I2T）匹配。这两种模态行为差异显著：I2I偏向形态相似性，I2T偏向语义一致性，两者检索得到的候选集重叠度低。在有限的检索预算（如top-20）下，真实实体往往只被其中一个源捕获，导致单源检索天然不完整，严重限制了VQA准确率的上限。
- **核心问题二：检索源盲重排序（Retrieval-Source-Blind Reranking）**。现有的双塔点式重排序器在给候选打分时，对所有候选统一对待，忽略了候选来自哪个检索源，也忽略了粗检索阶段已经给出的排序、相似度等有价值信号。这导致对已被粗检索充分利用过的模态产生冗余依赖，降低了重排序的判别能力，甚至造成真实实体被错误排名。
- **整体意义**：论文旨在通过统一异构源检索与检索引导的重排序框架，同时解决上述两个瓶颈，为KB-VQA提供更高效、更准确的检索范式。

### 2. 论文提出的方法论

论文提出 **UniHEAR**（Unified Heterogeneous-Source Attentive Retrieval），一个统一轻量级框架，包含三个阶段，核心设计如下：

**阶段一：异构源粗粒度检索（Heterogeneous-Source Coarse-Grained Retrieval）**
- 同时使用CLIP视觉编码器对查询图像与两类库内容——实体图像和实体文章文本摘要——做相似度匹配，分别得到I2I候选集Cₖᵥ和I2T候选集Cₖₜ，取两者并集构成统一候选池，保证互补覆盖。
- 计算粗检索相似度: sim\_cˢ(e) = Eᵥ(I_q)·Eₛ(Kₛ) / (||Eᵥ(I_q)||·||Eₛ(Kₛ)||)，再利用Faiss索引进行近邻检索。
- 为每个源计算池级熵Hₛ（基于softmax归一化相似度），反映该源top-k检索分布的集中度，作为源的可靠性指标。
- **粗检索描述符（Coarse Retrieval Descriptor）D(e) ∈ R¹⁰**：将每个候选在两个源下的归一化排名rˢ、粗检索相似度simˢ、z归一化相似度zˢ、与第一名相似度差距δˢ以及池级熵Hₛ拼接而成，作为桥接粗检索与精细重排序的先验信息。

**阶段二：检索引导的多模态实体重排序（Retrieval-Guided Multimodal Entity Reranking）**
- 以VISTA为骨干，对查询编码得到多模态查询表示Qᵢₜ；对每个候选实体编码得到三模态表征Cᵢₜ、Cₜ、Cᵢ。
- **检索引导注意力模态门控（RAMG）**：将粗检索描述符D(e)通过线性变换获得仿射调制参数γ(D)和β(D)，对注意力logits进行缩放和平移，再去加权融合三模态表征，得到段级融合表示C̃ʰ。核心思想是让模型感知候选来源，抑制已被粗检索利用过的模态，避免冗余依赖。初始化时γ=1、β=0，保证训练初期与标准注意力一致。
- 实体重排序分数取所有段中的最大相似度：sim\_r(e) = maxₕ QᵢₜᵀC̃ʰ。
- **熵加权源融合（EWSF）**：以wˢ(e)=rˢ(e)/(Hₛ+ε)为权重，将两源粗检索分数加权融合，并通过池均值比R=μᵥ/μₜ校准文本源分数尺度，得到统一粗分数sim\_c(e)。最终的实体排序分数为 sim(e) = sim\_r(e) + sim\_c(e)，依据该分数排序后取top-kₑ实体用于生成。
- **混合训练策略**：主损失为对比损失L_con（学习判别性融合表示），辅助损失为模态保留损失L_aux（防止模态坍塌、保持段级跨模态匹配能力），并采用置信度掩码ωₘ过滤不可靠的正样本监督信号。总损失为 L = L_con + λ·L_aux。

**阶段三：多实体段落增强生成（Multi-Entity Section-Augmented Generation）**
- 对每个重排序后的实体，综合段级IT2T相似度与实体级重排序分数（调节系数α=0.2）计算段分数。
- 按实体排名分配段落配额（第i个实体分配kₛ-i+1个段落），将选出的段落上下文输入MLLM以生成最终答案。

- RAMG仅增加0.3%参数即可获得显著收益，验证了轻量级架构下注入检索先验的高效性。

### 7. 优点

- **问题定义清晰**：精准指出两个关键瓶颈（单源检索瓶颈和检索源盲重排序），并用数据（oracle上限对比）支撑论点。
- **方法设计巧妙**：粗检索描述符作为先验桥接大规模粗检索器与轻量重排序器，概念简洁而有效；RAMG通过仿射调制让模态注意力感知来源，具有较好的可解释性。
- **轻量高效**：以197M参数（远小于1.2B+的BLIP-2系模型）达到更优性能，RAMG仅增加0.59M参数，在效率和性能之间取得良好平衡。
- **统一框架**：在单一模型内同时完成实体级和段落级检索，省去外部独立段落重排序器（如OMGM依赖的bge-reranker），更实用。
- **实验严谨**：包含编码器公平性分析、候选池匹配分析、大量超参数研究和失败案例分析，体现了较高的研究规范性。

### 8. 不足与局限

- **EWSF的固有限制**：熵加权源融合是无监督、无学习的固定权重方案，对极端源置信度失衡敏感。案例研究中显示，当某一源（如I2I）对错误实体表现出极端高置信度集中时，会压制另一源中正确候选的证据，导致真实实体排名大幅下降。论文也承认学习式源可靠性估计是未来改进方向。
- **实验覆盖有限**：仅在两个基准上验证（E-VQA和InfoSeek），未在更广泛的KB-VQA基准上测试；生成实验主要基于Qwen系列和LLaMA，泛化性有待进一步验证。
- **上下文噪声问题**：多实体段落分配策略虽然有效，但随着kₑ增大，传给生成器的噪声上下文也随之增多，存在引入干扰的可能；对段落选择质量没有额外的去噪机制。
- **训练数据依赖**：InfoSeek缺少段落级标注，需用jina-reranker-v3自动标注段落，引入了额外的标注噪声；辅助损失中的掩码机制虽然过滤了不可靠视觉正样本，但可能丢弃部分有效监督信号。
- **复现细节部分缺失**：论文未完整报告总训练轮数、精确的总GPU时间、推理显存占用等资源指标，影响完全复现的便利性。
