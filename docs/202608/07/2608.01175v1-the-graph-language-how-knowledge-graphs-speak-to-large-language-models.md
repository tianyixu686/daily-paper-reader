## 摘要
大型语言模型（LLMs）擅长推理，但受益于知识图谱（KGs）提供的 grounding。然而，整合这两种范式颇具挑战。我们提出 GRALAN，它通过保留图结构的 relation tokens，使知识图谱能够直接在 LLM 的语义空间中表达。GRALAN 的可训练语言中介为任何冻结的 LLM 生成结构化 tokens，为知识密集型应用奠定基础。我们通过将任务重新定义为基于问题聚焦子图的实体分类，展示了其在问答中的有效性。实验表明，GRALAN 显著优于现有方法，尤其是在复杂的多跳推理任务上，为 KG-LLM 集成建立了新范式，在利用 LLM 推理能力的同时保持了结构保真度。

## Abstract
Large Language Models (LLMs) excel at reasoning but benefit from grounding provided by Knowledge Graphs (KGs). However, integrating these paradigms is challenging. We introduce GRALAN, which enables KGs to speak directly in the LLM's semantic space through relational tokens that preserve graph structure. GRALAN-s trainable language mediator generates structured tokens for any frozen LLM, creating a foundation for knowledge-intensive applications. We demonstrate its effectiveness in question-answering by re-framing the task as entity classification over question-focused subgraphs. Experiments show that GRALAN significantly outperforms existing methods, particularly on complex multi-hop reasoning tasks, establishing a new paradigm for KG-LLM integration that maintains structural fidelity while leveraging LLMs' reasoning capabilities.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心矛盾**：大型语言模型（LLM）虽然在语言理解和推理方面表现卓越，但存在**幻觉问题**和**事实不一致**的缺陷；知识图谱（KG）则能提供精确、结构化的事实知识，但其符号化的知识表示方式与 LLM 的神经语义空间之间存在根本性的**语义鸿沟**。
- **现有方法的不足**：
  - **结构化信息损失**：如同通过扁平化（flattening）或序列化（serialization）将 KG 转成文本，会破坏图结构的高阶关系。
  - **微调代价过高**：联合预训练或全量微调（如 JAKET）计算成本高，并存在灾难性遗忘风险。
  - **缺乏语义对齐**：已有方法如 GraphToken、GraphLLM 仅做局部编码或固定模板注入，未能在 LLM 的语义空间中真正保留图的异构关系结构。
  - **Scope 受限**：部分方法（如 GNP、Q-KGR）仅适用于选择题场景，图检索方法（如 G-Retriever）依赖固定的双路径序列化策略。
- **提出的范式转变**：论文认为应实现 KG 与 LLM 的**语义对齐（semantic alignment）**，而非结构性转换（structural transformation）。核心问题变为：**如何让知识图谱“用 LLM 的语言说话”？** ——通过可训练的“语言中介”（Graph Language Mediator）将图结构编码为关系令牌（relational tokens），直接注入冻结 LLM 的语义空间。

## 2. 方法论：GRALAN 框架

### 2.1 核心思想

GRALAN 将 KG-LLM 集成理解为**语义对齐问题**：通过训练一个中介模块，将 KG 子图转换为 LLM 可直接理解的结构化嵌入序列，同时不修改 LLM 的任何参数（冻结）。在问答任务中，将 QA 重构为**基于问题聚焦子图的实体分类问题**。

### 2.2 三大模块

**（1）任务聚焦子图提取器（Task-Focused Subgraph Extractor）**
- **两阶段流程**：
  1. **问题分析（Question Analysis）**：通过 LLM 或 NER 将自然语言问题 Q 映射为种子实体集 `E_seed` 和相关谓词集 `P_rel`，即 `Map(Q) = (E_seed, P_rel)`。
  2. **问题聚焦广度优先搜索（Question-Focused BFS）**：与普通 BFS 不同，其边扩展优先级由关系相似度函数 `sim(r, p)`（如 TF-IDF 关系相关度矩阵）决定，只扩展与问题中最相关关系对齐的边，并可通过阈值 θ 控制噪声。支持多路并行 BFS 再合并。

**（2）图语言中介（Graph Language Mediator）** ——关键创新
- **图编码器（Graph Encoder）**：使用 RGCN/RGAT 对子图进行 L 层消息传递，生成节点嵌入 H 和关系嵌入 R；通过注意力池化得到全局子图嵌入 `z_graph`（公式 1–3）。
- **问题编码（Question Encoding）**：通过 LLM 的嵌入层将问题 Q 转换为嵌入 `E_Q`（公式 4）。
- **语义对齐（Semantic Alignment）**：
  - **关系感知节点交互**：通过注意力机制捕获连接节点在问题语义下的相关性（公式 5）。
  - **问题空间投影（Question Space Projection）**：通过交叉注意力（cross-attention）将节点-关系对投射到问题的语义空间，再经残差和前馈网络得到融合最终表示（公式 6–10）。
- **LLM 输入序列构建**：使用特殊分隔符令牌组装：
  `X_LLM = [e[GRAPH]; z_graph; e[NODES]; z_top-K; e[QUESTION]; E_Q; e[ANSWER]]`
  其中 z_top-K 是挑选的与问题最相关的 top-K 节点嵌入。

**（3）基于 LLM 的推理（LLM-Based Reasoning）**
- 冻结的 LLM 处理输入序列，提取 `[ANSWER]` 位置的隐藏状态 `h_answer`，经分类层映射为子图各实体的概率，以 argmax 选择答案实体（公式 12–15）。

## 6. 主要结论与发现

1. **GRALAN 在开放域多跳问答上全面领先**：
   - PQ 系列：2-hop 达 98.9%（较 G-Retriever +2.1%），PQL-3h 达 86.6%（较 JAKET 提升 19 个百分点）。
   - MetaQA：2-hop 与 3-hop 均达 100%（并列最佳）。
   - 相较于 G-Retriever 和 JAKET，在多数分割上均有显著优势。
2. **优于 LLM 迭代推理方法**：GRALAN 用 FLAN-T5-XXL 超过了 ToG+GPT-4（ZeroShotRE: 89.45 vs 88.3；ComplexWebQuestions: 70.23 vs 67.6），表明结构化的语义对齐优于迭代探索。
3. **多项选择问答达 SOTA**：平均准确率 85.26%，略超 LoRA+Q-KGR（85.21%），在 ARC（80.56%）和 Riddle（81.03%）上取得最佳。
4. **设计原则验证**：
   - 子图提取阈值约 0.7 最佳；
   - BFS 深度 3 最优（过深反而下降）；
   - 混合预测策略（分类 + LLM 推理）优于纯 LLM 或纯分类方法，在 PQL-3h 上有 5% 增益；
   - λcls 在 0.5–0.7 为最佳平衡；
   - 较大 LLM 效果更好，但小模型也能保持竞争力。
5. **提出新范式**：KG-LLM 集成应从“适配”转向“对齐”，图语言中介（Graph Language Mediator）是可行路径。

## 7. 优点与亮点

- **核心思想创新**：从“把图转成文字/模板”转向“让图直接说 LLM 的语言”，以语义对齐为核心，概念上更根本。
- **结构保真度**：通过 GNN 编码保留图的结构关系，不依赖序列化压缩，避免了信息损失。
- **参数高效**：LLM 完全冻结，训练仅涉及图编码器与分类层，规避灾难性遗忘，计算开销远低于联合预训练/全量微调。
- **问题重构巧妙**：将 QA 转为子图上的实体分类，绕开 LLM 词汇表限制，可扩展到大型 KG。
- **可解释性**：基于相关性的子图提取和 top-K 节点选择提供了可追溯的推理路径。
- **实验系统性强**：覆盖多种数据集、多条推理深度和多类基线，消融实验验证关键设计决策。
- **灵活性**：框架不限于 QA，可推广至推荐、知识发现等多模态推理场景。
