## 摘要
视觉-语言大模型（VLLMs）在 AI 生成图像（AIGI）检测中具有前景，因为它们既能产生预测，又能输出自然语言。然而，现有大多数基于 VLLM 的检测器主要微调语言侧，而对低级视觉取证线索关注有限。它们还常常依赖手工设计的提示或人工标注的推理过程，这限制了可扩展性。我们提出了 UC-VLM，一个仅依赖二元监督的统一多阶段 AIGI 检测框架。UC-VLM 首先自动识别有效的指令变体。然后，它在多阶段训练框架中复用同一个二元标签：（i）视觉判别目标，增强对非语义取证线索的敏感性；（ii）标签条件生成目标，使用二元标签监督文本输出。这种设计将弱二元监督转化为视觉通路和语言输出共享的监督信号。我们的关键创新在于一个统一的多阶段二元监督框架，该框架一致地复用相同的真实性标签进行视觉适应和标签条件文本生成，同时利用自动优化的指令来减少对提示的敏感性，而无需人工编写的推理过程或手工设计的提示。实验表明，UC-VLM 在 GenImage 上达到 96.1% 的平均准确率，超过最强先前结果 4.6%；在 Chameleon 上，在 ProGAN / SDV1.4 训练下分别达到 69.6% / 77.9% 的准确率，超过最佳基线 11.2% / 15.3%。

## Abstract
Vision-Language Large Models (VLLMs) are promising for AI-generated image (AIGI) detection because they can produce both a prediction and a natural-language output. However, most existing VLLM-based detectors primarily fine-tune the language side while giving limited attention to low-level visual forensic cues. They also often depend on manually crafted prompts or human-annotated rationales, which limits scalability.We present UC-VLM, a unified multi-stage framework for AIGI detection that relies solely on binary supervision. UC-VLM first identifies effective instruction variants automatically. It then reuses the same binary label within a multi-stage training framework: (i) a visual discrimination objective that strengthens sensitivity to non-semantic forensic cues, and (ii) a label-conditioned generation objective that uses the binary label to supervise textual outputs. This design turns weak binary supervision into a shared supervision signal for both the visual pathway and the language output. Our key novelty is a unified multi-stage binary-supervised framework that consistently reuses the same authenticity labels for visual adaptation and label-conditioned text generation, while leveraging automatically optimized instructions to reduce prompt sensitivity without requiring human-written rationales or hand-crafted prompts.Experiments show that UC-VLM achieves 96.1% average accuracy on GenImage, exceeding the strongest prior result by 4.6%, and obtains 69.6% / 77.9% accuracy on Chameleon under ProGAN / SDV1.4 training, surpassing the best baseline by 11.2% / 15.3%, respectively.

### 一、核心问题与研究动机

- **背景**：生成式AI的快速发展使合成图像达到了高度逼真的水平，给数字媒体真实性带来严重威胁，AIGI（AI-Generated Image）检测成为重要研究课题。
- **现有方法局限**：
  - **传统分类器**（如CNNSpot、DIRE等）虽然能取得较好的基准准确率，但仅输出二分类标签，缺乏可解释性，且泛化能力有限。
  - **现有VLLM检测器**（如FakeVLM、FakeReasoning等）可以同时输出预测和自然语言解释，但存在三大问题：①主要微调语言侧，对低级非语义取证线索（频率伪影、局部纹理等）关注不足；②依赖人工设计的提示词（prompt）；③依赖人工标注的推理文本（rationales），限制了可扩展性。
- **核心研究问题**：如何仅使用二元真假标签（binary supervision），统一训练VLLM的视觉通路和语言输出，实现准确且鲁棒的AIGI检测，同时避免人工提示词和人工推理标注的依赖？

### 二、方法论：UC-VLM 统一多阶段框架

#### 核心思想
将单一的二元真实性标签扩展为“共享监督信号”，在多阶段训练中一致复用于三个互补的学习目标：
- 视觉判别（visual discrimination）
- 指令优化（instruction optimization）
- 标签条件生成（label-conditioned generation）

总训练目标：  
\[
\mathcal{L} = \mathcal{L}_{vis} + \mathcal{L}_{text}
\]

#### 1. 视觉适应（Visual Adaptation）
- **目标**：增强视觉编码器对局部非语义取证线索的敏感性，抑制对全局语义的依赖。
- **技术手段**：
  - **随机裁剪**：从输入图像中裁取小块区域（尺寸为原图的1/8～1/4），限制对全局场景语义的访问，保留细粒度纹理。
  - **补丁打乱（Patch Shuffle）**：将裁剪图像划分为N个非重叠补丁并随机重排空间顺序，破坏全局空间连贯性，迫使模型依赖局部纹理和结构不规律性。
- **损失函数**：对视觉路径用二元交叉熵（BCE）进行优化。

#### 2. 指令优化（Instruction Optimization）
- **动机**：实验表明，提示措辞对VLLM检测性能有显著影响（如将"Authentic/Generated"换为"Real/Fake"可提升准确率；增加结构化步骤引导可进一步提升）。
- **方法**（Algorithm 1）：
  - 以基础模板为起点，利用LLM（GPT-4o）生成N个候选指令，构建初始指令池；
  - 在验证集上评估每个指令的检测准确率，保留Top-k；
  - 从保留指令中随机选择父指令，用LLM进行改写（semantic rewriting）或修改（reasoning-expression modification），生成子指令；
  - 更新指令池并迭代M轮；
  - 最终选择准确率最高的指令作为Prompt-B，用于后续训练和推理。
- **意义**：在无需人工设计提示的情况下自动发现有效且相对稳定的指令表述，降低对提示措辞的敏感性。

#### 3. 标签条件再生（Label-Conditioned Regeneration）
- **目标**：在无人工推理标注的情况下，用二元标签监督语言侧的输出。
- **流程**：
  1. 使用优化后的指令对每个图像产生预测和文本输出；
  2. 若预测正确，保留原生成文本；
  3. 若预测错误，在提示前添加正确标签的引导前缀（label directive），重新生成文本；
  4. 构建再生数据集 \(\mathcal{D}_{regen}\)，冻结视觉编码器，用自回归目标微调语言模块。
- **重要声明**：生成的推理文本**不保证忠实于图像证据**，可能存在幻觉，仅作为辅助训练信号用于稳定检测输出，不作为已核实的解释。

### 六、主要结论与发现

1. **统一二值监督有效**：将同一真实性标签一致复用于视觉适应、指令优化和语言生成，显著优于单独优化任一组件或朴素联合微调；
2. **VLLM检测性能受提示措辞影响显著**：自动指令优化可有效降低这种敏感性，提升稳定性；
3. **视觉通路需显式增强取证敏感性**：随机裁剪+补丁打乱是对抗语义依赖、关注局部伪影的有效手段；
4. **语言侧输出可在无人工标注下获得监督**：标签条件再生机制将二元标签转化为文本生成的有监督信号；
5. **性能提升显著**：在GenImage和Chameleon上均大幅超越此前SOTA。

### 七、方法优点

- **无需人工标注理由**：彻底摆脱了对人工编写推理文本的依赖，大幅提高可扩展性；
- **无需手工设计提示**：利用LLM自动搜索和优化指令，降低了人工提示工程的成本和对特定提示的过拟合；
- **视觉与语言的统一优化**：不是简单地将视觉和语言模块拼接微调，而是通过同一监督信号实现协同一体化学习；
- **随机裁剪+补丁打乱设计精妙**：低成本、有效地引导视觉编码器关注低级取证痕迹；
- **消融设计完整**：逐组件验证，证明了整体框架中各部分互补的必要性；
- **跨生成器泛化能力强**：Chameleon数据集上的显著提升说明方法在分布外场景下具有较强的泛化能力。

### 八、不足与局限

1. **文本解释的可靠性存疑**：论文明确承认生成的推理文本可能涉及幻觉，不保证忠实于图像证据，这限制了其作为可解释性工具的可信度；
2. **艺术/风格化图像判断不稳定**：失败案例表明模型仍可能混淆“艺术风格”与“真实性”，对非摄影类图像缺乏鲁棒性；
3. **对高度逼真图像的检测仍有限**：当生成图像的伪影非常细微时，模型可能漏检；
4. **训练效率与可扩展性**：基于7B参数模型的多阶段训练（视觉LoRA+语言LoRA）虽有LoRA减负，但仍需A100级别硬件，部署和训练成本相对传统分类器更高；
5. **推理开销**：VLLM推断过程远慢于传统单前向分类器，不适用于实时或资源受限的场景；
6. **实验覆盖偏窄**：未测试除Qwen2.5-VL外的其他VLLM backbone；Chameleon的消融只覆盖了SDV1.4协议；未对生成文本质量进行定量评估；
7. **潜在的评估偏差**：动态指令优化过程在验证集上选择最佳提示，可能带来一定的验证集选择偏差风险；
8. **应用限制**：模型主要测试于图像域，未覆盖视频帧、社交媒体压缩后图像、对抗性扰动等更贴近实际部署的场景。

### 九、总结
UC-VLM提出了一个优雅的统一多阶段框架，通过复用二元真实性标签，将视觉取证、指令鲁棒性和语言生成三种能力整合到同一训练过程中，在极大简化标注需求的同时取得了显著的性能突破。其核心价值在于将“弱监督”有效转化为“多用途的共享监督信号”，为VLLM在AIGI检测中的应用提供了新的范式。然而，其文本解释的可靠性、艺术图像的鲁棒性以及计算开销仍需进一步改进。
