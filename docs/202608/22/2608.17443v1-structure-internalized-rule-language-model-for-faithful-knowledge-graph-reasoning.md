## 摘要
知识图谱推理（KGR）旨在利用知识图谱中可用的结构证据来发现潜在事实，这对KGR模型的结构语义理解能力提出了挑战。近期研究表明，大语言模型（LLMs）通过灵活的上下文学习在KGR任务上取得了显著进展。然而，KG结构上下文与LLM参数知识之间固有的表示不一致性仍未得到充分解决。这一局限性阻碍了LLMs有效感知符合KG约束的推理证据，从而削弱了推理的有效性和忠实性。我们将这一问题称为LLMs在KG上的推理证据感知漂移。为解决这一问题，我们提出了一种结构内化规则语言模型（SIRLM），其核心是结构规则生成，将结构知识的参数化学习与推理逻辑的忠实性评估相结合，使LLMs能够紧密锚定于基于KG的证据。具体而言，我们首先设计了一个结构内化规则生成器（SIRG），它包含一个通过结构关系记忆增强的上下文学习模块，以协调结构知识和参数知识。此外，我们为SIRG配备了基于结构不变性学习的KG分词器和基于规则约束消息传播的神经符号推理器。这些组件分别向SIRG提供可学习的结构表示和忠实的规则执行反馈。我们的SIRLM可以无缝集成到标准的LLM训练范式中，如SFT和GRPO。在36个数据集上与17种最先进的KGR方法进行的大量实验证明了SIRLM的显著优越性。

## Abstract
Knowledge Graph Reasoning (KGR) aims to discover latent facts by leveraging the structural evidence available in KGs, posing a challenge to the structural semantic understanding capability of KGR models. Recent studies have demonstrated that Large Language Models (LLMs) can achieve remarkable progress on KGR tasks via flexible in-context learning. However, the inherent representation inconsistency between KG structural context and LLM parametric knowledge remains inadequately addressed. This limitation prevents LLMs from effectively perceiving reasoning evidence that aligns with KG constraints, which undermines both the effectiveness and faithfulness of reasoning. We refer to this problem as reasoning evidence perception drift of LLMs over KGs. To address this problem, we propose a Structure-Internalized Rule Language Model (SIRLM), which centers on structural rule generation to couple the parametric learning of structural knowledge with the faithfulness evaluation of reasoning logic, enabling LLMs to anchor tightly to KG-grounded evidence. Specifically, we first design a Structure-Internalized Rule Generator (SIRG), which incorporates an in-context learning block augmented with a structural relation memory to coordinate structural and parametric knowledge. Furthermore, we equip SIRG with a KG tokenizer based on structural invariance learning and a neuro-symbolic reasoner based on rule-constrained message propagation. These components provide SIRG with learnable structural representations and faithful rule-execution feedback, respectively. Our SIRLM can be seamlessly integrated into standard LLM training paradigms, such as SFT and GRPO. Extensive experiments against 17 state-of-the-art KGR methods on 36 datasets demonstrate the significant superiority of SIRLM.

- **核心问题**：LLM 的**参数知识与 KG 结构上下文之间存在表示不一致性**。LLM 倾向于根据预训练语义偏好选择推理证据，而非严格遵循 KG 结构约束，导致推理逻辑"看似合理但无法在 KG 中落地"，即推理有效性与忠实性双双下降。作者将此问题定义为 **"LLM 在 KG 上的推理证据感知漂移"（reasoning evidence perception drift）**。
  - 具体表现：LLM 偏好带自然语言语义的路径（如"同一发行公司→相同发行地区"），而忽视KG中可显式归纳的匿名化结构规则（如 `release_region(X,Y) = language(X,Z) ∧ speak_in(X,Z)`），甚至会刻意忽略匿名标识符（如 P530）对应的潜在有效证据。
- **研究动机**：需要一个机制让 LLM 生成的推理逻辑能够**紧密锚定于 KG 可验证的证据**，将结构知识学习与推理逻辑的忠实性评估耦合起来。

### 2. 论文提出的方法论

**核心思想**：提出 **SIRLM（Structure-Internalized Rule Language Model，结构内化规则语言模型）**，以**结构化规则生成**为核心枢纽，将 LLM 的参数化知识学习与基于 KG 的忠实规则执行反馈相结合。SIRLM 由三大部分组成：

| 模块 | 作用 | 关键技术 |
|---|---|---|
| **KG Tokenizer（基于SIL）** | 将 KG 实体与关系编码为通用结构表示，作为 LLM 可感知的新 token | 结构不变性学习（SIL）：在关系图 Gr 与原始 KG 上运行 NBFNet，得到关系表示 R\|q 与实体表示 E\|h；Tokenizer 表达为 `TKNRG = [TKNLLM : TKNKG]`，`TKNKG = fup([rend : E|h : R|q])`，其中预训练 TKNLLM 冻结、TKNKG 可训练 |
| **SIRG（结构内化规则生成器）** | 基于 SRM 机制生成可执行的结构化规则 | ① **结构关系记忆（SRM）**：按相关性选出 Top-K 关系作为记忆 Rmem，注入注意力层：`InCon(xi, Rmem, X≤i) = FFN(softmax(fQ(xi)[fK(X≤i):mK(Rmem)]^T/√F)[fV(X≤i):mV(Rmem)])`；② **下一关系自回归预测**：`PΘ(r|hL) = fΘ(hL‖r)`，逐个生成关系 token 直至 `<END>`，得到规则体 ρ |
| **神经符号推理器（RCMP）** | 执行生成的规则并反馈规则忠实性度量 | 规则约束消息传播（RCMP）：将规则路径的隐状态作为额外初始化信号注入关系图 NBFNet：`R̂|q = NBFNet({<rq,1d>} ∪ {<rz, fdown(hL+z)>}^ε_{z=1}, R̂*)`，随后计算实体表示与候选得分 s(i)_RCMP |

**训练范式**：SIRLM 可无缝集成到标准 LLM 训练框架：
- **SFT/预训练损失**：联合优化规则 token 生成概率、KG 打分（s_KG）与 RCMP 打分（s_RCMP），并纳入负样本约束。
- **GRPO 后训练**：采样 M 条规则，以规则执行后目标实体的得分排名作为奖励，计算组内相对优势 A(m)，并加入 KL 散度约束。此时 RCMP 作为固定评估器不参与参数更新。

### 7. 论文的局限性与可改进方向

- **计算资源依赖**：尽管比 KRLM 更省显存，SIRLM 仍需 4× A100 进行预训练，且 NBFNet/SIL 打分模块与 LLM 的联合训练对算力要求较高，不利于小规模研究团队复现。
- **消融实验覆盖不足**：消融仅在 PT 模式下进行，未对 E2E、SFT、GRPO 三种训练模式下的组件贡献分别消融，无法判断模块重要性是否随训练范式变化。
- **基线对比不完整**：部分 LLM 基线（如 KICGPT、LSA、KG-FIT、FtG）在归纳场景下原始结果缺失，表格中以“—”处理；对于无法复现的基线，缺少公平的重新实现或近似对比，可能高估 SIRLM 的相对优势。
- **关系语义先验依赖**：SIL 的 NBFNet 运行仍以关系图结构为输入，在关系语义极度稀疏或完全不可见的场景下，结构内化的上限可能受限；对开放世界 KG（动态实体/关系持续增长）的适应能力未作讨论。
- **可解释性分析偏定性**：规则生成的案例研究仅展示 6 个示例，缺少对规则质量（如置信度、支持度、覆盖率）的系统性量化评估，也未与经典规则学习方法的规则质量指标（如标准置信度、PCA 置信度）直接对比。

### 8. 综合评价与个人学术判断

- **贡献层面**：这是将 LLM 结构感知能力与 KG 推理忠实性进行系统性耦合的代表性工作。其核心贡献不仅在于提出 SIRLM 这一具体模型，更在于首次明确定义并刻画了“推理证据感知漂移”问题，并给出“结构内化—规则生成—符号执行”的闭环求解框架，为后续研究提供了新的问题视角。
- **方法层面**：SIRLM 的设计具备较高的工程与学术创新性——KG Tokenizer 实现了结构表示向 LLM 语义空间的软对齐，SRM 提供了可控的结构记忆注入，RCMP 则把规则执行结果作为可微训练信号回传，形成端到端可训练的神经符号系统。但另一方面，整体框架复杂度较高，多个模块的耦合也使得归因分析（究竟是哪个模块贡献了性能增益）变得困难。
- **实验层面**：36 个数据集、17 种基线、4 种训练模式的评估矩阵在同类工作中属于较高水准，结论可信度较强。尤其是归纳场景（FullInd）上的显著领先，说明该方法真正解决了跨 KG 泛化这一核心痛点，而非仅仅在熟悉结构上做拟合。
- **实用价值层面**：SIRLM 生成的规则具有可读性与可执行性，适用于需要可解释决策的 KGQA、推荐系统等应用场景；但资源开销限制了其在轻量级工业场景下的即时部署，未来可探索模型蒸馏或轻量化的 SIL 编码器。
- **总体定位**：一篇方法完整、实验扎实、理论有据的高质量论文。它最大的贡献是将 LLM 从“语义记忆器”转化为“结构感知推理器”，为 LLM 与知识图谱的深度结合提供了一个值得长期跟踪的研究基线。
