## 摘要
视觉-语言-行动（VLA）模型处理长的多模态令牌序列，使得推理在内存和计算上都很昂贵。现有的高效方法主要减少视觉令牌，但激进的令牌剪枝变得脆弱，因为移除一个令牌会丢弃其整个表示。子令牌压缩提供了一种互补的替代方案，通过保留更多令牌同时减少其值宽度。然而，直接将子令牌压缩应用于VLA策略效果较差，因为对感知、语言理解和控制重要的信息在多模态表示中的分布不同。我们引入了角色条件子令牌路由（RoleSub），它学习如何压缩保留令牌的值表示。在视觉令牌缩减后，RoleSub将每个保留的值表示在正交空间中划分为组，并使用轻量级路由器确定应保留哪些组。路由决策基于令牌表示、学习到的潜在角色表示和语言上下文。同样的机制也可以应用于语言值，使得视觉和语言表示可以在不移除额外令牌的情况下被压缩。我们在四个LIBERO套件上评估了OpenVLA-OFT-7B上的RoleSub。在匹配的视觉KV预算下，RoleSub在36个设置中的33个中优于训练过的仅令牌控制方法，在激进压缩下增益最大。结合视觉和语言压缩，总KV减少到原始的9.2%–11.3%，同时在大多数任务上保持强大的控制性能。这些结果表明，减少保留令牌内的表示为令牌剪枝提供了有效的补充，以实现激进的VLA压缩。

## Abstract
Vision-Language-Action (VLA) models process long multimodal token sequences, making inference expensive in both memory and computation. Existing efficiency methods mainly reduce visual tokens, but aggressive token pruning becomes fragile because removing a token discards its entire representation. Sub-token compression provides a complementary alternative by retaining more tokens while reducing their value width. However, directly applying sub-token compression to VLA policies is less effective because information important for perception, language understanding, and control is distributed differently across the multimodal representation.   We introduce Role-Conditioned Sub-Token Routing (RoleSub), which learns how to compress the value representations of retained tokens. After visual token reduction, RoleSub partitions each retained value representation into groups in an orthogonal space and uses a lightweight router to determine which groups should be preserved. The routing decision is conditioned on the token representation, a learned latent role representation, and language context. The same mechanism can also be applied to language values, allowing visual and language representations to be compressed without removing additional tokens.   We evaluate RoleSub on OpenVLA-OFT-7B across the four LIBERO suites. At matched visual-KV budgets, RoleSub outperforms a trained token-only control in 33 of 36 settings, with the largest gains under aggressive compression. Combining visual and language compression reduces total KV to 9.2--11.3% of the original while retaining strong control performance on most tasks. These results show that reducing the representation within retained tokens provides an effective complement to token pruning for aggressive VLA compression.

## 1. 核心问题与研究动机
- **背景**：视觉-语言-行动（VLA）模型将视觉观测、自然语言指令和机器人状态联合处理并生成动作，但在每个控制步都需要处理很长的多模态 Transformer 上下文，其中视觉 token 占主导，导致推理在**内存和计算上都非常昂贵**，限制实际部署。
- **现有方法的不足**：已有 VLA 加速方法（如 VLA-ADP、VLA-Pruner）主要做**视觉 token 级剪枝**，压缩单元是整个 token，一旦删除该 token，其携带的全部信息（目标定位、几何关系、操作线索等）都会丢失。在激进压缩下，这种"全有或全无"的粒度尤其脆弱；在闭环控制中，压缩误差还会沿轨迹累积传播，影响后续决策。
- **核心问题**：能否在保留更多 token 位置的同时，对每个保留 token 内部的**值（value）表示**进行压缩，从而在 token 剪枝之外开辟一条互补的压缩维度？但直接将通用子 token 压缩搬到 VLA 上效果很差（均匀 S=4, K=1 路由在 LIBERO-Spatial 上仅 43.8% 成功率），因为感知、语言理解与控制所需信息在多模态表示中的分布并不相同。

## 2. 方法论（RoleSub）
- **总体思想**：RoleSub 将压缩分为两个正交维度：
  1. **Token 级缩减**——决定哪些 token 状态被保留；
  2. **子 token 路由**——决定每个保留 token 的值表示中保留多少信息。
- **Token 级缩减**：对每种 token 类型（视觉、语言、本体感觉、动作上下文），用选择函数 ψ_m 计算重要性分数，按保留比例 r_m 保留最高分的 ⌈r_m|I_m|⌉ 个 token；视觉 token 缩减采用了 VLA-ADP 的 QK 重要性选择机制。
- **正交值空间分解**：
  - 对每层使用固定的正交矩阵 R^(ℓ)（dv×dv，冻结不训练），将值向量 v 无损变换到正交路由空间：z = R^T v；
  - 将 z 划分为 S=16 个不重叠的组（每组 256 维）；
  - 用组级掩码 M 选择保留的组，再变换回原始值空间：ẽv = R M R^T v；
  - 正交变换本身无损，信息只在组选择时被丢弃；组不预设语义，而是为路由提供结构化空间。
- **潜在角色表示（Latent Role Representation）**：轻量角色估计器 f_role 从 token 隐状态输出软表示 a = softmax(f_role(h)) ∈ R^C（C=6），token 可同时参与多个潜在角色分量；角色组织方式**由控制目标联合学习**，不要求对应预定义的语义角色。
- **角色条件值路由**：每个组的保留分数由三部分信号相加：
  - token 状态评分头 γ_token = f_v(h_i)；
  - 角色投影 γ_role = W_role·a_i；
  - 语言上下文 γ_lang（保留语言 token 隐状态池化后经 f_lang 映射）；
  - 最终得分 γ = γ_token + 0.1·γ_role + 0.1·γ_lang（α_role=α_lang=0.1）；
  - 按 Top-K 选择保留组，训练时使用直通估计器（straight-through estimator）处理离散选择。
- **Token 类型相关预算**：不同类型 token 可分配不同平均组预算 K_m；通过角色优先级将总预算 B_m = K_m·|I_keep| 在 token 间自适应再分配（0 ≤ K_i ≤ S，总和保持 B_m）。
- **训练方式**：冻结预训练 VLA backbone，联合训练 LoRA 适配器（rank=32，scaling=16）、路由函数和角色估计器，优化目标为动作 chunk 的 L1 回归损失。

## 6. 主要结论与发现
- **主结果**：在匹配视觉 KV 预算下，RoleSub 在 36 组设置中 **33 组优于训练 token-only 剪枝**，优势在激进压缩（8 个视觉 token）和长时程任务（LIBERO-10）上最大。
- **角色条件路由有效**：在 8 个视觉 token 的极端预算下，RoleSub 将 LIBERO-10 从 plain 路由的 59.8% 提升到 74.2%（+14.4 点），说明"值容量如何分配"比"保留多少值"更重要。
- **语言 token 删除 vs 值压缩的强不对称性**：语言 token 是"位置敏感"的——剪掉 47% 的指令 token 后成功率跌至约 40%；但保留全部语言 token、把每个值压缩到 16 组中的 1 组（K_lang=1）时性能几乎无损，说明语言 token 位置关键、值宽度冗余度高。
- **联合压缩可行但存在跨模态耦合**：视觉+语言联合压缩可将总 KV 降至原始的 **9.2%–11.3%**，Object/Spatial 几乎不损失，Goal 损失较小；但 LIBERO-10 对联合压缩显著敏感（较 visual-only 下降约 10–11 点）。
- **模态间存在互补依赖**：视觉信息越少，语言值预算越重要（8 个视觉 token 时，K_lang 从 8 增至 16 带来 68.4→83.6 的跳跃）；RoleSub 当前未显式建模这种耦合。

## 7. 优点
- **角度新颖**：在 token 剪枝之外引入"值宽度压缩"这一互补维度，为 VLA 高效化提供新思路。
- **方法设计精细**：正交矩阵保证无损变换、潜在角色表示无需预设语义、预算可按 token 类型独立配置，且路由结构可端到端学习。
- **基线设置公平**：构造了匹配 KV 预算的训练 token-only 和 plain 子 token 路由两种控制，能清晰分离各组件贡献，避免了"训练 vs 压缩"的混淆。
- **实验观察深入**：发现语言 token 删除与值压缩之间的不对称性、视觉-语言预算的交互效应，具有较高的启发性。
