## 摘要
近期多模态检索增强生成（mRAG）的进展——通过外部知识增强多模态大语言模型（MLLM）——表明，通过有效通信，多个智能体的集体智能可以优于单个模型。尽管性能强劲，现有智能体系统却带来大量Token开销和计算成本，对大规模部署构成挑战。为解决这些问题，我们提出一种多模态多智能体分层通信图剪枝框架，称为M3Prune。M3Prune在模态内部和跨模态之间消除冗余通信边，改善任务性能与Token开销之间的权衡。具体而言，M3Prune首先在文本和视觉模态中进行模态内图稀疏化，以识别任务关键的通信链路。然后构建跨模态通信图，并在通过模态对齐分数促进一致的跨模态推理的同时，对跨模态连接进行稀疏化。最后，逐步剪枝冗余边以获得高效的分层拓扑。在通用领域和特定领域mRAG基准上的大量实验表明，M3Prune在显著提高Token效率的同时，一致优于单智能体和强多智能体mRAG系统。

## Abstract
Recent advances in multi-modal retrieval-augmented generation (mRAG), which augments multi-modal large language models (MLLMs) with external knowledge, have shown that collective intelligence from multiple agents can outperform a single model through effective communication. Despite their strong performance, existing multi-agent systems incur substantial token overhead and computational cost, posing challenges for large-scale deployment. To address these issues, we propose a Multi-Modal Multi-agent hierarchical communication graph PRUNING framework, termed M3Prune. M3Prune eliminates redundant communication edges both across and within modalities, improving the trade-off between task performance and token overhead. Specifically, M3Prune first performs intra-modal graph sparsification in the textual and visual modalities to identify task-critical communication links. It then constructs an inter-modal communication graph and sparsifies cross-modal connections while encouraging consistent cross-modal reasoning through a modality alignment score. Finally, it progressively prunes redundant edges to obtain an efficient hierarchical topology. Extensive experiments on both general-domain and domain-specific mRAG benchmarks show that M3Prune consistently outperforms single-agent and strong multi-agent mRAG systems while signifi- cantly improving token efficiency.

## 2. 论文提出的方法论

### 2.1 核心思想
将多智能体通信建模为**分层的时空图结构**（模态内图 + 模态间图），通过学习可微的软邻接矩阵（Softened Adjacency Matrix）量化每条通信边的重要性，以**任务效用最大化 + 稀疏性正则**为优化目标，并采用**渐进式剪枝**策略逐步移除低重要性边，最终获得紧凑高效的通信拓扑。

### 2.2 三大核心组件

**（1）模态内图稀疏化（Intra-Modal Graph Sparsification）**
- 分别为**文本模态**和**视觉模态**构建独立的时空通信图，每个智能体节点配有特定角色（如数据分析师、批评家、科学家、知识专家等）；
- 使用 Gumbel-Softmax 初始化可学习软邻接矩阵，作为边的权重；
- 设计**时空消息传递**机制，让智能体在同一模态内交换与任务相关的响应；
- 优化目标为：最大化期望任务效用 + 核范数稀疏惩罚（平衡性能与图稀疏度）；
- 因底层 MLLM 的 API 调用不可微，采用**策略梯度法**（Policy Gradient）近似梯度，通过采样 K 个图实例进行优化。

**（2）模态间图稀疏化（Inter-Modal Graph Sparsification）**
- 将文本与视觉智能体合并为跨模态图，初始化时各智能体与另一模态的所有智能体全连接；
- 学习跨模态时空边的软邻接矩阵，评估跨模态通信的重要性；
- 在优化目标中引入**模态对齐分数（Modality Alignment Score）**，通过对两个方向的跨模态邻接矩阵行向量做余弦相似度计算，鼓励跨模态语义理解的一致性；
- 优化目标 = 任务效用 − 稀疏正则 + 模态对齐奖励。

**（3）渐进式边剪枝（Progressive Edge Pruning）**
- 采用两阶段剪枝：先剪枝模态内边，再剪枝模态间边；
- 每轮剪枝率按 $p^{(t)} = p^{(t-1)} \cdot \exp(-t/T)$ 衰减；
- 通过 Top-K 掩码机制保留权重最高的边，永久移除被剪边；
- 推理时直接使用训练得到的剪枝后通信拓扑，无需额外开销。

## 6. 论文的主要结论与发现

1. **性能领先**：M3Prune 在所有数据集和骨干模型上均超越单智能体与固定拓扑多智能体基线。相比最强多智能体基线，平均准确率提升约 **9.4%**，Token 效率提升约 **23.8%**。
2. **冗余通信确实有害**：剪枝不仅能省 Token，还能**提升准确率**——证明固定全连接拓扑中的冗余信息会干扰智能体推理。
3. **模态对齐至关重要**：移除 Lalign 导致性能明显下降，说明跨模态语义一致性有助于稳定多模态协作。
4. **两个模态均不可或缺**：移除文本或视觉智能体均导致大幅性能退化；MultimodalQA 更依赖文本，ScienceQA 更依赖视觉，与任务特性一致。
5. **鲁棒性强**：在对抗攻击下，M3Prune 通过自适应降低被入侵智能体所连边的权重，性能下降幅度远小于固定拓扑基线。
6. **渐进稀疏化有效**：边权重随训练轮次趋集中于少数关键智能体对，形成"关键路径"，非必要连接被逐步降权。
