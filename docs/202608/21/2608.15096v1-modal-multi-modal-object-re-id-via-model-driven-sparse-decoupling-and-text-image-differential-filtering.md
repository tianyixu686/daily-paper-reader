## 摘要
多模态目标重识别（Re-ID）旨在通过利用视觉（如RGB、NIR、TIR）和文本模态的互补信息，促进复杂环境下的跨摄像头目标检索。然而，现有方法往往缺乏有原则的特征解耦和连贯的多模态集成，导致表征纠缠，引入跨模态冲突，掩盖判别线索，并在模态缺失情况下出现分布偏移。为应对这些挑战，我们提出MODAL，一种新颖的多模态目标重识别框架，基于耦合稀疏编码理论和差分抑制原理。MODAL的核心组件是多模态特征稀疏解耦模块，基于多模态耦合稀疏编码，以模型驱动的深度展开方式开发。它明确地将多模态特征分解为单模态特定、双模态和三模态共享表示，从而实现更透明有效的特征解耦。得益于有原则的特征解耦，MODAL通过模态感知子空间激活自然地缓解了不完整模态场景下的性能下降，该激活仅选择性地激活一致共享的子空间。此外，我们提出了一种文本-图像差分过滤模块，利用粗粒度文本语义自适应地抑制解耦视觉表示中与任务无关的响应，从而增强判别信息。在四个数据集上的大量实验表明，MODAL以卓越的透明性实现了最先进的性能。

## Abstract
Multi-modal object re-identification (Re-ID) aims to facilitate cross-camera object retrieval in complex environments by leveraging complementary information from visual (e.g., RGB, NIR, TIR) and textual modalities. However, existing approaches often lack principled feature disentanglement and coherent multi-modal integration, leading to entangled representations that introduce cross-modal conflicts, obscure discriminative cues, and suffer distribution shift under modality-missing conditions. To tackle these challenges, we propose MODAL, a novel multi-modal object re-identification framework, grounded in coupled sparse coding theory and differential suppression principles. A core component of MODAL is a Multi-modal Feature Sparse Decoupling module, developed in a model-driven deep unrolling manner based on multi-modal coupled sparse coding. It explicitly decomposes multi-modal features into uni-modal specific, bi-modal and tri-modal shared representations, thereby achieving more transparent and effective feature disentanglement. Benefiting from the principled feature disentanglement, MODAL naturally mitigates performance degradation in incomplete-modality scenarios via a Modality-Aware Subspace Activation that selectively activates only the consistently shared subspaces. Moreover, we propose a Text-Image Differential Filtering module that leverages coarse-grained textual semantics to adaptively suppress task-irrelevant responses in the decoupled visual representations, thereby enhancing discriminative information. Extensive experiments on four datasets demonstrate that MODAL achieves state-of-the-art performance with superior transparency.

- **研究背景**：多模态目标重识别（Re-ID）旨在利用多种视觉模态（RGB、NIR、TIR）以及文本描述，实现跨摄像头、跨环境下的目标检索。单模态方法在极端光照、遮挡、恶劣天气等场景下性能受限，多模态信息互补可显著提升鲁棒性。
- **核心问题**：
  - 现有方法普遍缺乏**有原则的特征解耦**，导致模态特有与模态共享信息纠缠，引发跨模态冲突并掩盖判别性线索。
  - 主流方法直接融合异构特征到统一嵌入空间，缺少结构约束，容易产生冗余和相互干扰。
  - 在**模态缺失或失配**的实际部署场景下（传感器故障、异步采集等），耦合的融合表示会产生显著分布偏移，导致检索性能严重下降。
- **整体含义**：本文提出统一的 MODAL 框架，通过模型驱动的稀疏解耦、文本引导的差分过滤以及模态感知子空间激活，同时解决特征纠缠、跨模态冲突和模态缺失鲁棒性问题，并兼顾可解释性。

## 2. 方法论

MODAL 由四个核心模块组成：

- **文本-图像特征提取（Text-Image Feature Extraction）**：
  - 使用预训练 CLIP 编码器提取对齐的视觉与文本特征。
  - 文本由 MLLM 根据图像生成，并辅以可学习的前缀提示。
  - 每种模态（RGB/NIR/TIR）均获得对应的视觉特征 $F_m^v = [f_m^v, P_m^v]$ 和文本特征 $F_m^a = [f_m^a, P_m^a]$。

- **多模态特征稀疏解耦（Multi-modal Feature Sparse Decoupling, MFSD）**：
  - 基于**多模态耦合稀疏编码**理论，将特征分解为 7 个解耦分量：3 个单模态特定特征 $\{h_r,h_n,h_t\}$、3 个双模态共享特征 $\{h_{rn},h_{rt},h_{nt}\}$ 和 1 个三模态共享特征 $h_{rnt}$。
  - 通过**模型驱动深度展开**，将稀疏编码的迭代求解过程转化为可学习的网络结构，包括 UFD、BFD、TFD 三类块，每个块内使用软阈值算子和可学习线性变换（瓶颈结构 + dropout）。
  - 整套 MFSD 参数在视觉和文本域**共享**，保证语义对齐。
  - 优化目标包含数据保真项和 $\ell_1$ 稀疏正则项，通过交替更新求解。

- **文本-图像差分过滤（Text-Image Differential Filtering, TIDF）**：
  - 受到差分 Transformer 启发，将解耦后的视觉特征 $z_v$ 和文本特征 $z_a$ 分别映射为两个查询 $Q_v$、$Q_a$，图像 patch 特征作为 $K,V$。
  - 注意力计算为 $\text{softmax}(Q_vK^T/\sqrt{d}) - \alpha \cdot \text{softmax}(Q_aK^T/\sqrt{d})$，其中 $\alpha$ 为可学习参数。
  - 该机制利用文本的粗粒度语义作为“干扰指示器”，自适应抑制视觉特征中与任务无关的响应，增强判别性。
  - 每个解耦分量对应一个 TIDF 块，输出经独立 MoE 门控后拼接形成最终表示。

- **模态感知子空间激活（Modality-Aware Subspace Activation, MASA）**：
  - 定义每个解耦分量的**模态支持**：单模态支持 $\{m\}$、双模态支持 $\{i,j\}$、三模态支持 $\{r,n,t\}$。
  - 对查询-画廊对 $(q,g)$，仅当分量支持 $\mathcal{S}(z) \subseteq M_q \cap M_g$ 时激活该分量。
  - 在推理时动态选择有效共享子空间进行匹配，**无需重建缺失模态**，避免误差传播。
  - 最终相似度通过所有激活分量的内积之和计算，开销极小。

- **损失函数**：三元组损失 + 带标签平滑的交叉熵损失，加权求和（$\eta=0.25$）。

## 3. 实验设计

- **数据集（4 个）**：
  - `RGBNT201`：行人 Re-ID，4787 组 RGB-NIR-TIR 三元组，201 个身份。
  - `RGBNT100`：大规模车辆 Re-ID，17250 组三元组。
  - `MSVR310`：车辆 Re-ID，2087 组三元组，310 个身份。
  - `WMVEID863`：车辆 Re-ID，863 个身份，光照变化大。
  - 文本注释来自 IDEA 公开资源或按同等流程由 MLLM 生成。

- **评估协议**：
  - 标准全模态评估（Rank-1/5/10 和 mAP）。
  - 模态缺失协议：在 RGBNT201 上构造 6 种缺失配置（单模态缺失 3 种，双模态缺失 3 种），测试时直接丢弃对应模态。
  - 模态失配协议：在 RGBNT201 上测试 4 种跨模态检索设置（如 RT-to-NT、R-to-N 等）。

- **对比方法**：
  - CNN 类：HAMNet、PFNet、IEEE、LRMM、TIENet、CCNet 等。
  - Transformer 类：EDITOR、TOP-ReID、HTT、FACENet 等。
  - CLIP/提示类：ICPL-ReID、PromptMA、MambaPro、DeMo、IDEA、Signal、MFRNet 等。

- **主要结果**：
  - RGBNT201：mAP 83.8%，Rank-1 86.1%，优于所有对比方法（如 MambaPro、DeMo、IDEA）。
  - RGBNT100：mAP 87.7%，Rank-1 98.6%。
  - MSVR310：mAP 57.7%，Rank-1 73.9%，显著超过 IDEA（+8.9% mAP）。
  - WMVEID863：mAP 71.2%，Rank-1 79.9%。
  - 模态缺失场景：6 种配置平均 mAP 54.2%，Rank-1 54.9%，优于 IDEA/DeMo 等。
  - 模态失配场景：平均 mAP 24.8%，Rank-1 20.4%，超过 TOP-ReID 等。

## 6. 主要结论

- 模型驱动的稀疏解耦可以**显式分离**单模态特定、双模态共享和三模态共享信息，减少跨模态冲突，提升表示可解释性。
- MASA 利用解耦结构，在模态缺失/失配时**仅激活有效共享子空间**，无需重建即可保持匹配可靠性，显著缓解分布偏移。
- TIDF 利用粗粒度文本语义作为差分过滤器，有效抑制背景或任务无关区域的注意力，增强判别特征。
- 在四个基准数据集、三种评估协议上均达到 SOTA，证实了方法在完整与不完整模态场景下的有效性和实用性。

## 8. 不足与局限

- **方法局限**：
