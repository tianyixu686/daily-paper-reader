## 摘要
通用多模态嵌入（UME）将异构多模态输入映射到一个共享的嵌入空间。现有的UME模型要么通过单次前向编码形成嵌入，要么通过显式推理标记和潜在自回归状态增加计算量。虽然令牌扩展可以改善复杂匹配，但串行生成增加了检索延迟，并使最终嵌入依赖于生成的中间状态。这引发了一个不同的问题：能否在保持令牌工作空间固定的同时，沿着模型深度扩展有用的计算？我们分析了独立训练的UME模型每一层的正负相似性分离，并观察到一个共同的进展：早期层对多模态输入进行上下文化，连续的中间到后期阶段形成检索判别特征，最后层将它们映射到嵌入空间。基于这一发现，我们提出了ReLoop-UME，它执行一次早期层，循环重用参数共享的检索形成块，并在最后一次循环后应用最终映射层。可学习的检索寄存器提供持久的检索特定状态，这些状态在循环中累积和交换证据，最终寄存器作为嵌入读出。在MMEB-V2和MRMR上，ReLoop-UME在不同骨干网络上持续改善检索，同时运行速度比UME-R1快44.9倍，比PLUME快1.5倍。

## Abstract
Universal multimodal embedding (UME) maps heterogeneous multimodal inputs into a shared embedding space. Existing UME models either form embeddings through single forward encoding or add computation through explicit rationale tokens and latent autoregressive states. Although token expansion can improve complex matching, serial generation increases retrieval latency and makes the final embedding depend on generated intermediate states. This raises a different question: can useful computation be expanded along model depth while keeping the token workspace fixed? We analyze positive-negative similarity separation at every layer of independently trained UME models and observe a shared progression: early layers contextualize multimodal inputs, a contiguous middle-to-late stage forms retrieval-discriminative features, and the final layers map them into the embedding space. Based on this finding, we propose ReLoop-UME, which executes the early layers once, recurrently reuses a parameter-shared retrieval-forming block, and applies the final mapping layers after the last loop. Learnable Retrieval Registers provide persistent retrieval-specific states that accumulate and exchange evidence across loops, with the final register serving as the embedding readout. On MMEB-V2 and MRMR, ReLoop-UME consistently improves retrieval across different backbones while running 44.9x faster than UME-R1 and 1.5x faster than PLUME.

## 1. 论文核心问题与研究动机

- **背景**：通用多模态嵌入（UME）的目标是将文本、图像、视频、视觉文档等异构多模态输入映射到统一嵌入空间，通过嵌入相似度衡量相关性。
- **现有方法的矛盾**：
  - 传统单次前向编码模型（如 VLM2Vec、GME、LamRA）效率高，但固定计算量不足以应对复杂查询意图和细粒度跨模态匹配。
  - 计算增强型方法（如 UME-R1 的显式推理轨迹、PLUME 的潜在自回归状态）虽然提升了检索性能，但沿着 token 维度扩展计算会带来串行生成延迟，且最终嵌入依赖中间生成状态。
- **核心研究问题**：能否在**保持 token 工作空间固定**的前提下，**沿模型深度方向**扩展有用计算？
- **关键观察**：通过对独立训练的 UME 模型逐层分析正负样本相似性分离度，发现所有模型呈现一致的阶段化进展：
  - **前缀理解阶段（Prefix Understanding Stage）**：浅层主要做多模态上下文化，正负样本仍纠缠；
  - **检索形成阶段（Retrieval Formation Stage）**：连续的中后段区间产生最大的判别性提升；
  - **嵌入映射阶段（Embedding Mapping Stage）**：末层将已判别的特征映射到输出嵌入空间。
- **核心论点**：检索能力在深度上非均匀形成，额外深度应集中分配在"检索形成"所在区间，而非重新计算输入理解或最终映射。

## 2. 方法论：ReLoop-UME

### 2.1 核心思想
- 将模型按层划分为三个部分：
  - **Prefix**：理解层（只执行一次）；
  - **Recurrent Block**：检索形成层（参数共享，循环复用 T 次）；
  - **Suffix**：映射层（最后一次循环后执行一次）。
- 通过**局部循环**将额外计算集中在正负样本分离能力最强的层区间，不复制骨干参数、不扩展 token 序列长度。

### 2.2 关键技术细节

**（1）阶段定位（Stage Localization）**
- 在独立训练的单次前向 UME 模型上，用训练集测量逐层检索判别性：

$$S_l = \frac{1}{N}\sum_{i=1}^{N}\left[s^+_{i,l} - Q_{0.8}\left(s^-_{i,l}\right)\right]$$

其中 $s^+_{i,l}$ 为正样本相似度，$Q_{0.8}(s^-_{i,l})$ 为负样本相似度的第 80 百分位。
- 使用确定性的三段分段线性变化点拟合（最小化多分位数汇总残差）自动定位边界，而非人工选阈值。
- 得到的边界：Qwen2-VL-2B/7B 与 Qwen3-VL-2B 均为 0–16 / 17–26 / 27；Qwen3.5-2B 为 0–11 / 12–22 / 23。边界对分位数选择不敏感（0.5/0.6/0.7/0.8 均一致）。

**（2）可学习检索寄存器（Learnable Retrieval Registers）**
- 在输入 token 序列后追加 M 个可学习向量 $R=[r_1,\dots,r_M]\in\mathbb{R}^{M\times d}$，作为**固定大小的检索特定工作空间**。
- 每个寄存器可关注完整多模态输入（因果掩码下），寄存器之间可互相交换信息；残差传播使证据跨循环保留。
- 仅**最后一个寄存器**作为嵌入读出（readout），其余 M−1 个作为内部状态。
- 寄存器不是显式推理步骤，数量不随循环深度增长。

**（3）整体前向流程**

$$\tilde{X}(x)=[X(x);R],\quad H^{(0)}(x)=E(\tilde{X}(x))$$
$$H^{(t)}(x)=G(H^{(t-1)}(x)),\ t=1,\dots,T$$
$$z_T(x)=\text{norm}_2\left(\left[O(H^{(T)}(x))\right]_{\rho_x}\right)$$

其中 E、G、O 分别表示 Prefix、共享循环块、Suffix。

**（4）终端对比训练**
- 仅在最后一次循环后应用 InfoNCE 损失：

$$\mathcal{L}_{NCE}=-\frac{1}{B}\sum_{i=1}^{B}\log\frac{\exp(q_i^\top c_i/\tau)}{\sum_{j=1}^{B}\exp(q_i^\top c_j/\tau)}$$

- 中间状态通过展开计算图获得梯度，但不要求形成独立可用的嵌入空间，不施加每循环额外的对比头或语言建模损失。

**（5）效率分析**
- 序列深度为 $D_{loop}(T)=L_p + T\cdot L_r + L_s$，额外深度仅 $(T-1)L_r$，集中在检索形成块。
- 模型参数仅增加寄存器的 $Md$ 个参数（M=5 时仅 7,680 个可训练参数），循环复用共享权重，不需要 transition adapter。

## 6. 主要结论与发现

- **阶段化检索形成**：检索判别性在深度上非均匀形成——前缀理解、中间检索形成、末层嵌入映射的三阶段模式在多个 backbone 上一致复现，且边界对分位数选择鲁棒。
- **局部循环有效**：仅循环"检索形成"区间（17–26 层，T=4）比循环全栈（112 次解码器应用）高出 1.9 个 All 点，证明"计算加在哪里"比"加多少计算"更重要。
- **检索寄存器有正交互作用**：单独的寄存器（M=5, T=1）不改变单次前向结果（60.6→60.6），但结合循环后增益扩大到 +1.4 点（2×2 因子交互为 +1.4），说明寄存器主要在跨循环证据累积时发挥作用。
- **性能结果**：
  - MMEB-V2 All：2B 达 63.2，7B 达 65.9，均优于 PLUME 和 UME-R1；
  - 效率：单样本延迟 201ms，比 UME-R1 快 44.9×，比 PLUME 快 1.5×，相比 VLM2Vec-V2 仅增加 1.3× 延迟；
  - 零样本 MRMR：Avg 48.6，领先 Ops-MM-Embedding（48.1），但优势有限且 Contradiction 组落后；
  - 跨骨干一致增益：三种 Qwen 骨干均提升 +2.2~+2.6 点。
- **视频仍是短板**：2B/7B 视频平均分均低于 PLUME 和 UME-R1，循环精化可能弱化时间信息。

## 7. 方法亮点

- **新颖的问题视角**：将"扩展计算"从 token 维度转向深度维度，提出固定 token 工作空间下的循环计算范式，绕开了自回归推理的高延迟问题。
- **数据驱动的阶段定位**：不以人为直觉确定循环区间，而是基于逐层正负样本分离度曲线和确定性变点拟合自动定位，且对量化参数稳健。
- **精巧的寄存器设计**：固定大小的可学习检索状态作为跨循环持久工作空间，仅需 7,680 个额外参数（M=5），即可带来显著增益；最终寄存器同时充当嵌入读出，设计简洁。
- **终端监督策略**：只在最终循环后施加对比损失，允许中间变换自由优化最终几何，避免每循环独立退出导致的次优。
- **完整的效率论证**：不仅给出理论序列深度分析，还提供实测延迟、吞吐量和跨方法加速比，证据链完整。
- **客观承认局限**：明确报告视频短板、MRMR 迁移不均衡、失败案例分析等负面证据，而非只报喜。

## 8. 不足与局限

- **视频模态明显偏弱**：Video Avg 在 2B 和 7B 上分别只有 40.5 和 42.9，低于 PLUME（44.1）和 UME-R1（47.5）；原因是固定 8 帧采样 + 循环精化不增强时间建模，短时动作事件可能完全未被采样。
- **阶段定位的适用范围有限**：论文承认区间边界依赖 backbone、数据配比和读出方式，不是普遍规律；且分段线性拟合不能证明中间层的每个神经元都只做检索形成。
- **固定循环深度 T=4 非最优**：不同查询可能需要的循环次数不同，自适应停止规则尚未实现；循环展开也增加了训练 FLOPs 和激活显存。
- **MRMR 零样本增益有限且不均衡**：Knowledge 组领先（71.6），但 Contradiction 组仅 30.7，Negation 子任务仅 9.50，极性敏感检索能力明显不足。
- **消融覆盖不完整**：消融仅在 Qwen2-VL-2B 上完成；7B 和 Qwen3/Qwen3.5 骨干上未验证寄存器数量与循环深度的最优组合。
- **训练配置可能不完全对等**：统一 5,000 步和相同超参与基线方法的训练步数、数据配比未必对齐，对比公平性存在不确定因素。
- **主观案例不能量化**：11 个定性案例是人工挑选的机制说明，不能代表各类错误的真实频率；更大的带标注错误集和条件准确率分析留待未来工作。
- **时间与文档细粒度证据易丢失**：全局单向量嵌入难以保留时序边界（如"开门"瞬间）和 OCR 局部修饰词（如"公共"vs"私人"投资）。
