## 摘要
在知识密集型场景中，提供可靠的交错文本-图像响应需要验证性图像接地（VIG）：即检索到的真实视觉证据的精确整合。现有的检索增强框架主要依赖于解耦的静态流水线，本质上无法动态推理何时需要外部知识以及视觉资产应插入何处。为弥合这一差距，我们提出了VIG-RL，一个自主智能体框架，将搜索-选择-插入工作流表述为一个主动决策过程。在动态的ReAct风格循环中运行，VIG-RL通过强化学习优化，并由一个综合奖励系统引导，该系统整体评估智能体的逐步工具执行和最终多模态对齐。大量评估表明，VIG-RL取得了新的最先进性能，显著优于现有的静态基线。

## Abstract
In knowledge-intensive scenarios, providing reliable interleaved text-image responses requires Verified Image Grounding (VIG): the precise integration of retrieved authentic visual evidence. Existing retrieval-augmented frameworks predominantly rely on decoupled, static pipelines, inherently failing to dynamically reason about when external knowledge is required and where visual assets should be contextually inserted. To bridge this gap, we propose VIG-RL, an autonomous agentic framework that formulates the search-selection-insertion workflow as an active decision-making process. Operating within a dynamic ReAct-style loop, VIG-RL is optimized via reinforcement learning, guided by a composite reward system that holistically evaluates the agent's step-by-step tool execution and final multimodal alignment. Extensive evaluations demonstrate that VIG-RL establishes a new state-of-the-art, significantly outperforming existing static baselines.

- **现有方法的缺陷**：
  - 主流多模态大模型（MLLM）只能输出单模态文本，无法直接生成可信图像；
  - 生成式流水线（统一生成模型或调用外部图像生成工具）产出的图像是合成的、以视觉合理性为先，缺乏事实准确性。论文举例：生成模型在描绘大雁塔时出现层数错误、栏杆颜色错误、拱门结构缺失等幻觉；

- **整体含义**：论文主张将 VIG 视为一个**序列决策问题**，让智能体在 ReAct 风格循环中自主学习"搜索—选择—插入"策略，从而生成高保真、可验证的交错多模态响应。

## 2. 论文提出的方法论

### 2.1 问题形式化
- 给定文本查询 \(q\)，目标是生成交错响应 \(A = (t_1, i_1, \dots, t_n)\)，其中 \(t_k\) 为文本段，\(i_k\) 为插入图像。
- 硬性来源约束：所有插入图像必须来自外部检索到的候选池（\(\forall i_k \in A, i_k \in I^{\text{retrieved}}\)），严格禁止生成式图像合成。

### 2.2 智能体交互框架（ReAct 风格循环）
- 状态 \(S_t\) 累积上下文；策略 \(\pi_\theta\) 先生成推理轨迹 \(r_t\)，再采样动作 \(a_t\)，环境执行后返回观察 \(o_t\) 并追加到上下文。
- **动作空间** \(A = \{a_{\text{txt}}(\cdot), a_{\text{img}}(\cdot), a_{\text{ans}}\}\)：
  1. **文本搜索** \(a_{\text{txt}}(q_{\text{txt}})\)：调用文本检索器，返回 top-\(K_{\text{txt}}\) 文本片段；
  2. **图像搜索** \(a_{\text{img}}(q_{\text{img}})\)：调用视觉检索器，返回 top-\(K_{\text{img}}\) 视觉资产（原始图像+关联文本+唯一标识符）；
  3. **答案生成** \(a_{\text{ans}}\)：终止搜索循环，基于终态 \(S_T\) 解码最终交错响应。
- **符号化视觉引用**：将检索图像映射为离散标识符 `<img:id>`，模型在解码时只预测符号标签，渲染时确定性替换为原图，从根本上规避像素级幻觉。
- 循环在调用 \(a_{\text{ans}}\) 或达到最大轮次 \(T_{\max}\) 时终止。

### 2.3 训练算法与复合奖励（GRPO）
- 采用 **GRPO**（Group Relative Policy Optimization）优化策略。
- **复合奖励包含四个子项**：
  - **格式奖励** \(r_{\text{format}}\)：二值指标，确保轨迹符合预定义交互语法（推理与动作交替、工具调用可解析）；
  - **文本结果奖励** \(r_{\text{txt,LLM}}\)：用模型评判器 \(\pi_{\text{judge}}\)（Qwen3-8B-Instruct）评估纯文本内容与参考文本的语义对齐和事实正确性，分数线性归一化到 [0,1]；
  - **图像插入奖励** \(r_{\text{img,pre}}\)：采用**可验证的基于规则的精确率**（受 DeepSeek-R1 启发，防止奖励黑客），计算插入图像 ID 集合与金标集合的精确率：\(r_{\text{img,pre}} = |I^* \cap I_{\text{ans}}| / |I_{\text{ans}}|\)；
  - **搜索过程奖励** \(r_{\text{search}}\)：计算积累候选池中金标图像的召回率 \(r_{\text{search}} = |I^* \cap I_{\text{retrieved}}| / |I^*|\)，为中间检索过程提供密集监督。
- **门控复合奖励**：\(R = r_{\text{format}} \cdot (r_{\text{txt,LLM}} + r_{\text{img,pre}} + r_{\text{search}})\)，格式错误时整体奖励归零。

### 2.4 上下文锚定图像检索（Context-Anchored Image Retrieval）
- 使用 **BGE-M3** 作为统一检索骨干，将语料表示为"上下文-图像对" \(C = \{(t_j, i_j)\}\)。
- 图像检索时按查询与锚定文本的余弦相似度排序，返回关联图像，从而规避直接跨模态（如 CLIP 式）嵌入的语义失配问题。

## 3. 实验设计

### 3.1 基准与数据集

### 3.2 评价指标

- **Order Score**：用于 Manual/Recipe，基于加权编辑距离衡量图像相对顺序。

### 3.3 对比方法
- **静态 RAG 工作流**：固定检索后生成；对比 GPT-5、Gemini-2.5-Flash、五个 Qwen3-VL 变体（30B-A3B-Instruct/Thinking、8B-Instruct/Thinking、4B-Instruct）、M2IO-R1-3B；
- **智能体搜索（零样本）**：将通用 MLLM 部署到 VIG-RL 工作流中（相同工具与动作空间，无额外训练）；
- **SFT 基线**：同一 Qwen3-VL-8B-Instruct 初始化，同一 1.1k 实例，采用 Gemini-2.5-Flash 五次 rollout 中 Image F1 最高的轨迹进行模仿学习，以隔离 RL 的贡献。

## 6. 论文的主要结论与发现

1. **VIG-RL-8B 达到新 SOTA**：六个数据集 C.S. 全部最优，F1/Order 也位居前列；相比同骨干静态 RAG，Image F1 从 57.7 提升到 78.9（+21.2），C.S. 从 56.4 提升到 78.1（+21.7）；即便对比各数据集最优静态 RAG 的"oracle"，宏平均 C.S. 仍从 72.4 提升到 78.1（+5.7）。
2. **增益超越集合级选择**：Web 上 GPT-5 RAG 的 F1 已达 96.0 但 C.S. 仅 85.7，VIG-RL-8B 达到 97.2 F1 / 94.0 C.S.，说明提升来自语义放置、图文对齐和整体连贯性。
3. **零样本泛化良好**：在未见过的 Wit/Manual/Recipe 上 C.S. 均最优，且在顺序敏感的任务上（Manual Order 32.2、Recipe 40.9）保持领先。
4. **4B 规模依然有效**：VIG-RL-4B 大幅超越零样本基线，且多项指标优于同龄的 M2IO-R1-3B。
5. **VIG-RL 学会了"何时搜索"**：Wit 上搜索触发率从基线模型的 36.4%/30.6% 提升到 100%，条件 Answer F1/C.S. 显著提高。
6. **混合奖励设计必不可少**：纯 EM 奖励过于稀疏（Arxiv Answer F1 仅 22.0），纯 MLLM 评判奖励可被黑客利用（文本分数 80.5 但 Answer F1 归零）；过程监督负责证据覆盖，精确率型终局奖励负责过滤噪声，二者分工互补。
7. **奖励解耦催生涌现式放置能力**：奖励对图像位置/顺序不变，但 VIG-RL 的 Order Score 仍大幅提升，说明序列级 RL 放大了预训练 MLLM 的潜在图文对齐先验。
8. **上下文锚定检索优于直接视觉检索**：直接图文匹配使 Arxiv 检索召回从 92.7 降到 84.6、Answer F1 从 84.2 降到 51.1；文本搜索支持多跳检索，移除后 Manual C.S. 从 48.1 降至 36.5。

## 7. 优点

- **问题定义清晰且有价值**：精准指出"合成图像幻觉"与"静态检索流水线"两大痛点，提出 VIG 形式化约束（硬来源约束），任务界定严谨。
- **方法设计有亮点**：
  - 将搜索-选择-插入建模为 ReAct 式智能体决策，动作空间简洁完备；
  - 符号化视觉引用规避像素级幻觉，工程上优雅实用；
  - 复合奖励"门控+分工"设计精巧——格式门控、可验证规则奖励防黑客、过程/终局奖励各司其职、文本与图像奖励严格解耦；
  - 上下文锚定图像检索针对知识密集型场景做了合理适配。
- **实验规范**：SFT 与 RL 严格对齐的对比设计、静态 RAG 检索深度调优、域内/域外划分、训练测试无泄漏，均体现了较高的实验严谨性。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量及训练耗时，可复现性和成本评估受限。
- **基准单一**：仅使用 MRAMG-Bench 一个基准族，缺乏跨基准/真实应用场景的外部验证。
- **缺乏人类评估**：C.S. 依赖 GPT-4o 评判，存在评判器固有偏差；未

进行人类偏好评测，因此模型输出的真实可用性（如用户对图文排版的满意度和信息可信度）缺乏直接证据。

- **训练数据覆盖有限**：1.1k 训练实例规模较小，且仅来自三个域内数据集；域外性能虽有提升，但主要是靠基座模型的泛化能力，VIG-RL 本身能否在更多领域学到更强的通用搜索-放置策略尚未充分验证。
- **评估指标仍有盲区**：Image F1 只衡量图像 ID 的集合匹配，不区分重复插入、乱序插入等细节；Order Score 仅应用于两个域外顺序任务，对域内任务的顺序正确性未做统计；C.S. 虽然综合了多维度，但其权重和评判标准未公开，可复现性有限。
- **奖励设计的潜在缺陷**：
  - 文本奖励依赖 Qwen3-8B 作为评判器，其自身可能受到基座模型的偏见影响，且与主模型同源（均为 Qwen 系列），存在"自我偏好"风险；
  - 搜索过程奖励只监督召回率，可能诱导智能体不加区分地堆砌检索结果（只要金标在候选池中即可获得高分），而忽视候选池中噪声图像对最终插入决策的干扰；
  - 格式奖励为硬门控，若格式被误判（如检索结果格式合法但多模态上下文过长导致解析异常），会产生假阴性。
- **方法边界未充分探讨**：
  - 仅以 Qwen3-VL 系列为基座，未验证该方法在其他架构（如 Llama、DeepSeek-VL）上的通用性；
  - 未分析训练收敛曲线、奖励各子项在训练过程中的动态变化，难以判断是否存在奖励振荡或早停过拟合；
  - 未测试更长交互轮次（\(T_{\max} > 5\)）或更大动作空间（如增加"查询改写"、"证据去重"等动作）是否会带来额外收益。

- **引入人类评估与真实场景部署**：在人工标注的图文对齐任务上开展用户研究，评估模型输出的整体可信度、视觉证据真实性和信息获取效率；同时在历史研究、医疗科普、工业文档等真实知识密集场景中做小规模落地测试。
- **扩展基准与跨域验证**：构建更多带显式图像放置标注的数据集（如多图新闻、教育讲义、电商展示），并加入对图文顺序、重复引用、图像去重等细粒度指标的评测。
- **改进过程奖励设计**：引入精确率与召回率的联合过程监督（如 F1 型过程奖励），或对候选池质量进行惩罚（如对检索噪声的 KL 惩罚），避免奖励黑客；可探索"过程奖励+终局奖励"的权重自适应机制。
- **提升基座模型的决策能力**：考虑在更大规模基座（如 Qwen3-VL-30B）上训练，或采用 MoE 结构以降低推理成本；也可以将 VIG-RL 学习到的策略蒸馏到更小的模型，提升部署效率。
- **探索多轮交互与工具扩展**：将动作空间扩展为包含"图像重检索"、"文本–图像联合定位"、"证据链生成"等更细粒度的操作，使智能体在长尾知识场景中具备更强的抗噪和推理能力。
- **与其他范式融合**：与生成式图像的"编辑式"检索（retrieval-then-edit）结合，在严格来源约束下允许对检索图像做局部修正（如裁剪、标注高亮），进一步拓展 VIG 的可用边界。

## 10. 总体评价

总体而言，VIG-RL 是一篇**问题定义清晰、方法论完整、实验设计规范**的高质量工作。它精准发现了多模态大模型在"可信图像引用"上的核心矛盾（生成式幻觉 vs. 检索式静态流程），并将该问题引入强化学习的序列决策框架，提出了一套以符号化引用、门控复合奖励、过程监督为三大支柱的可训练解决方案。实验中的对比设计（SFT 与 RL 对齐、静态 RAG 检索深度调优、OOD 泛化测试）体现了较强的学术严谨性，RL 所带来的收益也从中得到了充分论证。

其不足在于：基准单一、缺乏人类评估和算力信息，奖励设计仍存在潜在的奖励黑客空间（尤其是过程召回奖励），方法在更广泛架构上的通用性也尚未验证。但从研究贡献看，VIG-RL 为"可信多模态检索增强生成"提供了一个极具启发性的范式——它证明了**强化学习不仅能教会模型"说什么"，还能教会模型"查什么、选什么、插在哪里"**，为后续研究打开了"搜索决策与时序插入"这一全新方向。这一思路未来若能结合更大规模基座、更多元化的工具集和人类反馈校准，将有望在知识密集型多模态对话、智能助手、教育培训等领域产生实际应用价值。
