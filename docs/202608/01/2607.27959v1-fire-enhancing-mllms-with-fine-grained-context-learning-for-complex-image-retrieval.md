## 摘要
由于具有强大的泛化多模态处理与推理能力，多模态大语言模型（MLLMs）已被证明在作为通用图像检索器方面具有显著潜力，能够有效处理多样化的现实图像检索任务。然而，早期的相关研究虽前景广阔，却忽视了细粒度上下文建模和分离微调目标在提升MLLMs检索性能方面的潜力，尤其是在长文本到图像检索、视觉对话检索和组合图像检索（CIR）等复杂任务中。因此，本研究提出了一种自动化的细粒度多模态五元组数据集构建流程，以及一种新颖的两阶段细粒度多模态微调策略。该数据集生成流程可生成包含细粒度图像描述和修改文本的综合性CIR数据集，从而促进细粒度上下文建模。与以往纠缠式的微调范式不同，我们的方法将微调过程分为两个不同阶段：（1）面向细粒度上下文推理的微调，以及（2）面向细粒度检索任务的微调。这两个阶段旨在依次增强模型的上下文理解能力和查询-目标对齐能力，进而提升检索性能。在涵盖多样且复杂图像检索任务的五个数据集上进行的大量实验表明，即使使用比现有方法更轻量级的MLLM主干网络，我们的方法在零样本检索设置下也显著优于现有方法。

## Abstract
Due to their strong generalizable multimodal processing and reasoning capabilities, Multimodal Large Language Models (MLLMs) have demonstrated significant potential as universal image retrievers, effectively addressing diverse real-world image retrieval tasks. Nevertheless, pioneering studies, while promising, overlook the potential of fine-grained context modeling and disentangled fine-tuning objectives in enhancing MLLMs' retrieval performance, particularly for complex tasks such as long-text-to-image retrieval, visual dialog retrieval, and composed image retrieval (CIR). Therefore, in this work, we propose an automated fine-grained multimodal quintuple dataset construction pipeline and a novel two-stage fine-grained multimodal fine-tuning strategy. The dataset generation pipeline produces a comprehensive CIR dataset with fine-grained image captions and modification text, facilitating fine-grained context modeling. Beyond the previously entangled fine-tuning paradigm, our approach separates the fine-tuning process into two distinct stages: (1) fine-grained context reasoning-oriented fine-tuning and (2) fine-grained retrieval-oriented fine-tuning. These stages aim to sequentially enhance the model's context understanding and query-target alignment capabilities, thereby improving retrieval performance. Extensive experiments across five datasets encompassing diverse and complex image retrieval tasks demonstrate the remarkable superiority of our method over existing approaches in zero-shot retrieval settings, even with a more lightweight MLLM backbone compared to those methods.

## 2. 方法论：核心思想、技术细节与流程

### 2.1 自动化细粒度多模态五元组数据集生成流水线（FiGMaQ）

该流水线包括三个阶段，最终生成每个样本包含 `<参考图, 参考细粒度描述, 修改文本, 目标图, 目标细粒度描述>` 的五元组数据，共约 **87K** 样本。

- **阶段1：基于 CoT 的细粒度图像描述生成**
  - 数据来源：ImageNet1K 未标注测试集（100K 开放域真实图像）。
  - 设计 **CoT 引导指令**，将视觉信息处理过程分为四个推理步骤：**主题导向推理**（识别主要主体及其数量）→ **属性导向推理**（外观、颜色、图案、显著特征、动作、交互六类细粒度属性）→ **上下文导向推理**（环境和其他重要元素）→ **总结导向推理**（综合前三步生成连贯细粒度描述）。
  - 生成的描述平均超过 **100 tokens**。

- **阶段2：基于 MLLM 的图像对识别**
  - 利用阶段1得到的细粒度图像-描述对，采用 **图像-文本对比损失** 微调一个 MLLM，以提升其细粒度长文本编码能力。
  - 采用类似 decoder-only 检索模型的做法，在输入序列后追加 **M 个 EOS token**（实验中 M=5），取其最后隐藏层 EOS token 嵌入的平均值作为图像/文本的表示（式1）。
  - 使用 **图像-文本对比损失**（式2）进行对齐微调。
  - 通过余弦相似度阈值筛选相关图像对：仅保留相似度落在 `[θ_l, θ_h] = [0.6, 0.83]` 区间内的图像对（式3），以排除过于相似或无关联的无效对。该设计基于"视觉相似但语义无关"的观察，以**细粒度语义相似度**代替传统视觉相似度。

- **阶段3：人类化细粒度修改文本生成**
  - 输入图像对的**细粒度描述**（而非粗粒度描述）到 LLM（LLaMA 3.1 70B），确保修改细粒度属性的能力。
  - 设计 **模糊引导指令（Vagueness-guided Instruction）**，模拟真实用户表达（如用 "fewer people"、"lighter color" 代替精确数值），允许必要时给出精确修改（如"把猫变成狗"），并配以3个人工标注示例进行少样本引导。
  - 这种方法避免了以往 LLM 生成修改文本"过于精确、偏离真实用户表达习惯"的问题。

### 2.2 两阶段微调策略（FiRE）

- **阶段1：细粒度上下文推理导向微调**
  - 基于五元组数据构造指令-答案对：指令为 `"<reference image> but modified with modification text. Please describe the new image"`，答案为**目标图的细粒度描述**。
  - 与 MCL 使用单一 CLIP 嵌入不同，本文使用 MLLM 输出的**长序列 token 嵌入**表示参考图像，将其视为类似长文本处理，以促进细粒度上下文推理并提升泛化能力。
  - 使用生成损失（式4）微调。

- **阶段2：细粒度检索导向微调**
  - 查询格式化为 `"⟨reference image⟩ but modification, please describe the new image"`，目标格式化为 `"⟨target image⟩ describe the image"`，实现**多模态查询到多模态目标**的对齐（区别于 MCL 对齐到单模态文本特征）。
  - 损失函数为 **InfoNCE 损失**（式5）与 **Recall@k 代理损失**（式6）的加权组合（式7）：采用 Recall@1 和 Recall@5，权重 β1=0.4，β2=0.15。Recal@k 代理损失直接约束目标在 batch 内的排序位置，增强判别式检索能力。

- **推理方式**：微调后的模型可将查询编码为 EOS token 平均值特征，通过与候选目标图像特征计算相似度完成检索。支持三类查询：纯文本、纯图像、图像+文本组合。

## 6. 关键见解与创新点

- **细粒度数据优于海量数据**：FiGMaQ 流水线仅用约 87K 的高质量五元组数据，就超越了 MMC（2.7M）和 LaSCo（359.2K）等大规模粗粒度数据集，证明了“数据质量”远比“数据规模”重要，尤其对于需要深度上下文理解的复杂检索任务。
- **解耦微调目标**：将“上下文理解”和“查询-目标对齐”分为两阶段独立优化，避免了两者相互干扰。第一阶段让模型学会根据参考图与修改文本生成目标图描述（推理能力），第二阶段再专门对齐查询与目标表示（检索能力）。这种范式比 MCL 的混合训练更干净、更高效。
- **长序列 token 嵌入代替单向量**：用 MLLM 最终隐藏层的多个 EOS token 平均嵌入作为图像表示，保留了比 CLIP 单嵌入更丰富的细粒度视觉信息，使模型能像处理长文本一样“读懂”图像细节。
- **人类化模糊指令**：通过模糊引导指令和少样本示例，迫使修改文本生成器模仿真实用户的表达习惯（如“更多人”“颜色更浅”），解决了以往合成数据过于精确而偏离实际查询分布的问题。
- **轻量级高效训练**：仅用 4 张 A100-40G 和 LoRA 微调 4B 模型即可全面超越 8B 的 E5-V，大幅降低了训练成本，验证了“方法设计”比“模型参数”对复杂检索性能更具决定性作用。

## 7. 局限性与未来工作

- **数据生成的级联误差**：FiGMaQ 依赖预训练的 MLLM 和 LLM 生成描述与修改文本，若底层模型存在幻觉或偏见，这些误差会传递到训练数据和最终检索器。未来可采用更强大的生成模型或引入人工校验环节来缓解。
- **图像对筛选阈值需人工调节**：相似度区间 `[0.6, 0.83]` 依赖人工观察设定，不同数据集的最佳阈值可能不同，缺乏自适应机制。未来可探索基于难例挖掘或动态阈值的筛选策略。
- **短文本检索性能仍有差距**：在 Flickr30K 上 FiRE 的 R@1 比 E5-V 低约 3 个百分点，说明细粒度长文本训练可能在一定程度上弱化了极短查询的匹配能力。未来可通过混合训练或多任务学习平衡不同粒度的输入。
- **未覆盖更多复杂检索场景**：当前验证集中于单轮对话和单步修改的 CIR，尚未涉猎多轮对话检索、视频检索、多图组合等更高阶任务。未来可扩展五元组结构以支持更复杂的交互模式。
- **领域泛化性验证不足**：除 FashionIQ 外，其余数据集均为开放域通用图像；在医学、遥感等垂直领域的表现未知，未来需在特定领域数据上检验其泛化能力。

## 8. 总结与启发

本文提出的 FiRE 框架，以**自动化细粒度五元组数据生成**和**两阶段解耦微调**为核心，成功将轻量级 MLLM 转化为强大的通用检索器，在多个复杂图像检索任务上取得了领先成果。其核心启示在于：

- **复杂任务需要细粒度数据与针对性训练**：简单的短句对或三元组不足以支撑模型对复杂查询的深层语义建模，精心设计的细粒度多模态数据是关键。
- **推理能力与检索对齐应解耦**：将“理解”和“匹配”分开训练，比单一目标混合训练更有效，这一思路或可推广至其他多模态理解任务。
- **轻量高效是落地方向**：通过高质量数据和高效训练策略，即便是 4B 级别的模型也能超越大型模型，为资源受限场景提供了可行路径。

FiRE 不仅为图像检索社区提供了一套新的数据生成和微调范式，也为后续 MLLM 在多模态检索、组合推理等方向的研究奠定了坚实基础。
