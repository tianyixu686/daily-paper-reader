## 摘要
将大型语言模型（LLMs）适配到专业领域通常会带来对齐税，因为针对领域特定任务的微调可能导致灾难性遗忘，并显著降低在通用任务上的性能。我们提出MemSFT，通过将领域专业化与骨干参数更新解耦，采用即插即用的参数化记忆来缓解对齐税。该记忆被训练以模仿在领域数据上运行的非参数检索器的行为，从而记住原本需要通过检索获得的知识和模式。一旦在特定领域上训练完成，该记忆可被不同规模的LLMs复用。在生成过程中，一个学习得到的路由器在每个解码步骤动态融合记忆与骨干的输出分布，从而选择性地调用领域专业知识。在生物学、地球科学和法律领域，使用从Qwen3-8B到Qwen3-235B-A22B的模型进行评估，结果表明MemSFT持续提升领域性能，同时通用性能的下降可忽略不计，而完全微调（full SFT）则在通用任务上遭受严重遗忘。总体而言，我们的结果展示了一条在参数层面将通用模型能力与领域特定知识解耦的实用路径，从而在不损害通用能力的前提下为LLMs赋予新的专业化能力。

## Abstract
Adapting Large Language Models (LLMs) to specialized domains often incurs an alignment tax, as fine-tuning on domain-specific tasks can cause catastrophic forgetting and substantially degrade performance on general tasks. We propose MemSFT, which mitigates the alignment tax by decoupling domain specialization from backbone parameter updates through a plug-and-play parametric memory. The memory is trained to imitate the behavior of a non-parametric retriever operating over domain data, thereby memorizing knowledge and patterns that would otherwise be accessed through retrieval. Once trained on a specific domain, the memory can be reused across LLMs of different sizes. During generation, a learned router dynamically fuses the output distributions of the memory and backbone at each decoding step, allowing domain expertise to be invoked selectively. Across biology, geoscience, and law, evaluations with models ranging from Qwen3-8B to Qwen3-235B-A22B show that MemSFT consistently improves domain performance with negligible degradation in general performance, whereas full SFT suffers severe forgetting on general tasks. Overall, our results demonstrate a practical path to decoupling general model capabilities from domain-specific knowledge at the parameter level, thereby equipping LLMs with new specialized capabilities without compromising their general capabilities.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：将 LLM 适配到专业领域（如生物、地学、法律）通常需要进行领域微调，但领域 SFT 会带来严重的 **对齐税（alignment tax）**，表现为灾难性遗忘：模型在领域任务上提升的同时，数学推理、指令遵循、通用知识等能力大幅下降。
- **已有方案的不足**：
  - 全参数 SFT：领域提升明显，但通用性能下降严重（例如 Qwen3-14B 在 BioIns 上 +34.52 分，通用平均分却下降 31.39 分）。
  - LoRA 等 PEFT：虽减轻遗忘，但依然存在领域性能与通用保持之间的固有权衡，无法根本消除。
  - 混合训练、Wise-FT 等缓解策略：只能平移权衡曲线，不能同时达到高领域性能和几乎无损的通用性能。
- **核心含义**：本文主张在**参数层面**将通用能力与领域知识解耦——通过外部参数化记忆承载领域专长，保持骨干模型完全冻结，从而在获取新专长的同时不损害原有通用能力。

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 总体框架
- 包含两个核心组件：
  1. **外部参数化记忆（Memory LM）**：一个可分离、可复用的领域专家模型。
  2. **学习式路由器（Router）**：逐 token 动态决定记忆与骨干分布的融合比例。
- 训练流程分两阶段：先训练记忆，再在冻结骨干和记忆上训练路由器；推理时两者并行运行。

### 2.2 构造检索式监督（Retrieval-Based Supervision）
- 在领域 SFT 数据上构建 **token 级 datastore**：对每个答案位置使用冻结编码器提取隐藏表示作为 key，答案 token 作为 value：
  \[
  (\mathcal{K},\mathcal{V}) = \bigcup_{i=1}^{N} \{(k_t^{(i)}, y_t^{(i)})\}_{t=1}^{T_i}
  \]
- 查询时用 FAISS L2 最近邻检索，构造**非参数教师分布**（kNN-LM 风格）：
  \[
  p_{\text{teacher}}(y|c_t) \propto \sum_{(k_j,v_j)\in \mathcal{N}(k_t)} \mathbb{1}[y=v_j]\exp(-d(k_t,k_j)/\tau)
  \]
- 实现细节：使用最终 decoder block 的 MLP 输入隐藏状态作为特征，检索 top-2048 邻居（去掉自身），温度 \(\tau=16.0\)，datastore 仅覆盖答案侧 token。

### 2.3 训练损失
- **记忆训练**：结合 KL 散度（对齐教师分布）与交叉熵（锚定正确答案），总损失：
  \[
  \mathcal{L}_{\text{mem}} = \beta \cdot \text{KL}(p_{\text{teacher}} \| p_{\text{mem}}) + (1-\beta)\cdot \mathcal{L}_{\text{CE}}
  \]
  实际取 \(\beta=0.1\sim0.3\) 效果相近，各领域使用域内取值。
- **路由器训练**：路由器为两层 MLP，输入两分支隐藏状态、置信度和熵等标量特征，输出 \(\lambda_t \in [0,1]\)，融合公式：
  \[
  p_{\text{fused}} = (1-\lambda_t)p_{\text{base}} + \lambda_t p_{\text{mem}}
  \]
  目标函数为融合分布的交叉熵加上带符号线性正则项：
  \[
  \mathcal{L}_{\text{router}} = \mathcal{L}_{\text{CE}} + \alpha_s \cdot s_t \lambda_t
  \]
  其中领域样本 \(s_t<0\)，通用样本 \(s_t>0\)，从而使路由器在领域 token 上加大记忆权重、在通用 token 上减小记忆权重。

### 2.4 推理与记忆复用
- 推理时骨干和记忆并行处理相同输入，路由器逐 token 预测 \(\lambda_t\) 并融合分布。骨干参数完全冻结，领域更新只存在于记忆和路由器中。
- 只要模型共享 tokenizer 和输出词表，同一领域记忆可跨不同模型规模直接复用（如 Qwen3-8B 记忆用于 8B/14B/32B/235B-A22B）。

## 6. 主要结论与发现

1. **MemSFT 显著提升领域性能**：例如 BioIns 上 Qwen3-8B 从 5.07 提升至 42.84（+37.77），OpenSWI 上 Qwen3-8B RMSE 从 103.07 降至 0.47，LawBench 上 Qwen3-14B 从 49.83 提升至 56.47。
2. **通用能力几乎无损**：所有 MemSFT 配置的通用平均分变化均在 ±0.6 分以内，而全量 SFT 普遍下降 10~31 分，LoRA 下降 3~17 分。
3. **记忆可跨规模复用**：同一 8B 领域记忆可直接用于 8B 到 235B-A22B，不必按骨干重新训练。
4. **适配算力显著更低**：四骨干适配总成本仅为全量 SFT 的 22%，单 235B 适配成本约为 SFT 的 57%。
5. **学习式 token 级路由优于固定插值**：固定插值存在明显的领域-通用权衡曲线，而学习路由能跳出该曲线，同时对不同角色 token 动态调节记忆权重（如 OpenSWI 中数值 token 的 \(\lambda\approx0.99\)，函数词仅 0.20）。
6. **记忆规模与领域能力正相关**：1.7B→4B→8B 记忆在固定冻结骨干上持续提升 BioIns 分数，而通用性能稳定。
7. **直接检索不足以替代参数化记忆**：BM25 RAG 在 top-50 时 BioIns 仅 12.23，远低于 MemSFT 的 42.92。

## 7. 优点

- **方法设计创新且通用**：将外部参数化记忆与学习式路由结合，从参数层面解耦领域专化和通用能力，核心思路简单而有效。
- **即插即用与高效复用**：记忆训练与骨干无关，可在共享 tokenizer 的模型家族内一次训练、多处使用；适配算力大幅降低。
- **不修改骨干权重**：完全避免了对齐税，并保留了 backbone 的推理与指令遵循能力，符合后训练模型的实用性需求。
- **实验覆盖较广**：三个差异较大的领域（序列科学、数值地球物理、法律文本）跨多个模型规模验证，并补充了非 Qwen 家族验证。
- **分析深入**：对路由器行为做了细粒度 case study，证明选择性融合具有语义合理性；对固定插值、记忆规模、检索教师、直接 RAG 等做了系统性消融，证据链完整。
- **结果报告细致**：提供全 per-task 结果、算力实测、FLOPs 估算和评估协议细节，可复现性强。

## 8. 不足与局限

- **跨家族记忆复用受限**：记忆目前只能在共享 tokenizer/词表的模型之间复用，跨家族需要词表对齐或额外继续训练，本文未展开解决。
- **未探索强化学习阶段**：记忆是完整 decoder 模型，文中没有探索通过 RL 进一步增强领域能力或与骨干对齐的可能性。
- **实验覆盖仍有空白**：
  - 235B 骨干上未运行 SFT/LoRA 对比，无法同规模直接比较；
  - 法律领域仅验证了 14B 一个规模；
  - OpenSWI-deep 因输出过长、结构复杂被排除，未验证在更长结构化生成上的表现；
  - 通用评估基准数量有限（5 个），未覆盖更多对话、代码等能力维度。
- **推理成本增加**：推理时需同时运行骨干和 8B 记忆两个模型，带来额外显存和时延开销，文中未给出推理效率的量化分析。
- **训练数据构造复杂度高**：依赖 FAISS 大规模检索构造教师分布，预处理（datastore 构建、KNN 目标物化）虽占时比例小，但工程实现门槛较高。
- **RAG 对照较弱**：仅使用 BM25 作为直接检索基线，未与更先进的稠密检索

- **RAG 对照较弱**：仅使用 BM25 作为直接检索基线，未与更先进的稠密检索（如嵌入向量检索）或混合检索方法对比，无法充分说明参数化记忆相对于检索增强方法的差异化优势；且 RAG 的领域增益主要通过"检索-复制"实现，而 MemSFT 以压缩记忆进行生成，两者机制不同，缺少对两类方法在生成可控性、泛化边界上的深入比较。

- **记忆跨多领域扩展方式不明确**：MemSFT 目前为每个领域独立训练一个 8B 记忆模型。若需同时适配多个领域（如生物+法律+地学），是训练一个多领域混合记忆、多个记忆并联路由、还是记忆链式叠加，文中没有给出方案；记忆模型的组合管理与动态加载机制亦未讨论，限制了实际部署中的可扩展性。

- **路由器训练仍需依赖混合通用数据**：学习式路由器依赖领域样本与通用样本联合训练以学会区分两类 token，这意味着新增领域时仍需准备一部分通用指令数据作为"负样本"；虽然所需通用数据量远小于混合训练，但并未完全摆脱对通用数据收集与标注流程的依赖。

- **评测维度未覆盖多轮交互与长文本生成**：领域任务评测均为单轮问答或结构化输出预测，未在对话式、多轮交互的领域场景（如法律咨询对话、科研助手多轮追问）下验证；OpenSWI-deep 这类超长结构化生成任务也被排除，记忆+路由机制在长序列动态决策上的表现尚属未知。

- **对齐税缓解的条件性**：MemSFT 完全冻结骨干的前提是骨干本身已具备较强的通用指令遵循能力。对于不存在指令微调 checkpoint、通用能力基线较低的基座模型，其"零遗忘"收益的绝对值会大打折扣；此外，本文所有实验均在 Qwen3 指令微调版上进行，未检验该框架在纯基座模型上的适用性。

- **推理效率缺乏量化分析**：虽然文中承认推理时需同时运行骨干与 8B 记忆两个模型，但未给出额外的显存占用、时延增量或吞吐下降的具体数据，也未讨论记忆模型蒸馏、层裁剪或投机解码等推理加速方案的可行性。

## 9. 整体评价与展望

总体来看，MemSFT 是一项设计精巧、实证扎实的领域适配工作。其核心贡献在于**将领域知识的外部化参数存储与轻量级 token 级路由相结合**，在参数层面而非数据层面实现了领域专化与通用能力的解耦，从而以较低的适配成本同时获得了高领域性能和近乎无损的通用保持。该方法在三个差异显著的领域（序列生物学、数值地球物理、法律文本）和四个 Qwen3 骨干规模上表现稳定，并通过消融实验、算力实测和跨规模复用验证，构建了较为完整的证据链。

从更广阔的视角看，MemSFT 的价值不仅在于缓解对齐税，更在于它为"模型能力模块化"提供了一条可行路径：领域记忆作为可插拔的独立模块，与骨干模型解耦，可复用、可组合、可替换。这一思路与参数高效微调、检索增强生成共同构成了后训练阶段的三种互补范式，未来在多领域记忆的组织、记忆间的协同路由、以及记忆的动态更新与卸载方面仍有可观的探索空间。
