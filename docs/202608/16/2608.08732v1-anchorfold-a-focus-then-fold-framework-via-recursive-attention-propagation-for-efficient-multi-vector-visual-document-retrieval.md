## 摘要
多向量视觉语言检索器通过后期交互实现细粒度的视觉文档检索（VDR），但每页存储和评分数百个视觉补丁嵌入会产生大量开销。现有的免训练方法依赖于剪枝或合并：剪枝在激进压缩下性能急剧下降，而合并方法在形成代表向量时并未明确优先考虑重要区域。我们提出了AnchorFold，一种免训练的聚焦-折叠框架，用于文档端索引压缩。AnchorFold在视觉自注意力图上应用递归注意力传播，在每个注意力头内执行多步传播，并跨头和层整合分数。聚焦阶段选择最高中心性标记作为锚点。折叠阶段将剩余标记分配给归一化检索空间中与其最相似的锚点，并通过中心性加权聚合对每个以锚点为中心的组进行汇总。这在将容量集中于结构上重要的标记的同时，保留了非锚点标记的贡献。在ViDoRe v1/v2和REAL-MM-RAG上，使用三种不同的检索主干，AnchorFold在γ≤0.20时持续优于所有评估的免训练基线。在ViDoRe v1/v2上，在5倍压缩下平均保留了全索引NDCG@5的98.3%，实现近乎无损压缩；在20倍压缩下保留了92.4%。

## Abstract
Multi-vector vision-language retrievers enable fine-grained Visual Document Retrieval (VDR) through late interaction, but storing and scoring hundreds of visual patch embeddings per page incurs substantial overhead. Existing training-free methods rely on pruning or merging: pruning degrades sharply under aggressive compression, whereas merging does not explicitly prioritize important regions when forming representatives. We introduce AnchorFold, a training-free focus-then-fold framework for document-side index compression. AnchorFold applies Recursive Attention Propagation over visual self-attention graphs, performing multi-step propagation within each attention head and integrating scores across heads and layers. The focus stage selects the highest-centrality tokens as anchors. The fold stage assigns remaining tokens to their most similar anchors in the normalized retrieval space and summarizes each anchor-centered group through centrality-weighted aggregation. This preserves non-anchor contributions while concentrating capacity on structurally important tokens. Across ViDoRe v1/v2 and REAL-MM-RAG with three diverse retrieval backbones, AnchorFold consistently outperforms all evaluated training-free baselines at $γ\leq 0.20$. On ViDoRe v1/v2, it retains 98.3% of full-index NDCG@5 on average at $5\times$ compression, achieving near-lossless compression, and 92.4% at $20\times$ compression.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想：Focus-Then-Fold（聚焦-折叠）
- **聚焦（Focus）**：通过**递归注意力传播（Recursive Attention Propagation, RAP）**在视觉自注意力图上计算每个 token 的结构重要性（中心性分数），选择得分最高的 m 个 token 作为**锚点（anchors）**，从而分配有限的表示预算。
- **折叠（Fold）**：将每个非锚点 token 分配给与其在归一化检索空间中最相似的锚点，形成锚点中心分组；然后用**中心性加权聚合**将每组压缩为一个文档向量。这样非锚点 token 的证据被保留在聚合表示中。

### 关键技术细节与公式（用文字说明）
1. **视觉注意力图构建**：取中间层 l、注意力头 h 的 post-softmax 自注意力矩阵，限定在有效视觉 token 上并做行归一化，得到行随机转移矩阵 \(G_{l,h}\)。
2. **递归注意力传播**：从均匀分布初始分数 \(s^{(0)}=\frac{1}{N}\mathbf{1}\) 出发，迭代执行 \(s^{(t)}=(G_{l,h})^\top s^{(t-1)}\) 共 K 步（论文中 K=6），让重要性沿多跳注意力路径传播，得到每个 token 的多跳注意力支持度。
3. **跨头、跨层整合**：对每个头使用 **RMS 操作**整合分数，再按层做**均值归一化**以消除尺度差异，最后在选定的层窗口上取平均，得到最终中心性分数 \(\alpha_j\)。
4. **锚点选择**：选取得分最高的顶 m 个 token 作为锚点集合 \(C=\{c_1,\dots,c_m\}\)，其中 \(m=\lceil\gamma N\rceil\)，\(\gamma\) 为目标保留比率。
5. **Token 分配**：每个非锚点 token i 根据 L2 归一化后的检索向量 \(e_i\)，找余弦相似度最高的锚点 \(a(i)=\arg\max_{q} e_i^\top e_{c_q}\)。
6. **中心性加权聚合**：将每组（锚点 + 分配到它的非锚点 token）用中心性分数加权的隐藏状态求加权平均：
   \(y_q=\frac{\sum_{i\in C_q}\alpha_i z_i}{\sum_{i\in C_q}\alpha_i}\)，
   再把 \(y_q\) 过检索投影并归一化得到压缩索引 \(\hat{E}=[\hat{e}_1,\dots,\hat{e}_m]\)。
7. **检索方式不变**：压缩后仍用原始 MaxSim 评分函数检索，查询端无需任何改动。

- **显著优于全部免训练基线**：在所有 6 个 主干×基准 组合下，γ≤0.20 时 AnchorFold 均取得最高 NDCG@5 保留率。

- **跨基准泛化**：在更具挑战性的 ViDoRe v2 上增益更明显（γ=0.05 时超出最强基线 4.6–5.5 个百分点）；在 REAL-MM-RAG（低词法重叠场景）上同样一致领先。

- **不逊于训练方法**：与 AGC 在固定预算下对比，AnchorFold 在 ViDoRe v2 上比 AGC 高 2.8 个 NDCG@5 点，且无需额外训练。

## 7. 优点
1. **免训练、即插即用**：不引入任何可学习参数，不改变查询编码与 MaxSim 评分，可直接对任意多向量 VDR 模型压缩索引。
2. **方法设计巧妙**：用“注意力图上的多跳中心性”替代单层注意力或不可逆剪枝，既保留了非锚点 token 的证据，又把容量聚焦到结构关键区域。
3. **无标签超参校准**：基于 SR（压缩前后 MaxSim 分数比）在留出对上自动选择传播深度和层窗口，标注成本低且与下游指标一致（验证表明 SR 选择的窗口对应最高的 NDCG@5）。
4. **实验充分、公平性好**：覆盖 3 个异构主干、3 个基准（共 18 个数据集）、4 档压缩率；所有基线在统一代码库中复现，预算对齐；消融清晰验证每个组件的贡献。
5. **效率演示完整**：报告了计算复杂度分析（O(LsHKN² + γN²dr + γNddr)）和实测时延，压缩开销仅在离线索引阶段发生，不增加查询时延。
6. **定性分析有说服力**：通过 Pair-SR 热力图直观展示压缩表示对查询相关证据区域的保留能力。

## 8. 不足与局限
1. **算力细节披露不足**：未报告 GPU 数量、总 GPU 时、训练/推理耗时，难以评估大规模部署的实际资源需求；ColQwen2.5 基座的训练成本也未单独列出。
2. **超参仍需一次性校准**：虽然无标签且只进行一次，但仍需少量查询-页配对数据（500 对）和每 backbone 单独校准 K 与层窗口，对完全陌生的模型需要重复这一过程。
3. **评估指标单一**：主要依赖 NDCG@5，未报告 Recall@k、MRR、MAP 等指标；且未在更大规模语料（如千万级页面）上测试实际吞吐与存储节省。
4. **大规模语料未验证**：ViDoRe 数据集每页平均数百 token，真实场景中可能涉及更复杂的长文档、手写文档、非英语排版；REAL-MM-RAG 虽涵盖多语言查询，但语料规模有限。
5. **与训练方法对比不够全面**：仅对比了一个训练方法 AGC，未与 MetaEmbed、CausalEmbed 等其他新方法比较；且固定预算为 128 向量，未覆盖更宽的压缩区间。
6. **效率实验覆盖有限**：仅测了 ColQwen2.5 / γ=0.10 一个配置；不同主干、不同压缩率下的索引开销变化未展示（复杂度分析本身是通用的，但实测数据有限）。
7. **潜在的应用限制**：方法依赖访问骨干网络的中间层自注意力图，若模型不暴露中间层输出（如某些 API 化检索服务）则无法应用；自注意力矩阵的显存占用在长序列上可能成为瓶颈（但文中给出了复杂度分析）。
8. **γ=0.50 时优势小**：在中等压缩率下与基线差距很小，说明方法的核心价值集中在极端压缩（γ≤0.20）场景。
