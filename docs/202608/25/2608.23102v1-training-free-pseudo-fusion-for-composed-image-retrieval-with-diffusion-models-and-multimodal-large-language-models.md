## 摘要
组合图像检索（CIR）是内容基图像检索中的一种新兴范式，它使用户能够通过将参考图像与辅助模态（通常是基于文本的）相结合来构建组合查询。这种方法支持细粒度搜索，其中目标图像与用户提供的图像共享结构元素，同时纳入辅助文本指定的修改。传统的CIR方法依赖多模态融合将视觉和文本特征组合成联合查询嵌入，这需要训练模块来对齐组合查询与目标。在这项工作中，我们提出了PeFuse（伪融合），一个无训练框架，利用预训练的扩散模型和多模态大语言模型通过生成式转换来桥接模态。我们引入了两种新颖的策略：单向和双向转换，将CIR转化为四个单模态检索问题。这些方法将CIR重新表述为模态内或跨模态的单查询检索任务，无需专门的任务特定训练。在标准基准上的大量实验表明，将CIR转换为文本到图像检索任务比替代转换策略更有效，与最先进的方法相比达到竞争性或更优的性能，同时由于转换管道的组件可替换而保持高度灵活性。这些结果突显了伪融合范式在零样本CIR中的有效性。我们的代码公开于：https://github.com/StevenXuf/PeFuse4CIR。

## Abstract
Composed Image Retrieval (CIR) is an emerging paradigm in content-based image retrieval that enables users to formulate compositional queries by combining a reference image with an auxiliary modality, usually text-based. This approach supports fine-grained search where the target image shares structural elements with the user-provided image while incorporating the modifications specified by the auxiliary text. Conventional CIR methods rely on multimodal fusion to combine visual and textual features into a joint query embedding, which requires training modules that align composed queries with the targets. In this work, we propose PeFuse (for pseudo-fusion), a training-free framework that leverages pretrained Diffusion Models and Multimodal Large Language Models to bridge modalities via generative conversion. We introduce two novel strategies: uni-directional and bi-directional conversion, which convert CIR into four single-modality retrieval problems. These methods reformulate CIR as either intra-modal or cross-modal single-query retrieval tasks, bypassing the need for dedicated task-specific training. Extensive experiments on standard benchmarks demonstrate that converting CIR into text-to-image retrieval tasks is more effective than alternative conversion strategies, achieving competitive or superior performance compared with state-of-the-art methods, while maintaining high flexibility thanks to replaceable components of the conversion pipeline. These results highlight the effectiveness of the pseudo-fusion paradigm for zero-shot CIR. Our code is publicly available at: https://github.com/StevenXuf/PeFuse4CIR.

- **背景**：组合图像检索（Composed Image Retrieval, CIR）允许用户将参考图像与文本描述（修改指令）结合为组合查询，实现细粒度图像搜索。例如，输入一张红色跑鞋的图片，加上文本“改成蓝色”，检索目标为蓝色跑鞋。

### 二、方法论：PeFuse（伪融合框架）

#### 核心思想
- 利用预训练的**扩散模型（Diffusion Model）** 和**多模态大语言模型（MLLM）** 进行“生成式转换”，将组合查询（图像+文本）**转换为单模态查询**（纯文本或纯图像），从而将CIR问题重新表述为四个单模态检索任务。
- 框架不需要训练，所有组件均为现成预训练模型。

#### 两种转换策略
1. **单向转换（Uni-directional Conversion）**：
   - 仅将参考图像转换为文本（通过MLLM生成图像描述），与用户修改文本拼接，得到“综合查询文本”，然后执行文本到图像检索（T2I）。
2. **双向转换（Bi-directional Conversion）**：
   - 同时执行两个方向：
     - 图像→文本：用MLLM描述参考图像，再与用户文本拼接。
     - 文本→图像：利用扩散模型根据用户文本生成“伪目标图像”（或对参考图像进行编辑），然后执行图像到图像检索（I2I）。

#### 四种单模态检索任务
| 任务 | 查询形式 | 检索方式 |
|------|----------|----------|
| T2I | 综合查询文本 | 文本→图像 |
| I2I | 生成的伪目标图像 | 图像→图像 |
| I2T | 参考图像 | 图像→文本（反向检索） |
| T2T | 综合查询文本 | 文本→文本（跨模态反向检索） |

- 采用固定的CLIP（或BLIP等）编码器计算查询与目标之间的相似度，无需任何梯度更新或任务特定训练。

### 六、主要结论与发现

1. **T2I转换策略最有效**：将组合查询转换为综合文本、执行文本到图像检索，是四种转换方式中效果最好的，在多个基准上达到或超越现有SOTA。
2. **伪融合范式可行**：通过生成式转换，零样本CIR可以完全绕过任务特定训练，且性能不逊于需要大规模训练的方法。
3. **组件灵活可替换**：由于不使用融合模块，任何MLLM、扩散模型、编码器均可即插即用，研究者和工程师可根据资源限制选择合适组件。
4. **生成质量是性能瓶颈**：扩散模型生成的伪目标图像质量影响I2I路线表现，而T2I路线依赖于MLLM的图像描述质量——两者提供互补的误差来源。

### 七、优点

- **训练自由**：零训练成本，无需标注数据、无需求解联合嵌入空间，极大降低使用门槛。
- **生成式理解桥梁**：创新性地利用生成模型将跨模态组合「翻译」为单模态检索，避免了对融合网络的设计依赖。
- **统一框架**：用单向/双向转换统一了四种检索任务，提供了一个完整的CIR问题再定义视角。
- **模块解耦**：每个管道组件（描述生成器、图像生成器、编码器）可独立替换与升级，天然支持即插即用。
- **实用性**：简化了检索管线，且实验证明不牺牲性能，具备替代传统训练范式的潜力。

### 八、不足与局限

- **生成误差累积**：MLLM生成的文本描述可能丢失参考图像中的细粒度细节；扩散模型的图像编辑也可能引入与目标不一致的伪影，导致检索相关度下降。
- **计算成本并未消失**：虽然免训练，但推理时需要运行MLLM和扩散模型，在实际大规模候选集检索中的时间开销可能高于直接使用融合嵌入的方法。
- **对生成模型的依赖**：框架性能直接受制于底层生成模型的能力边界，若生成模型产生偏差或幻觉，检索效果将受影响。
- **多模态信息损失**：单向/双向转换本质上将组合信息压缩为单模态表示，可能在转换过程中丢失部分跨模态对齐信息。
- **实验规模有限**：仅在三个公开数据集上验证，未覆盖视频检索或更细粒度的专业领域（如医疗、遥感）。
- **资源信息缺失**：未报告推理耗时、显存占用或API成本，难以评估其在真实部署中的经济性。
