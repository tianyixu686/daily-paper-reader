## 摘要
组合视觉数据检索的核心是将参考视觉输入和文本修改融合为单一查询。虽然当前最先进的方法利用多模态大语言模型进行这种融合，但其复杂性引入了难以接受的查询时延，限制了可扩展性。我们转而重新审视嵌入空间中简单线性插值的有效性，并引入SRAIN，这是第一个动态预测查询特定插值权重的框架。关键挑战在于，插值权重的质量应通过插值嵌入相对于负样本的判别性以及其与真实目标的接近程度来衡量；这使得收集和预测最优权重变得棘手。我们通过两项关键创新克服了这一瓶颈：训练期间的批次级排序感知权重估计，以及推理期间合成难负样本的紧凑记忆库。SRAIN在组合视频检索中取得最佳性能，并在组合图像检索中达到当前最先进水平，同时相比基于MLLM的替代方案大幅降低了查询时延。

## Abstract
At the heart of composed visual data retrieval is the fusion of a reference visual input and a textual modification into a single query. While current state-of-the-art methods utilize multimodal large language models for this fusion, their complexity introduces prohibitive querytime latency, limiting their scalability. We instead revisit the efficacy of simple linear interpolation within an embedding space, and introduce SRAIN, the first framework that dynamically predicts query-specific interpolation weights. The key challenge lies in the fact that the quality of an interpolation weight should be measured by the interpolated embedding's discriminability from negatives as well as its proximity to true targets; this makes collecting and predicting optimal weights intractable. We overcome this bottleneck through two key innovations: batch-wise rank-aware weight estimation during training, and a compact memory bank that synthesizes hard negatives during inference. SRAIN achieves the best in composed video retrieval and matches the current state of the art in composed image retrieval, all while substantially reducing querytime latency compared to MLLM-based alternatives.

## 1. 核心问题与整体含义（研究背景与动机）

- **任务背景**：组合视觉数据检索（Composed Visual Data Retrieval）包括组合图像检索（CoIR）和组合视频检索（CoVR），要求根据“参考视觉输入 + 文本修改描述”合成一个查询，从数据库中检索对应的目标视觉内容。
- **现有方法的主要矛盾**：
  - 当前最先进方法依赖多模态大语言模型（MLLM）将参考视觉与修改文本共同“改写”或融合成查询，虽然准确率高，但模型规模大、推理复杂，导致查询时延极高，难以规模化部署。
  - 另一些轻量方法（如简单线性插值 Slerp）虽高效，但使用数据集级统一插值权重，无法根据具体查询内容动态调整文本修改的影响强度，性能次优。
- **本文目标**：在保留线性插值高效性的同时，实现**样本级别的动态插值权重预测**，使模型能够根据每个查询自适应地决定“参考视觉”和“修改文本”各自的影响力，从而兼顾性能与效率。

## 2. 方法论：核心思想与技术细节

### 2.1 总体框架（SRAIN）
- SRAIN = **S**ample-wise **R**ank-**A**ware **IN**terpolation，即“样本级排序感知插值”。
- 采用预训练 BLIP-2 作为视觉-语言骨干，分别编码参考视觉、修改文本与目标视觉，得到单位超球面上的嵌入向量。
- 通过**球形线性插值（Spherical Linear Interpolation, Slerp）**融合参考嵌入 $r_i$ 与文本嵌入 $t_i$：
  \[
  f_i^k = \frac{\sin((1-\alpha_k)\theta_i)}{\sin(\theta_i)} r_i + \frac{\sin(\alpha_k\theta_i)}{\sin(\theta_i)} t_i
  \]
  其中 $\alpha_k$ 是候选插值权重，$\theta_i$ 是两向量的夹角。

### 2.2 核心挑战与应对
- **挑战 1：最优权重缺乏监督信息**。最优插值权重不能仅由查询本身决定，而应同时考虑“插值后嵌入与真实目标的接近程度”和“对负样本的判别能力”，即需要全局排序信息。
- **应对：批次级排序感知权重估计（Batch-wise Rank-aware Weight Estimation）**：
  - 在训练中，对于一个包含 $B$ 个三元组（参考、文本、目标）的 mini-batch，对每个查询尝试 $K=101$ 个均匀分布在 $[0,1]$ 的候选权重 $\alpha_k$。
  - 对每个候选权重，计算插值查询与 batch 内所有目标嵌入的余弦相似度，得到正样本在该 batch 中的**排序名次**（rank）。
  - 选择使正样本名次最优（rank 最小）的权重作为该样本的近似最优权重 $\alpha_i^*$；若有多个候选并列，则取中位数。
- **挑战 2：推理时无法访问 batch 内负样本**。
- **应对：条件化权重预测 + 记忆库**：
  - 训练时，权重预测器除了输入参考嵌入和文本嵌入外，还显式接收一组条件化 token（包括正样本嵌入和若干 hardest negative 嵌入）。
  - 推理时，使用一个紧凑的**记忆库**（memory bank，含 1024 个原型向量）存储训练集目标嵌入的代表性原型。模型用多个候选权重融合查询，检索记忆库中频繁出现的高相似原型作为“合成难负样本”，代替 batch 内负样本参与条件化预测，从而保持训练与推理一致性。

### 2.3 两阶段训练策略
- **阶段 1（模态对齐）**：固定目标视觉编码器（BLIP-2 冻结），微调 Q-Former，使用****hard-negative 对比损失**，将插值后的查询嵌入与目标嵌入对齐，同时推开难负样本。
- **阶段 2（权重回归）**：冻结所有编码器，仅训练轻量级权重预测器（2 层 Transformer + 3 层 MLP，约 1.63M 参数，仅占总模型 0.14%），回归阶段 1 中估计的 $\alpha_i^*$，损失为 MSE。
- **分离原因**：如果同步更新编码器和预测器，编码器变化会导致同一查询的最优权重估计不断漂移，监督信号不稳定，训练难以收敛。实验也验证了端到端训练效果不如两阶段策略。

### 2.4 推理流程
- 参考视觉与修改文本独立编码；
- 从记忆库中检索若干原型作为条件化输入；
- 轻量预测器输出样本级插值权重 $\hat{\alpha}_i$；
- 在线性插值后与库中目标嵌入计算余弦相似度进行检索。

## 3. 实验设计

### 3.1 数据集与基准
- **组合视频检索（CoVR）**：
  - **WebVid-CoVR**：大规模数据集，1.64M 训练三元组，2,556 个测试三元组；评估指标 R@1、R@5、R@10、R@50。
- **组合图像检索（CoIR）**：
  - **FashionIQ**：细粒度时尚检索，三个类别（Dress、Shirt、Toptee），报告验证集 R@10、R@50。
  - **CIRCO**：零样本 CoIR 基准，测试集 800 个查询，检索库 123,403 张图像，指标 mAP@5/10/25/50。
  - **CIRR**：开放域场景 CoIR，36,554 个三元组，报告 R@1/5/10。

### 3.2 对比方法
- 视频检索：CoVR、CoVR-2、Thawakar 等（CA/MLP 融合），以及文本-only、视觉-only、平均插值基线。
- 图像检索：大量现有方法，包括 CIReVL、OSrCIR、Pic2Word、SEARLE-XL、TAT、MagicLens、LinCIR、CompoDiff、CASE、FashionVLP、CLIP4CIR、CoVR-2、BASIC 等，涵盖零样本与微调设置。
- 另外对比了 BLIP 骨干下的 CoVR 以验证泛化性。

### 3.3 主要结果
- **WebVid-CoVR**：R@1 达 **61.07**，超过所有先前方法（如 Thawakar 等 60.12、CoVR-2 59.82），在 R@5/R@10 上也与最优相当，R@50 略低于个别方法。
- **FashionIQ（微调）**：平均 R@10 **49.26**，超过 CoVR-2（48.86）等，R@50 亦领先。
- **CIRCO（零样本）**：mAP@5 **26.16**，在所有不使用外部知识的方法中最高，接近使用外部大模型的方法。
- **CIRR（监督）**：R@1 **50.95**、R@5 **81.21**、R@10 **89.60**，全面超越所有对比方法。

## 6. 主要结论与发现

- 样本级动态插值权重比固定权重（数据集级最优 α）更有效；即使不使用编码器微调（仅训练预测器）也能优于固定平均插值。
- 两阶段训练（先对齐、再回归权重）优于端到端联合训练，原因是避免监督信号漂移。
- 记忆库在推理时代替 batch 内难负样本，能保持训练–测试一致性，且在领域偏移（零样本 CoIR）下依然有效。
- SRAIN 在组合视频检索上达到 SOTA，在组合图像检索上匹配甚至超过多数现有方法，同时查询时延比 MLLM 方法低约 24 倍（以 CIRCO mAP@5 与吞吐量对比为例）。
- 验证了“轻量线性插值 + 动态权重”这一范式能够替代复杂 MLLM 融合，实现高效且性能可观的可扩展检索。

## 7. 优点

- **高效性**：推理无需 MLLM，权重预测器极轻量（1.63M 参数），查询时延显着降低，适合大规模检索场景。
- **方法新颖**：首次将“样本级插值权重预测”引入组合视觉检索，并利用排序感知目标构造监督，填补了固定权重与全模型融合之间的空白。
- **监督信号设计巧妙**：用批内排序名次代替不可行的全局最优权重估计，使问题可解；两阶段训练避免优化不稳定性。
- **训练-推理一致性处理得当**：通过记忆库合成难负样本，解决推理时无负样本的问题，并验证了在领域偏移下仍有效。
- **实验较全面**：覆盖视频与图像、零样本与有监督、不同骨干，且有 oracle 分析，提供了性能上界视角。
