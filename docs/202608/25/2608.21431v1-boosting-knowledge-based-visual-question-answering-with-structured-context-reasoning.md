## 摘要
基于知识的视觉问答旨在通过融合外部知识与视觉和文本信息来回答有关图像的问题。近期方法通常依赖上下文学习，以零样本或少样本方式用多模态上下文提示大语言模型（LLM）。然而，我们观察到，将异构的视觉描述和检索到的知识直接拼接成冗长的非结构化提示，往往因包含过多无关上下文且缺乏显式关联结构而降低推理性能。为此，本文提出一种基于LLM的结构化上下文推理（SCoRe）框架，该框架同时推断显式与隐式关系以进行预测。SCoRe包含三个阶段：上下文获取阶段，通过高效的两阶段多模态检索策略生成多样的视觉笔记并检索显式知识；上下文选择阶段，利用LLM引导选择过滤相关的视觉、显式及隐式知识；上下文压缩阶段，执行关系逻辑蒸馏（RLD）将原始文本转换为显式的实体-关系三元组。这些关系三元组可作为简洁、结构化的提示，用于最终答案预测。在OK-VQA和A-OKVQA基准上的大量实验表明，SCoRe始终优于最先进的方法。

## Abstract
Knowledge-based Visual Question Answering aims to answer questions about an image by integrating external knowledge with visual and textual information. Recent approaches often rely on in-context learning to prompt Large Language Models (LLMs) with multimodal context in a zero-shot or few-shot manner. However, we observe that directly concatenating heterogeneous visual descriptions and retrieved knowledge into long, unstructured prompts often degrades reasoning performance, due to both excessive irrelevant context and the lack of explicit relational structure. In this paper, we propose an LLM-based Structured Context Reasoning (SCoRe) framework that infers both explicit and implicit relationships for prediction. SCoRe consists of three stages: Context Acquisition, which generates diverse visual notes and retrieves explicit knowledge via an efficient two-stage multimodal retrieval strategy; Context Selection, which filters relevant visual, explicit, and implicit knowledge using LLM-guided selection; and Context Compression, which performs Relational Logic Distillation (RLD) to transform raw text into explicit entity-relation triplets. These relational triplets serve as a concise and structured prompt for final answer prediction. Extensive experiments on the OK-VQA and A-OKVQA benchmarks demonstrate that SCoRe consistently outperforms state-of-the-art methods.

**研究动机与背景：**

- 知识型视觉问答（KB-VQA）要求模型结合外部知识与图像、文本等多模态信息来回答复杂问题，其问题往往涉及隐含概念和多步推理。
- 现有主流方法趋向于使用大语言模型（LLM）进行零样本或少样本上下文学习，将图像描述、检索知识和任务指令直接拼接到一个长提示词中。

- 因此，核心研究问题是：如何将异构多模态输入转化为**简洁、结构化的关系表示**，以提升LLM在KB-VQA中的推理效果。

**整体含义：**

- 论文提出：**上下文结构**（而非上下文数量）才是决定KB-VQA推理效果的关键因素。通过显式建模实体关系，可以显著改善LLM的推理表现。

## 2. 论文提出的方法论

**核心思想：**

- 提出 **SCoRe（Structured Context Reasoning）** 框架，将异构多模态证据通过“获取—选择—压缩”三阶段流程，逐步转化为实体-关系三元组，作为最终问答的结构化提示。

**关键技术细节与流程：**

1. **上下文获取（Context Acquisition, CA）**
   - 视觉证据：使用目标检测（VinVL）提取物体属性、使用问题引导的标题生成、使用OCR提取图像文本，形成多视角视觉笔记。
   - 显式知识检索：针对OK-VQA用Google Search语料，针对A-OKVQA用Wikipedia；设计**两阶段渐进式多模态检索**，提升检索效率并保持高召回。
   - 检索公式概述：
     - 利用文本编码器 \(F_L\) 和视觉编码器 \(F_V\) 编码问题与图像，通过映射层 \(F_M\) 对齐视觉特征，拼接得到跨模态查询向量 \(Q\)。
     - 第一阶段：标题级粗检索，基于晚期交互计算 \(S(q,t)\)，选出 top-k1 标题，合并其对应段落构成候选集合 \(P_{\text{candidate}}\)。
     - 第二阶段：段落级细粒度检索，在候选集合中再次使用相同相关性度量，选出 top-k2 段落作为目标知识片段。

2. **上下文选择（Context Selection, CS）**
   - 利用LLM对视觉笔记和显式知识分别进行筛选，得到选中视觉知识 \(VK_i\) 和选中显式知识 \(EK_i\)。
   - 同时，根据图像标题和问题，让LLM生成与视觉内容对齐的隐式知识 \(IK_i\)。

3. **上下文压缩（Context Compression, CC）**
   - 提出**关系逻辑蒸馏（Relational Logic Distillation, RLD）**，包含三步：
     1. **实体抽取**：初始化实体集为检测到的物体，再让LLM分别从显式知识和隐式知识中抽取实体，合并成显式实体列表 \(E_e^i\) 与隐式实体列表 \(E_i^i\)。
     2. **关系抽取**：对实体对 \((e_p, e_q)\) 抽取关系，生成显式关系三元组集合 \(ER_{\text{init}}^i\) 和隐式关系三元组集合 \(IR_{\text{init}}^i\)。
     3. **关系精炼**：从图像标题和问题中提取关键实体集合 \(KE_i\)，过滤掉与关键实体无关或无法通过关系连通的关键实体三元组，得到最终关系集合 \(R_i\)。

4. **预测（Prediction）**
   - 将最终关系集合 \(R_i\) 与问题 \(Q_i\) 一起输入QA模型（Mistral-7B或Gemma-7B），模型直接基于结构化关系进行答案推断。

## 6. 主要结论与发现

- SCoRe在OK-VQA和A-OKVQA上均**显著优于所有对比的零样本和少样本方法**：
  - 零样本：SCoRe（Mistral-7B）达到OK-VQA 52.1%、A-OKVQA 52.4%，超过DIETCOKE约3个百分点。
  - 16-shot：OK-VQA达55.7%，A-OKVQA达54.9%，刷新最优成绩。
- 消融实验表明：各个模块（视觉笔记、显式知识、上下文选择、上下文压缩）逐步累加均带来性能提升，完整模型最佳。
- 两阶段检索策略将候选段落压缩数十至数百倍，同时保持较高的伪召回率。
- 关键发现：**初始获取阶段的信息量虽然更高（PR更高），但最终性能低于压缩后的结构化上下文**，说明冗余和非结构化信息会损害LLM推理，而结构化关系三元组能帮助模型更准确地进行逻辑推理。
- 结论：显式建模实体关系、将上下文结构化为三元组，是提升KB-VQA的有效途径。

## 7. 优点

- **新颖性**：首次系统性地将KB-VQA中的上下文组织问题视为“结构化表示”问题，提出三阶段流水线，而非简单拼接或过滤文本。
- **高效检索**：两阶段渐进式多模态检索显著减少搜索空间，在保持高召回的同时大幅降低计算开销。
- **可解释性**：通过显式实体-关系三元组进行推理，模型决策依据更加透明，便于分析错误来源。
- **通用性**：方法不依赖特定QA模型，可与不同LLM搭配（Mistral、Gemma），且适用于零样本和少样本场景。
- **模块化设计**：各阶段独立可替换，便于后续改进和集成。

## 8. 不足与局限

- **基准覆盖有限**：仅在OK-VQA和A-OKVQA上评估，A-OKVQA仅用验证集，未在更多KB-VQA数据集（如KVQA、F-VQA）或跨域场景上验证。
- **隐式知识依赖LLM内部知识**：当LLM内部先验与检索到的显式知识冲突时，模型可能错误优先采用内部知识（如案例中的“1886” vs “1892”），导致答案错误。
- **细粒度视觉信息不足**：对于需要精细分类的任务（如区分鸟类品种），仅依靠目标检测和字幕难以捕获足够的细节特征，限制了性能。
- **流水线信息损失**：每个阶段都可能丢失部分原始信息，论文虽分析了PR下降，但未提出缓解机制。
- **算力与时间**：虽然比DIETCOKE快，但每样本仍需约17.5秒，在大规模实际应用中可能仍有延迟成本。
- **缺乏统计严谨性**：未报告多次实验的方差或显著性检验，可能存在随机性影响。
