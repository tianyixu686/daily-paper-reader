## 摘要
长期第一人称记忆将连续的第一人称视频和音频转化为可搜索的过往经历记录。我们指出现有系统中的两个瓶颈：由缺乏上下文描述的标题构建的索引在智能体搜索中不可靠，而检索忽略了问题的时间意图。为了解决这两个瓶颈，我们引入了EgoCITE（第一人称上下文增强索引与时间感知证据检索），一个用于第一人称问答的长期智能体记忆框架。EgoCITE包含三个组件。EgoScheme利用局部多模态上下文将片段化的视频标题和语音转录转化为自包含的原子记忆索引。EgoIndex将互补的动作、活动、话语和对话表示组织成多个粒度下的可搜索多视图记忆索引。EgoRetrv将语义搜索与问题条件的时间相关性评分和检索证据的策展相结合。我们在EgoLifeQA、EgoMem和EgoR1-Bench上评估EgoCITE的答案准确性和目标事件检索对齐。EgoCITE相比智能体记忆基线至少提高了4.4%至14.2%的准确性，同时比长上下文LLM智能体成本低36倍。

## Abstract
Long-horizon egocentric memory transforms continuous first-person video and audio into a searchable record of past experiences. We demonstrate two bottlenecks in existing systems: indices built from context-poor captions are unreliable for agentic search, while retrieval ignores a question's temporal intent. To address both bottlenecks, we introduce EgoCITE (Egocentric Context-augmented Indexing and Time-aware Evidence retrieval), a long-horizon agentic memory framework for egocentric QA. EgoCITE comprises three components. EgoScheme uses local multimodal context to turn fragmentary video captions and speech transcripts into self-contained atomic memory indices. EgoIndex organizes complementary action, activity, utterance, and conversation representations into searchable multi-view memory indices at multiple granularities. EgoRetrv combines semantic search with question-conditioned temporal relevance scoring and curation of retrieved evidence. We evaluate EgoCITE on EgoLifeQA, EgoMem, and EgoR1-Bench in terms of answer accuracy and target-event retrieval alignment. EgoCITE improves accuracy over agentic memory baselines by at least 4.4--14.2% while achieving 36$\times$ lower cost than long-context LLM agents.

## 1. 核心问题与整体含义

- **研究背景**：长期第一人称（自我中心）记忆系统旨在将可穿戴设备连续采集的视频与音频转化为可搜索的日常经历记录，支持记忆增强、AR 眼镜、AI 助手等应用。随着 Ego4D、EgoLife 等数据集出现，社区已从短片段动作识别转向多日、多模态的长期推理。
- **核心问题**：论文指出现有系统存在两个关键瓶颈：
  - **索引瓶颈**：记忆条目通常直接构建于上下文匮乏的独立视频标题和语音转录上，包含未消解的指代、省略表达和碎片化描述，导致下游智能体搜索无法命中真实事件。
  - **检索瓶颈**：检索仅依赖语义相似度，忽略问题中"last"、"first"、"usually"、"this morning"等时间意图。最相似的语义事件往往既不是用户要求的那次发生，也无法代表重复性习惯。
- **总体意义**：论文主张"记忆索引的质量取决于它所组织的条目，以及用于从中检索证据的时间推理"——即先构建自包含、可解释的原子索引，再显式进行时间感知检索，两者缺一不可。

## 2. 方法论

- **整体框架**：EgoCITE 是一个四阶段流水线：
  1. 多模态感知与标题生成（视频→视觉标题，语音→转录，融合为多模态标题）；
  2. 上下文增强的记忆索引构建（本文贡献）；
  3. 时间感知的原子索引检索（本文贡献）；
  4. 推理与回答。
- **EgoScheme（上下文增强的原子索引构建）**：
  - 给定当前标题及其前 T 分钟（默认 5 分钟）的上下文窗口，通过 LLM 解析指代与省略，将碎片化内容改写为**自包含的原子记忆索引**；
  - 从人本与解耦两个原则出发，定义四类视图的结构化规范：
    - **动作（Action）**：细粒度，分为手-物交互（HOI）、有意义的手势、位移；
    - **话语（Utterance）**：细粒度，注明说话者、言语行为、完整命题内容（如"Jake confirms all packages are outside"）；
    - **活动（Activity）**：粗粒度，注明即时目标、参与者、对象和地点（30 分钟窗口）；
    - **对话（Conversation）**：粗粒度，跨标题抽取一致主题（30 分钟窗口）；
  - 采用显式"解耦"程序，将"and/while"连接的复合事件拆分为多个原子索引；跨窗口的连续索引用句向量相似度（阈值 0.9）识别并合并。
- **EgoIndex（多视图、多粒度索引库）**：
  - 将原子记忆索引按视图组织为 `M = ⋃_{v∈V} M_v = {(τ_i, m_i)}`，V 为四视图集合，τ 为时间戳；
  - 优点：(1) 支持不同抽象层级的查询；(2) 物理行为与语言互动分离，互补描述经历。
- **EgoRetrv（时间感知检索）**：双智能体设计。
  - **Drafting agent（起草智能体）**：每轮生成结构化查询 `Q={Q_s, Q_v, Q_t}`（语义查询、目标视图、可选时间查询），利用向量检索并维护持久化的索引池（index pool），优先保证召回率。可调用 `search_action_utterance`、`search_activity`、`search_conversation`、`curate_index`、`answer` 等工具，最多 5 轮。
  - **时间相关性评分公式**：将时间戳映射到连续时间轴（单位为小时），根据预测时间区间 `Q_t=[t_start, t_end]` 计算：
    - R_i = 1（在区间内），
    - R_i = λ^{t_start − τ_i}（早于区间），
    - R_i = λ^{τ_i − t_end}（晚于区间）；
    - 最终评分 `score(m_i|Q_s, Q_v, Q_t) = S_i · R_i`，其中 S_i 为语义相似度，λ 默认 0.99。软衰减避免硬时间过滤对模糊时间表达过于脆弱。
  - **Sampling agent（采样/策展智能体）**：对索引池按时间排序，根据问题中的时间限定词（如"last"选最新、"usually"选跨日期的多样证据、"first"选最早）策展出 5–15 条最相关索引，传给最终回答智能体。回答智能体将索引时间戳映射回原始多模态标题进行推理。

- **主结果**：EgoCITE-GPT 在 EgoLifeQA、EgoMem、EgoR1-Bench 上分别达到 63.8%、75.3%、75.3%（EgoR1 数值在表 2 中约 75.3%），相比最强智能体记忆基线 WorldMM-GPT 平均准确率提升至少 14.2%、4.4%、9.0%；相比长上下文 LLM 智能体提升 0.9–8.9%，同时输入 token 节省 23 倍以上、归一化成本低 36 倍。

- **VLM 标题鲁棒性**：用 Gemini-3-Flash 代替人工标题仅下降 1.2% 准确率，Gemma-4-31B 全开源流水线下降 4.4%，说明对真实感知噪声有一定适应性。

- **设计解耦、模块化**：将"构建时上下文增强"与"检索时时间/跨事件推理"分离，四个阶段职责清晰，便于检查与替换。

在准确率超越百万 token 上下文的 LLM 智能体的同时，实现了约 23 倍的输入 token 压缩和约 36 倍的归一化成本下降，证明"多轮检索 + 小上下文"范式在长期记忆问答中兼具精度与效率优势。

## 8. 局限与不足

- **感知层误差的下游放大**：EgoScheme 的输入完全依赖视觉标题与语音转录的质量；若第一阶段的感知模型漏检关键事件、错认说话人或产生错误 OCR，后续索引构建即使语义改写正确也无法恢复缺失信息。论文虽验证了 VLM 标题替换的鲁棒性，但仍未覆盖极端噪声（如多人重叠对话、严重遮挡、环境噪音）场景。
- **数据集规模有限**：全部实验基于 EgoLife 的 6 名参与者、7 天 × 8 小时的记录。参与者人数少、文化背景单一，无法验证索引规范（如"话语需包含完整命题内容"）在不同语言、不同社交习惯下的泛化性；EgoLifeQA 等基准的题目数量虽达数千，但本质仍出自同源数据，存在分布重叠风险。
- **时间推理能力仍较为浅层**：软时间衰减公式只支持"区间内/早于/晚于"三类情形，对周期性事件（"每天早晨"）、相对锚点（"我上次见到 Jake 之后"）、跨时区作息差异等更复杂的时间语义缺乏显式建模；λ 为全局固定超参，无法适应不同问题的模糊程度差异。
- **参数与阈值依赖经验设定**：上下文窗口 5 分钟、活动/对话窗口 30 分钟、索引合并余弦阈值 0.9、λ=0.99 等均来自启发式或小规模验证集（λ 消融仅用 100 题），缺乏理论指导或端到端自适应学习。
- **离线静态评估，缺乏交互闭环**：所有指标都在预构建的离线视频/音轨上评测，未考虑真实使用中用户会追问、纠正、或记忆库实时写入新数据的动态场景；双智能体检索无法在流式记忆环境中得到验证。
- **可复现性与统计稳健性不足**：主结果未报告多次运行的标准差或置信区间，也未说明 API 采样温度等随机性控制手段；闭源模型（GPT-5.4、Gemini-3.1-Pro）的版本迭代可能使基线对比难以精确复现。

## 9. 总体评价与未来方向

- **总体评价**：EgoCITE 是一篇问题诊断犀利、设计模块化、实验覆盖度高的记忆系统工作。它没有试图用"更大上下文窗口"强行解决长期记忆问题，而是回到记忆系统的基本链路——**条目质量决定可检索上限，时间感知决定检索命中率**——分别用 EgoScheme 和 EgoRetrv 给出工程上可落地的解决方案。其核心思想"先让每条记忆可独立理解，再让检索显式理解时间"，对更广泛的 RAG、智能体记忆、多模态日志分析领域均有迁移价值。
- **未来方向**：若能沿以下方向推进，该框架将更具说服力：
  1. 引入记忆更新与遗忘机制，使索引随时间推移动态合并、衰减或淘汰；
  2. 构建跨语言、跨文化、更大规模的自我中心记忆基准，检验索引规范的通用性；
  3. 将时间参数（λ、窗口大小、合并阈值）从人为设定改为可学习的自适应模块；
  4. 设计"索引—检索—回答"的端到端反馈闭环，利用用户纠正信号反向优化索引构建；
  5. 探索基于图结构或稀疏倒排的索引组织方式，替代纯向量检索以支持更复杂的时间/实体约束查询。
