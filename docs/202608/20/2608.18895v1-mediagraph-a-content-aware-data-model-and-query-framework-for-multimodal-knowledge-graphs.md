## 摘要
多模态知识图谱通常将多媒体文档视为不透明的外部实体。这种内容无关的方法将媒体与图谱的核心结构相隔离，限制了检索与分析能力，阻碍了对跨媒体类型复杂关系的捕获与查询。为解决这一问题，我们提出了MediaGraph数据模型及其原型实现MeGraS（MediaGraph Store），这是一种将多媒体内容作为图节点集成的新方法。这一范式转变使查询引擎能够直接访问和处理文档的内在内容，从而支持基于特征的相似性搜索、动态分割以及非物化关系的推断等原生操作。通过扩展SPARQL查询语言，MeGraS为多模态数据的存储、管理和表达性查询提供了一个统一的平台。MeGraS是开源软件，建立了一个新框架，推动该领域向内容感知的多模态知识图谱发展。

## Abstract
Multimodal knowledge graphs typically treat multimedia documents as opaque, external entities. This content-agnostic approach constrains retrieval and analysis by isolating media from the graph's core structure, hindering the ability to capture and query complex relationships across media types. To address this, we introduce the MediaGraph Data Model and its prototypical implementation MeGraS, the MediaGraph Store, a novel approach that integrates multimedia content as graph nodes. This paradigm shift enables the query engine to directly access and process a document's intrinsic content, allowing for native operations such as feature-based similarity search, dynamic segmentation, and the inference of non-materialized relations. By extending the SPARQL query language, MeGraS provides a cohesive platform for the storage, management, and expressive querying of multimodal data. MeGraS is open-source software that establishes a new framework, moving the field toward content-aware multimodal knowledge graphs.

- **核心问题**：现有多模态知识图谱（Multimodal Knowledge Graphs）在处理多媒体内容（图像、视频、音频、文档）时，通常将其视为**不透明的外部实体**——要么以外部 URI 引用，要么作为“不透明二进制大对象”（BLOB）存储在字面量中。这种**“内容无关”（content-agnostic）**的处理方式使查询引擎无法直接访问和理解媒体内部的内容与结构，导致查询表达能力受限，无法执行跨媒体类型的复杂关系推理与分析。
- **研究动机**：作者指出，上述问题的根源并非单纯的技术实现差距，而是**概念层面的缺陷**——现有数据模型在设计上未赋予知识图谱及其查询引擎对媒体内在内容的有意义访问能力。这种局限阻碍了多媒体建模、语义记忆检索、交互式视频探索等多个领域的发展。
- **整体含义**：本文提出了一种**“内容感知”（content-aware）**范式，通过将多媒体文档及其分段提升为知识图谱中的“一等公民”（first-class citizens），打破结构化符号知识与非结构化多媒体内容之间的壁垒，使查询引擎能够原生访问和处理媒体内容，实现特征相似性搜索、动态分段和非物化关系推理等能力。

## 2. 论文提出的方法论：核心思想与关键技术

- **MediaGraph 数据模型**：在传统 RDF 图定义（GRDF ⊆ (U ∪ B) × U × (U ∪ B ∪ L)）的基础上，引入了多媒体文档节点集合 M，将图定义为 GMG ⊆ (U ∪ B ∪ M) × U × (U ∪ B ∪ L ∪ M)。多媒体文档由此成为 URI 可寻址的图节点，可充当任何三元组的主语或宾语。
- **MeGraS 系统架构**（原型实现）：
  - **双组件存储**：将语义三元组存储与原始媒体内容存储分离。图存储支持 PostgreSQL（搭配 pgvector 扩展）、Cottontail DB、轻量级文件后端三种后端；媒体存储采用**内容寻址存储**，通过 MultiHash（SHA3-256）对文件内容做哈希，生成 URI-safe base64 编码（46 字符）作为唯一标识，实现自动去重和数据完整性保障。
  - **查询引擎**：基于 **QuadSet 抽象**（在三元组基础上增加语句 ID），采用批量处理模式执行 SPARQL 查询，结合选择性启发式重排序、算子下推（LIMIT/PROJECTION/JOIN）等代数优化，并通过自定义函数库支持空间、时间和特征属性推断。
  - **统一多媒体分段（UMS）**：集成 Unified Multimedia Segmentation 模型，支持 Filter（如时间间隔、矩形区域、多边形、路径、B 样条）和 Reduction（如轨道/通道选择、颜色通道）两类操作，将媒体分解为 URI 可寻址的分段，URI 格式为 `<server>/<canonical id>/segment/<segment type>/<segment description>`。
  - **向量分析**：原生支持高维特征向量的存储与检索，提供 DoubleVectorValue、FloatVectorValue、LongVectorValue 三级类型系统，支持 kNN 搜索（余弦、欧氏距离、内积）。
  - **动态知识生成**：区分**隐式关系**（如空间拓扑关系、Allen 时间区间代数关系、相似性关系，查询时计算、不持久化）和**派生关系**（如 CLIP embedding、OCR 转录、文档结构模型，按需计算并持久化存储）。
  - **外部服务**：通过 gRPC 连接外部 Python 模型服务器（如 CLIP、OCR、transformer 模型），将特征提取能力无缝集成到查询流程中，用户无需区分数据是否已物化。

## 6. 论文的主要结论与发现

- 通过 MediaGraph 数据模型，将多媒体文档及其分段作为一等图节点集成，验证了“内容感知”范式的可行性和价值。
- MeGraS 作为开源原型实现，成功扩展了 SPARQL 以支持原生多媒体操作（特征相似搜索、动态分段、时空推理），使用户能够在统一平台中完成多模态数据的存储、管理与表达性查询。
