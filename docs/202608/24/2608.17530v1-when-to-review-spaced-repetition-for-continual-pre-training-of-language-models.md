## 摘要
大型语言模型的持续预训练必须在获取新信息的同时不遗忘旧知识。现有的回放方法通常选择全局的旧/新混合比例并均匀采样，忽略了不同样本被遗忘的速度各不相同。我们将持续预训练形式化为自适应复习调度：训练循环不仅应决定回放多少历史数据，还应决定每一步应返回哪些样本。我们引入了间隔重复训练（SRT），这是一种受认知科学启发的持续学习框架，使用SuperMemo-2（SM-2）算法来调度样本复习。SRT维护每个样本的复习状态，将每个样本的困惑度映射为回忆质量信号，并调度历史样本以促进保留、新样本以促进巩固，同时保持模型、目标和优化器不变。在时间分离的维基百科和代码语料库上，SRT改善了稳定性-可塑性权衡，在不同模型规模下恢复了朴素持续预训练所损失的旧知识准确率的5到37个百分点，同时保持或提高了新知识的获取。在更大规模上，SRT保持了广泛的基准性能，而朴素持续预训练和均匀回放则显著下降。针对视觉和表格数据的实验进一步表明，当与适当的回忆信号配对时，该调度原则可扩展到语言之外。

## Abstract
Continual pre-training of large language models must acquire new information without erasing old knowledge. Existing replay methods often choose a global old/new mixture and sample uniformly, ignoring that examples differ in how quickly they are forgotten. We formulate continual pre-training as adaptive review scheduling: the training loop should decide not only how much history to replay, but which examples should return at each step. We introduce Spaced Repetition Training (SRT), a continual learning framework inspired by cognitive science, which schedules sample-rehearsal using the SuperMemo-2 (SM-2) algorithm. SRT maintains per-example review state, maps per-example perplexity to a recall-quality signal, and schedules historical examples for retention and new examples for consolidation while leaving the model, objective, and optimizer unchanged. On temporally separated Wikipedia and code corpora, SRT improves the stability-plasticity trade-off, recovering 5 to 37 percentage points of old-knowledge accuracy lost by naive continual pre-training across model scales while preserving or improving new-knowledge acquisition. At larger scale, SRT preserves broad benchmark performance that naive continual pre-training and uniform replay substantially degrade. Experiments with vision and tabular data further suggest that the scheduling principle extends beyond language when paired with an appropriate recall signal.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- **持续预训练（CPT）的挑战**：大语言模型在预训练后会持续更新，以吸收新事实、适应软件生态演进或加入新领域语料。然而，直接用新数据继续训练会导致**灾难性遗忘**（catastrophic forgetting），即模型在获取新知识的同时丢失旧知识。
- **现有回放方法的不足**：回放（replay）是常用的缓解遗忘策略，但现有方法大多是**混合层级**（mixture-level）的——只决定旧/新数据混合比例，然后对旧样本**均匀采样**或按固定课程采样。这种做法忽略了不同样本的**遗忘速度差异**——有些样本复习一次即可长期保留，有些则很快被干涉冲散。均匀回放可能把预算花在已记牢的样本上，而忽略了真正脆弱的样本。
- **核心洞察**：将持续预训练视为**自适应复习调度问题**——不仅要决定回放多少旧数据，更要决定**每一步应该回放哪些具体样本**。该思路受人类记忆研究中**间隔重复**（spaced repetition）和**难度自适应记忆巩固**（Ebbinghaus, 1885; Cepeda et al., 2006）的启发。

## 2. 论文提出的方法论

**核心思想：**

- 论文提出**间隔重复训练（Spaced Repetition Training, SRT）**，一个“即插即用”的持续预训练调度器。它借鉴认知科学中的**SuperMemo-2（SM-2）算法**（Wozniak, 1998）——该算法原本用于安排人类记忆复习计划——将其适配到语言模型训练中。

**关键技术细节：**

- **每个样本维护复习状态**：每个可回放样本 $x_i$ 关联一个状态 $s_i(t) = \langle E_i(t), n_i(t), I_i(t), d_i(t) \rangle$，其中：
  - $E_i$：**间隔增长因子**（ease factor），控制复习间隔增长速度；
  - $n_i$：连续成功复习次数；
  - $I_i$：当前复习间隔（以训练步数为单位）；
  - $d_i$：下次到期步数（due step）。
  - 初始值设为 $E_i = 2.5$，$n_i = 0$，$I_i = 1$，初始到期时间在前几步内均匀交错，避免所有样本同时复习。
- **到期集采样**（Due-set sampling）：每个训练步 $t$，分别从旧数据 $D_{old}$ 和新数据 $D_{new}$ 中选出到期样本集合 $M_t^{old}$ 和 $M_t^{new}$（即 $d_i \le t$ 的样本）。批次中 $\lfloor \rho B \rfloor$ 个槽位分配给到期旧样本，其余给到期新样本（$\rho \in [0,1]$ 是旧数据暴露比例）。若某一侧到期集为空，预算释放给另一侧，避免阻塞训练。
- **困惑度→回忆质量映射**：对每个被选中的样本 $x_i$，在标准前向传播中计算其**逐样本困惑度** $\text{PPL}_i(t) = \exp(L_i(t))$（$L_i$ 是 token 平均负对数似然），再通过单调递增阈值 $0 < \tau_5 < \tau_4 < \tau_3 < \tau_2 < \tau_1$ 映射为 SM-2 的离散回忆质量评分 $q_i(t) \in \{0,1,2,3,4,5\}$：

$$q_i(t) = \max\left(0, \, 5 - \sum_{k=1}^{5} \mathbb{1}[\text{PPL}_i(t) \ge \tau_k]\right)$$

- **关键细节**：$q_i(t)$ 反映的是**当前更新前**模型对该样本的保留程度（用当前前向传播的损失），而非更新后拟合程度。低困惑度→高质量→间隔拉长；高困惑度→低质量→间隔缩短。
- **SM-2 状态更新规则**：
  - 间隔因子更新：$\Delta(q_i) = 0.1 - (5-q_i)[0.08 + 0.02(5-q_i)]$，$E_i \leftarrow \max(1.3, E_i + \Delta(q_i))$；
  - 若 $q_i < 3$，视为**遗忘**，重置 $n_i = 0$、$I_i = 1$，立即安排重审；
  - 否则 $n_i$ 递增，间隔更新为：$I_i = 1$（$n_i=1$）、$I_i = 6$（$n_i=2$）、$I_i = \lceil I_i E_i \rceil$（$n_i > 2$）；
  - 下次复习时间设为 $d_i \leftarrow t + I_i$。
- **对称应用于新旧样本**：SRT 对旧样本（决定回放时机）和新样本（决定巩固时机）使用同一套调度逻辑。
- **不改变模型架构、目标函数和优化器**：模型参数 $\theta$ 仍然用标准 next-token 交叉熵损失更新；SRT 只是改变每个批次中**选择哪些样本**。
- **非生成式模型的适配**：对于困惑度不适用场景（如分类模型），可以用预测类别的置信度 $\hat{p}_\theta(y_i|x_i)$ 替代困惑度作为回忆信号，其余 SM-2 逻辑不变。

## 6. 论文的主要结论与发现

- **朴素 CPT 导致严重遗忘**：TinyLlama 在 Wikipedia 上旧准确率从 BASE 的 54.3% 暴跌至 11.7%，同时新知识只从 13.1% 提升到 17.0%。
- **调度的贡献是核心，而非暴露量本身**：SRT 和 Uniform Replay 共享同样的 20/80 暴露上限，唯一的区别是池内选择是否被调度。在 TinyLlama Wikipedia 上，这一变量造成了 23.8 个百分点的旧知识差距（49.0% vs. 25.2%）。结论是：**看似充足的回放预算，若在异质难度的样本上均匀分配，可能仍然失效**。
- **SRT 在保留与获取两方面都优于基线**：SRT 在 Wikipedia 上恢复到或超过 BASE 的旧知识水平，同时匹敌或超过 CPT 的新知识获取；在 code 上是唯一同时在旧和新上超过 CPT 的方法。恢复旧知识损失 5-37 个百分点。
- **均匀回放可能损害推理能力**：在 Llama-3.2-3B 上，UNIFORM REPLAY 将 BBH 从 53.9% 降至 8.4%，GSM8K 从 77.6% 降至 6.8%，比完全不回放还差；而 SRT 保持 52.6% 和 76.7%。这提示：未经良好设计的回放可能引入比无回放更严重的干扰。
- **间隔调度优于单纯难度优先**：PPL-Prioritised 虽然比均匀采样有更高新知识获取（Wikipedia 上 38.8%），但旧知识恢复远不如 SRT（27.4% vs. 49.0%）。间隔调度能够在“中间难度”样本上持续复审，而贪婪难度优先忽略这些样本。
- **调度原则可跨模态泛化**：视觉和表格数据上用分类置信度替代困惑度后，SRT 在所有四个数据集上取得最高的总体准确率。
- **计算开销可控**：SRT vs. CPT 总开销约 15% 墙钟时间，其中 3.5% 是调度本身，10.8% 是回放本身的构建成本。

## 7. 优点

- **问题重构富有洞察力**：将持续预训练从“混合比例问题”重新定义为“样本级调度问题”，直接针对样本间的遗忘异质性，概念上清晰有力。
- **方法简洁且通用**：SRT 不改模型、不改损失、不改优化器，只是调度批次中的样本选择；可作为独立的“调度层”与现有方法（学习率重加热、数据混合选择、参数高效微调、合成回放等）正交组合。
- **归因严谨**：通过严格匹配 Uniform Replay 的暴露比例和池结构来隔离调度本身的贡献；通过 PPL-Prioritised 来区分难度优先和间隔调度。
- **消融系统**：对回放预算、阈值缩放、初始间隔因子三个关键设计选择均做了敏感性分析，并验证了默认值（20/80、$\alpha=1.0$、$E_0=2.5$）的合理性。
- **跨模态验证**：用分类置信度替代困惑度，在视觉和表格数据上重现主结论，增强了方法的一般性。
- **关注部署场景**：选择从指令微调 checkpoint 开始持续预训练，与现实中的模型更新场景一致。
- **计算开销透明**：明确量化了 SRT 引入的额外开销，并指出其中大部分来自回放本身的构建而非调度逻辑。

## 8. 不足与局限

- **实验规模有限**：语言实验限于 1.1B 和 3B 两个 Llama 家族模型；更大参数量、其他模型家族、多语言场景均未验证。
- **训练方差未量化**：Table 2 的结果缺乏多次训练运行的方差估计，结论的说服力打折扣。
- **基准覆盖面与新颖性**：广泛的推理基准（MMLU、BBH、GSM8K、PIQA）在 TinyLlama 上近乎随机水平，难以检测出显著差异；TemporalWiki 的评估因快照日期早于模型知识截止，只能作为保留率检查，无法检验新知识获取。
- **阈值需人工校准**：困惑度到回忆质量的固定阈值（$\tau_5=50$ 至 $\tau_1=5000$）对模型规模和领域敏感，论文通过消融说明需要调整，但未提出自适应校准的方法。
- **任务受限**：当前语料只覆盖维基百科和代码，未覆盖对话、结构化知识库、多模态数据等持续预训练更广泛场景。
- **工程部署风险**：回放的前提是存储历史数据，需要考虑数据保留政策、删除请求和数据治理义务（论文在 Ethics 部分自行声明了这一点）；此外 SRT 额外一次前向传播的开销在超大规模部署中可能被放大。
- **潜在偏差风险**：构建 QA 时使用了 LLM 辅助生成并有手工检查，但基准仍可能带有生成偏差；同时论文明确声明不公开精确工件与代码，仅提供了可复现的描述性信息，可复现性存在一定风险。
