## 摘要
我们引入了预测状态检索（PSR）任务，在该任务中，模型观察一个短视频前缀和一个关于对象未来状态的时间问题，然后从其他视频或图像中检索描述该状态的实例。与预测标签的动作预测、在视频中定位已观察事件的时刻检索或合成像素的视频生成不同，PSR将预测与跨多个时间视野的跨实例检索相结合。我们从四个数据集构建了一个基准，具有分级、人工验证的真实标注、难度级别和预言机上限。我们还提出了LFTR，一种轻量级检索器，使用冻结编码器，预测一个问题和视野条件的未来潜在表示，并在互补的语义和视觉空间中匹配它。上限分解揭示了一个明显的瓶颈：一旦指定了真实未来状态，它很容易被检索到，而我们评估的每个预测器（包括能够访问前缀帧的大型多模态语言模型）仍远低于预言机。因此，预测而非感知是核心的可学习挑战。LFTR以显著更低的推理成本缩小了这一差距，消融实验将其改进归因于跨空间融合和难负样本训练，而非潜在展开。我们发布了基准、代码和评估脚本。

## Abstract
We introduce Predictive State Retrieval (PSR), a task in which a model observes a short video prefix and a temporal question about an object's future state, then retrieves instances from other videos or images that depict that state. Unlike action anticipation, which predicts a label, moment retrieval, which localizes an observed event within a video, or video generation, which synthesizes pixels, PSR combines anticipation with cross-instance retrieval across multiple temporal horizons. We construct a benchmark from four datasets with graded, human-validated ground truth, difficulty tiers, and an oracle ceiling. We also propose LFTR, a lightweight retriever with frozen encoders that predicts a question- and horizon-conditioned future latent and matches it in complementary semantic and visual spaces. A ceiling decomposition reveals a clear bottleneck: the true future state is highly retrievable once specified, whereas every predictor we evaluate, including a large multimodal language model with access to the prefix frames, remains far below the oracle. Thus, forecasting rather than perception is the central learnable challenge. LFTR narrows this gap at substantially lower inference cost, and ablations attribute its gains to cross-space fusion and hard-negative training rather than latent rollout. We release the benchmark, code, and evaluation scripts.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：现有视频理解研究在处理"预测未来 + 跨实例检索"这一结合能力上存在空白。人类看到玻璃杯从桌边滑落时，能预判其将摔碎，并在脑海中回忆起其他场景中同样"摔碎"的画面——这种从已观察到的前缀中**预测对象未来状态**，并**从其他视频/图像中检索出该状态的具体实例**的能力，尚未被任何现有任务覆盖。
- **现有任务局限**：
  - **动作预测（Action Anticipation）**：预测未来标签，但将未来压缩为固定类别，而非开放实例集。
  - **时刻检索（Moment Retrieval）**：检索的目标是**已发生**的描述时刻，且限定在单个视频内。
  - **组合/跨实例检索（Composed/Cross-instance Retrieval）**：可在实例间匹配，但查询是当前状态，而非预测的未来。
  - **世界模型（World Models）**：预测未来但保持潜在且内部化，从不呈现匹配证据。
- **论文提出的任务**：**预测状态检索（Predictive State Retrieval, PSR）**——给定视频前缀和时间问题，从其他视频和图像语料库中检索描述对象预测未来状态的实例。该任务具有两个独特难点：(1) 目标未被观察到，预测随时间视野增长而更加不确定；(2) 答案存在于不同视频中，必须按**语义含义**而非**外观**匹配。"预测"与"跨实例语义检索"的**结合**正是其新颖性所在。

## 二、论文提出的方法论

### 2.1 核心思想
- 遵循人类的两步思维过程："先预测，再按语义回忆"。将**预测（未来状态）**与**检索（跨实例匹配）**解耦，并通过"天花板分解"（ceiling decomposition）证明：**预测是核心可学习瓶颈，而非感知**。

### 2.2 LFTR 方法（Latent-Rollout Retriever）
- **整体架构**：冻结编码器 + 轻量可训练头（约 1200 万参数）。
  - 冻结视频编码器 E 将 8 帧前缀映射为 tokens；小型 Transformer 形成上下文，初始化潜在状态。
  - 问题通过 `q_c = W_q BGE(question)` 嵌入。
- **潜在轨迹滚动**（公式）：
  - 状态转移：`s_{j+1} = s_j + Φ_θ(s_j, h̄, q_c)`，j = 0, …, H−1
  - 在查询视野处读取：`μ_h = W_o s_h`
  - 不确定性建模：采样 K 个样本 `z_k = μ_h + σ_θ(h) ε_k`，用多查询最大相似度评分。
- **跨空间融合（Cross-space Fusion）**：在**语义空间**（BGE 文本状态空间）和**视觉空间**（DINOv2 图像空间）分别运行检索，对逐项分数进行 z-score 标准化后融合——这是最强配置。
- **训练目标**：多查询 InfoNCE 损失，使用随机负样本 + **硬负样本**（嵌入空间中与正样本相似但错误的未来状态，从 21.8 万段跨实例语料中挖掘），并添加将 μ_h 锚定到真实状态嵌入的 grounding 项。
- **重要说明**：论文诚实指出，多步滚动（rollout）**并非性能增益来源**——在相同训练条件下，H=8 完整轨迹与 H=1 单步视野条件读取统计上无显著差异（p=0.54）。增益来自未来状态头部、硬负样本视觉训练和跨空间融合。

## 三、实验设计

### 3.1 Benchmark 构建
- **数据来源**：四个视频域数据集——HOWTOCHANGE、OOPS、SSv2、MOST；可选图像语料为 Visual Genome + MIT-States（33.3 万张图像）。
- **规模**：20,182 个查询（训练/验证/测试 = 14,390 / 2,996 / 2,796），来自 5,061 个前缀，1,448 个源视频片段；主检索语料为 218,276 个视频片段，含 51,362 个去重谓词状态。
- **问题类型**：五种——Q1 下一状态、Q2 最终状态、Q3 k 秒后状态、Q4 中间状态、Q5 多对象联合状态；预测视野为 1–7 步。
- **难度分级**：真实标注按位置分为 in-video（自身视频，最易）、in-dataset（同域不同视频）、cross-dataset（跨域，最难的泛化测试）。主基准排除 in-video 层以强制跨实例预测。
- **质量验证**：VLM（Gemini-2.5-Flash）自动挖掘 + 多轮独立验证 + 五名人工标注者审计（GT 精度 89.4%，Fleiss κ=0.76）；跨模型校验（Gemini-3-Flash）与人类一致率达 93.4%。

### 3.2 对比方法
- **朴素基线**：随机、仅问题、kNN-future、持久性（未来=当前帧）、文本预测器。
- **零样本基线**：多种冻结编码器的零样本检索（Qwen-VL、SigLIP、InternVideo2、LanguageBind、DINOv2、CLIP、V-JEPA2、LingBot）。
- **MLLM 基线（M3）**：Qwen3-VL-32B 零样本预测（与 GT 生成器 Gemini 不同家族，避免同族偏差）；另测试 LLaVA、LLaVA-NeXT-Video、27B 编码 VLM 等。

## 六、主要结论与发现

1. **预测而非感知是核心瓶颈**：语义 oracle 天花板 R@5 为 53.0，几乎在所有视野上平稳；独立外观 oracle 仅 5.7（原始像素无法跨实例匹配语义状态）；最强学习预测器仅达 16–18。32B MLLM 仅 11.9，LLM 规模阶梯（7B→32B）仅 6.5→9.3——感知和规模都不是缺失要素。
2. **LFTR 以极低成本显著优于 M3**：LFTR 融合达 R@5 16.1±1.0，显著超过 32B MLLM（+4.81pp，p<10⁻⁴），参数仅约 1200 万，推理快四个数量级。
3. **增益来源为跨空间融合和硬负样本**：跨空间融合提升约 3.3pp（互补性而非数量是关键，4 空间融合达 18.6±0.6）；视觉空间硬负样本带来显著 +3.9pp 增益（语义空间中性）；问题条件、grounding、不确定性头、展开深度均仅在种子噪声范围内。
4. **多步展开机制被证伪为增益来源**：H=8 与 H=1 无统计差异；但展开轨迹仍有 ±4.3/4.8pp 未开发信号，是基准暴露的开放问题。
5. **预测差距的可学习部分约 14pp**：通过释义 oracle 分解检索通道，自由形式预测器可实现的上限约 30（而非 53），因此 16→30 是真正的可学习预测差距。
6. **跨数据集泛化是诚实考验**：in-video 层由外观持久性解决（R@5 75.2），跨数据集层仅约 8.4——语义泛化仍有巨大空间。
7. **图像模态对动态状态检索困难**：即使 oracle 在图像语料上也仅 8.9，因"坠落""被推"等动态状态难以在静态图像中充分表达。

## 七、优点

1. **任务新颖且动机清晰**：PSR 统一了预测与跨实例检索，填补了现有任务的实质性空白；与各邻域任务的差异分析系统透彻（Table 1）。
2. **基准设计严谨**：
   - 分级 GT（难度层 × type1/type2 × consensus 池）支持多角度鲁棒性检验；
   - 无时间泄漏保证（前缀 100% 严格在目标状态之前）——构造性保证；
   - 人工验证（5 标注者）+ 跨模型自动校验双重保障 GT 可靠性；
   - oracle 天花板和外观下限的设计使"瓶颈在哪"可被清晰诊断。
3. **方法诚实且可解释**：LFTR 由已知组件（硬负样本 InfoNCE、z-score 融合）构成，明确不做新颖预测器宣称；通过天花板分解实现了"方法—上限"差距的可测量化。
4. **消融实验严谨**：主动报告无效结果（rollout 无增益、前缀融合有害、LoRA 微调仅在噪声内），避免了夸大方法的常见问题。
5. **公平性考量周到**：M3 与 GT 生成器不同家族（排除同族亲缘偏差）；通过多项压力测试验证 MLLM 对比公平性。
6. **资源可复现性**：全量数据、代码、评估脚本、预计算特征索引均发布，预算极低（约 6 GPU 小时即可复现完整扫描）。

## 八、不足与局限

1. **单生成器作者偏差**：状态、问题和 GT 候选均由单一 VLM（Gemini-2.5-Flash）生成，其措辞惯例可能塑造 GT；跨家族完全重写留作未来工作（论文已明确承认）。
2. **外观下限部分由构造决定**：GT 按共享语义状态连接实例，外观 oracle 低分反映"无法恢复语义状态 GT"，而非对假设的视觉定义 GT 的断言——"外观无法解决 PSR"需要在此限定下解读。
3. **天花板划分不精确**：两个语义 oracle 均轻微乐观（作者自审），因此方法—上限差距的预测/检索误差精确拆分未建立。
4. **人工研究范围有限**：仅 500 个查询 × 5 名内部标注者；未做分层逐层审计；**没有测量人类在检索任务上的实际表现**，所以 16→53 的余量是 oracle 界，而非人类可达成目标。
5. **泛化范围受限**：跨源迁移仅在四个域内，非留一域泛化研究。多对象联合预测、远视野预测、图像动态状态桥接均为开放问题。
6. **远视野统计功效不足**：h=4/h=5 测试子集较小（n=109/49），相关显著性检验不显著，结论需谨慎。
7. **方法局限**：冻结前缀编码器虽非瓶颈，但 LoRA 微调增益甚微（+0.4–0.5pp）；多步 rollout 被证明无效后，方法未提出替代的远视野预测机制——距离 oracle 仍有约 35pp 的差距。

---

**总体评价**：这是一篇任务设计、基准构建与方法验证均十分扎实的工作。其核心贡献在于**清晰地界定了一个新任务（PSR）并通过天花板分解科学地定位了关键瓶颈（预测）**，同时提供了一个低成本强基线（LFTR）和一系列可操作的开放问题。论文在实验设计上的诚实与严谨（主动报告负结果、多角度公平性验证）尤其值得肯定；主要短板在于单生成器偏差和缺少人类表现基准，但作者对此均有透明披露。
