## 摘要
近期视觉语言模型（VLMs）通过将视觉令牌与文本相结合，增强了预训练大语言模型的能力，其中LLaVA等方法展现了令人印象深刻的结果。然而，处理多达576或729个视觉令牌的计算负担使得边缘部署面临挑战。虽然各种令牌剪枝技术需要重新训练，但有些方法无需训练，因此能够轻松适应架构变化。我们引入了ClustRS，一种两部分的、无需训练的鲁棒令牌剪枝算法。其第一部分是一种注意力加权的聚类算法，从每个语义簇中选择代表性令牌。第二部分是残差收缩（Residual Shrinkage），即对选定令牌进行的一遍去噪步骤。这些无需训练的轻量级步骤使LLaVA能够应对真实世界数据，提高了对多种图像噪声类型和强度的鲁棒性。在ScienceQA-IMG和MM-VET基准上的实验结果表明，在极端噪声和令牌条件下（将令牌减少97%，降至16个令牌），我们的方法在LLaVA 1.5 7b上比基于注意力和多样性的方法最多高出20%，并在LLaVA-OneVision上取得了卓越成果，在轻微噪声条件下，我们使用不到其三分之一的令牌即可匹配基线性能。我们的研究表明，仅基于分数和仅基于多样性的剪枝规则之外，存在一种简单而强大的替代方案，为计算高效且抗噪声的VLM部署铺平了道路。

## Abstract
Recent Visual-Language Models (VLMs) have enhanced the capabilities of pre-trained LLMs by adding vision tokens alongside text, with approaches like LLaVA showing impressive results. However, the computational burden of processing up to 576 or 729 visual tokens makes edge deployment challenging. While various token pruning techniques require retraining, some are training-free and thus can easily adapt to architecture changes. We introduce ClustRS, a two-part, training-free algorithm for robust token pruning. Its first component is an attention-weighted, clustering algorithm that selects representative tokens from each semantic cluster. The second component, Residual Shrinkage, is a one-pass denoising step on the selected tokens. These training-free lightweight steps make LLaVA ready for real-world data, improving robustness to a wide range of image-noise types and intensities. Experimental results on the ScienceQA-IMG and MM-VET benchmarks show our method outperforms attention- and diversity-based methods by up to 20\% under extreme noise and token conditions (reducing tokens by 97\%, down to 16 tokens) on LLaVA 1.5 7b and achieves exceptional results on LLaVA-OneVision, where we match baseline performance with fewer than one-third of their tokens under mild noise conditions. Our study demonstrates a simple yet powerful alternative to both score-only and diversity-only pruning rules, paving the way for compute-efficient and noise-resilient VLM deployment.

## 2. 论文提出的方法论

- **总体框架**：ClustRS 算法由两个训练免费的组件构成：
  1. **C+H（Clustering + Huber distance，聚类+Huber距离）**：用于从所有视觉 token 中选出若干语义簇的代表性 token。
  2. **RRS（Robust Residual Shrinkage，鲁棒残差收缩）**：对选出的 token 进行一次性的去噪增强。
- **C+H 的细节**：
  - 在视觉-语言投影层之后的特征空间中聚类，使聚类结果直接反映 LLM 自身对语义关系的理解。
  - 使用**注意力加权的 k-means++**：以 [CLS] token 的自注意力分数作为每个 token 的重要性权重；第一个质心选取最高注意力 token，后续质心按“注意力 × 距离”的概率采样。
  - 将 k-means 目标中的欧氏距离替换为 **Huber 距离**，从而降低噪声离群值对质心的拉扯，提升聚类鲁棒性。
  - 聚类迭代次数很少（I ≤ 3），初始化后就近分配、注意力加权更新质心，最后从每个簇中取出注意力最高的 token 作为代表。
- **RRS 的细节**：
  - 每个选中 token 可表示为“簇质心 + 残差”；噪声主要存在于残差中。
  - 利用簇内中位绝对距离作为鲁棒尺度估计，计算自适应收缩系数 α（使靠近质心的 token 几乎不变，远离质心的 token 向质心收缩；α 被裁剪到 [0.1, 0.95]）。
  - 最终增强 token 为原 token 与质心的凸组合，因而保留原语义方向，不产生分布偏移。
  - 该方法受 James–Stein 估计器启发，但将收缩中心从原点改为数据驱动的簇质心，属于经验性适配。
- **针对 SigLIP 的适配（LLaVA-OneVision）**：由于 SigLIP 的注意力分布比 CLIP 更平坦，论文在注意力分数中引入“范数奖励”项（`s_i = a_i + λ·max(0, ||v_i|| - μ_||v||)`），以恢复显著性排序的动态范围，其余流程不变。

- ClustRS 在 MM-VET 和 ScienceQA-IMG 上整体优于 FasterVLM、DivPrune 和 VisionZip，尤其在**极端压缩（k=16）与高噪声**条件下优势明显；例如在 σ=3.0 时，k=16 下较基线最高提升约 1.5 个百分点（相对提升约 11%），论文宣称在极端条件下最高可提升 20%。

- 整个流程训练免费、开销极低，且与 KV-cache、flash-attention 等推理优化兼容，适合边缘部署。

## 7. 优点

- **训练免费、即插即用**：无需任何微调，可直接用于现有 VLM 推理流程。
- **兼顾注意力与多样性**：C+H 在聚类中同时利用注意力显著性和特征空间覆盖面，弥补了“仅看分数”和“仅看多样性”两类方法的缺陷。
- **抗噪设计扎实**：Huber 距离抑制离群值影响，RRS 受 James–Stein 理论启发并采用自适应收缩；对真实噪声来源（模糊、JPEG、遮挡等）也有增益。
- **轻量高效**：额外计算仅为 O(kD) FLOPs，与整体 LLM 生成耗时相比几乎可忽略。
- **可扩展性**：通过简单的范数奖励适配即可迁移到 SigLIP 类新骨干网络。

## 8. 不足与局限

- **RRS 的适用条件受限**：在严重高斯噪声且 token 预算较大时，RRS 可能反而降低性能；论文也承认需要自适应机制来调节收缩强度。
- **空间信息被忽略**：基于语义聚类可能丢弃空间位置不同但语义相似的 token，对细粒度定位和空间关系推理可能有负面影响。
- **对比范围有限**：未与训练型 token 压缩方法（如 Honeybee、TokenPacker、TwigVLM）比较；无法全面说明相对于有监督方法的优劣。
- **评测集限制**：ScienceQA-IMG 本身对视觉细节不敏感，各方法差距较小；MM-VET 的评测器替换也可能导致与既有文献中的分数不完全可比。
- **噪声模拟的局限性**：虽然覆盖了多种常见噪声，但仍属于可控实验，不能完全代表所有真实世界的分布偏移。
