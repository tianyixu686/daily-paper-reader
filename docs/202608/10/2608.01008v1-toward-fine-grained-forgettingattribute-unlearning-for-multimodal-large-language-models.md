## 摘要
多模态大语言模型（MLLMs）展现出强大的视觉-语言能力，但也可能记忆并泄露敏感信息。机器去学习旨在无需从头重新训练的情况下移除指定知识，同时保留通用实用性。现有的隐私导向基准主要采用档案级删除，而实际请求往往更为细粒度：模型应忘记特定属性，同时保留同一身份的非敏感信息。因此，我们将属性级MLLM去学习引入为一项更细粒度的任务，并构建了一个涵盖长文本、数值和短文本目标、多种遗忘比例及多样化问题类型的基准。我们的评估揭示，目标属性和保留属性共享身份特定及视觉证据，使得选择性遗忘容易受到残留泄漏或附带性能下降的影响；因此，现有方法在此场景中表现出不稳定的遗忘-保留权衡。为应对这一挑战，我们提出了因果定位与保留感知投影（CLRP），一种轻量级且无需训练的框架。CLRP利用激活修补来识别因果关系中介目标属性披露的层，然后应用保留感知投影，在保留同一身份证据的同时移除目标属性子空间。跨多种广泛使用的、具有不同架构和参数规模的MLLMs的实验证明了CLRP的有效性。

## Abstract
Multimodal large language models (MLLMs) exhibit strong vision--language capabilities but may also memorize and disclose sensitive information. Machine unlearning seeks to remove designated knowledge without retraining from scratch while preserving general utility. Existing privacy-oriented benchmarks primarily adopt profile-level deletion, whereas practical requests are often finer grained: a model should forget a specified attribute while retaining non-sensitive information about the same identity. We therefore introduce attribute-level MLLM unlearning as a finer-grained task and construct a benchmark spanning long-text, numeric, and short-text targets, multiple forget ratios, and diverse question types. Our evaluation reveals that target and retained attributes share identity-specific and visual evidence, making selective forgetting susceptible to residual leakage or collateral degradation; accordingly, existing methods exhibit unstable forgetting--retention trade-offs in this setting. To address this challenge, we propose Causal Localization and Retain-Aware Projection (CLRP), a lightweight training-free framework. CLRP uses activation patching to identify the layer that causally mediates target-attribute disclosure, then applies a retain-aware projection that removes the target-attribute subspace while preserving same-identity evidence. Experiments across multiple widely used MLLMs with distinct architectures and parameter scales demonstrate the effectiveness of CLRP.

## 一、核心问题与整体含义

**研究动机：**
- 多模态大语言模型（MLLMs）在视觉问答、指令跟随、文档理解等任务上表现强大，但在大规模多模态预训练过程中可能记忆并泄露隐私敏感的身份信息。
- 现有机器去学习基准（如 MLLMU-Bench、FIUBench、CLEAR）均以"档案级/身份级"为删除单位：整份人物档案、整个虚构身份或整个角色被一次性抹除，评估时并不显式要求保留同一身份内部的单个非目标属性。
- 实际隐私请求往往更细粒度：用户可能只要求删除某个出生日期、地址式字段、数值标识、组织归属或传记描述，而同一身份的良性属性和视觉识别能力应当继续保留。

**论文引入的新任务：**
- 提出**属性级多模态去学习（Attribute-Level MLLM Unlearning）**：指定属性必须变得不可访问（包括在未见过的问题改写下），同时同一档案的非目标属性及无关多模态知识须得到保留。
- 这比档案级删除施加了更严格的选择性要求：因为在数据层面，目标属性和保留属性共享同一身份、同一图像和相近的提示结构；在表征层面，二者可能位于表征空间中的邻近区域，并经由重叠的因果通路被路由，导致"删除与保留之间的边界"极难界定。

## 二、方法论：CLRP 框架

**总体定位：**
- CLRP（Causal Localization and Retain-Aware Projection，因果定位与保留感知投影）是一种**无需训练**的轻量级去学习框架，所有模型参数保持固定。
- 由两个组件构成：先确定"在哪里干预"（因果层定位），再确定"衰减哪些表示方向"（保留感知投影）。

### 1. 因果层定位（Causal Layer Localization）

- 将目标查询（target query，关联目标属性答案）与同一身份的保留查询（retain query，涉及非目标信息）配对，形成对照运行。
- 借鉴激活修补（activation patching）思路：缓存目标运行的激活，并将其修补到保留运行中，计算目标答案证据的恢复量：

\[
\Delta_{i,\ell,u} = m_i\left(x_i^r;\, a_{\ell,u} \leftarrow a_{i,\ell,u}^f\right) - m_i(x_i^r)
\]

- 遍历候选层（实验中为层 12–30）和注意力头，选择平均修补效应最大的层作为干预层。被选中的头仅作为层选择的证据，不修改任何注意力参数；后续干预作用于该层的完整隐藏状态。

### 2. 保留感知对比投影（Retain-Aware Contrastive Projection）

- 在选定层构造对比特征：目标条件化表征与其参考运行的差异构成目标统计量 \(F\)；同一身份的非目标属性、辅助保留数据及中性图像提示特征构成保留统计量 \(R\) 与档案共享统计量 \(C\)。
- 先从 \(F\) 中移除由 \(R\) 和 \(C\) 识别的共享方向，得到 \(\tilde{F}\)，再计算目标与保留特征的正则化二阶矩 \(S_f\) 与 \(S_r\)。
- 通过白化变换 \(W = Q\Lambda^{-1/2}Q^\top\)（源自 \(S_r = Q\Lambda Q^\top\)）将每个方向按其在保留表征中的方差归一化，从而将目标变化相对保留变化进行排序：

\[
U_k = \mathrm{eig}_k(W S_f W), \quad V = \mathrm{orth}(W U_k)
\]

- 得到衰减算子 \(P = (1+\epsilon)I - VV^\top\)；推理时通过前向钩子将选定层输出替换为 \(h' = hP\)（配合状态相关的插值强度调度）。\(k\) 控制子空间秩，\(\epsilon\) 控制衰减系数（实验中 \(k=20\)、\(\epsilon=0.01\)）。

## 三、实验设计

**基准构建（AMU-Bench）：**
- 以 MLLMU-Bench 的虚构档案为数据来源，但将监督信号重构到"档案-属性"粒度，而非直接复用档案级问题。
- 使用受约束的 GPT 流水线为每个可用的档案-属性对生成/修复生成式、完型式（cloze）和分类式三类问题；设计结构与跨任务一致性检查以触发不一致输出的再生成。
- 属性按值结构分为三个类别：
  - **长文本**（16 个属性）：如兴趣爱好描述、食物偏好、父母背景等，信息分布于描述性内容中；
  - **数值**（4 个属性）：如出生日期、年薪、身高，需要恢复特定数值序列；
  - **短文本**（6 个属性）：如出生地、性别、职业、教育机构、居住地、医疗状况，为紧凑的分类型值。

**评估视图（5 个）与指标：**
- Attribute Forget Set（目标属性遗忘，越低越好）
- Test Set（未见过改写下的目标属性恢复，越低越好）
- Attribute Retain Set（同身份非目标属性保留，越高越好）
- Shared Retain Set（未选中虚构档案的保留，越高越好）
- Real-Person Retain Set（外部真实人物知识保留，越高越好）
- 指标：完型准确率、分类准确率、生成 ROUGE-L，分别报告以避免聚合掩盖同档案附带损失。

**数据划分与问题类型：**
- 遗忘比例：5%、10%、15%
- 问题类型：生成、完型、分类三种接口，各 5 个评估视图均在所有模型上评测。

**对比方法（4 个训练型基线）：**
- Gradient Ascent（GA）
- Gradient Difference（GD）
- KL Minimization（KL）
- Preference Optimization（PO，NPO 风格）

**测试模型（3 个）：**
- LLaVA-1.5-7B、LLaVA-1.5-13B、Qwen2.5-VL-3B，覆盖两个架构家族与三种参数规模。

## 六、主要结论与发现

1. **属性类别间遗忘难度存在系统性差异**：数值属性在所有基线下平均 Forget Set 完型准确率仅 0.33%，比短文本（15.00%）和长文本（20.00%）低一个数量级以上，证实属性类型是必要的评估维度。
2. **同一身份内的保留比跨身份保留更难**：在 LLaVA-1.5-7B 上，15 组方法-属性比较中，Attribute Retain Set 性能在完型、生成、分类上分别有 12、12、10 组低于 Shared Retain Set；表明现有目标在"目标与保留属性属于同一身份"时面临更严苛的保持挑战。
3. **CLRP 的有效性**：在 5% 结果中，与最强基线相比，最大遗忘提升为 Attribute Forget Set 完型准确率从 20.00% 降至 4.00%（下降 16.00 个百分点）；最大保留提升为 Attribute Retain Set 完型准确率从 14.77% 提升至 17.79%（上升 3.02 个百分点）。三类属性平均从 14.50% 降至 2.00%（遗忘集）、从 25.25% 提升至 29.76%（保留集）。
4. **CLRP 在所有 9 个模型-属性条件中的 8 个上取得最优 Forget Set 完型准确率，在 8 个条件上取得最优 Test Set 完型准确率**，并同时改善同档案保留，实现更好的遗忘-保留权衡。
5. **消融验证了两个组件的必要性**：因果定位优于固定层选择；移除保留感知几何虽能更激进地压制目标（ROUGE-L 降至 0.177/0.210），但保留性能大幅退化（Attribute Retain Set ROUGE-L 降至 0.300/0.281），验证了保留感知约束对避免附带损伤的关键作用。

## 七、优点

- **任务定义新颖且贴近实际**：首次将属性级去学习作为独立任务提出，弥合了"档案级删除"与真实细粒度隐私请求之间的鸿沟。
- **基准设计细致**：同一档案内构造 Forget 与 Retain 对照，使"同档案附带损伤"显式可测；属性按值结构分层，避免将不同类型目标混为一谈；三类问题接口 + 五个评估视图的组合覆盖了恢复路径的多样性。
- **方法轻量且优雅**：CLRP 无需参数更新，仅需激活修补定位 + 子空间投影，低算力开销、部署友好；将因果定位与保留感知融入一个统一框架，两个组件均有清晰的可解释性（"在哪干预" + "衰减什么"）。
- **实验严谨**：多模型、多比例、多类别、多维指标齐备；消融对照设计合理；各视图分开报告避免聚合偏差；超参数搜索结果与主实验一致，验证了配置稳定性。
- **结果具有一致性**：在 5%/10%/15% 三个遗忘比例下遗忘性能稳定（均值 1.33%、3.33%、1.33%），显示方法对删除规模不敏感。

## 八、不足与局限

- **数据规模与来源单一**：AMU-Bench 仅基于 MLLMU-Bench 的虚构档案，属性池仅 26 个（长文本 16、数值 4、短文本 6），类别分布不均衡；对真实世界复杂属性（如嵌套结构、跨属性依赖）的覆盖有限。
- **属性类别划分的任意性**：作者承认长/数/短三类是"操作性分层"而非通用语言学分类，不同属性类别间的难度差异可能与问题构造方式而非属性本质有关。
- **CLRP 在部分指标上非全面最优**：从附录表格看，CLRP 在分类准确率和部分生成 ROUGE-L 上并不总是最优（如 LLaVA-1.5-13B 数值类别的生成 ROUGE-L 为 0.402，高于基线但分类准确率与基线持平；某些条件下 Shared Retain Set 分类精度低于基线）；论文强调完型准确率，可能弱化了其他指标的波动。
- **Real-Person Retain Set 上表现不稳定**：在 LLaVA-1.5-13B 上 CLRP 的真实人物保留分类精度明显低于部分基线（如 5% 长文本 36.03 vs GA 的 44.13）；Qwen2.5-VL-3B 上 CLRP 分类精度亦多低于 GA/KL，提示对模型规模/架构的泛化存在边界。
- **超参数敏感性隐忧**：消融显示将 \(\epsilon\) 从 0.01 增至 0.05 时遗忘性能下降（ROUGE-L 从 0.355 升至 0.379），将 \(k\) 增至 40 时保留几乎崩溃——说明 CLRP 的性能对秩与衰减系数较敏感，实际部署时需要针对性调参。
- **未报告训练时长与推理开销**：缺少与训练型基线的效率对比数据，CLRP 的"轻量"优势缺乏直接量化证据。
- **接口级输出空间抑制的公平性**：CLRP 在完型接口上对目标集直接减 logit（-4.0），虽为固定实现，但在跨方法比较中可能带来不公平优势，论文对这一点未做专门讨论或控制实验。
- **单一数据源与虚构身份**：对真实人脸/真实身份图像的隐私场景未做验证，从虚构档案到真实世界的迁移能力未知。
