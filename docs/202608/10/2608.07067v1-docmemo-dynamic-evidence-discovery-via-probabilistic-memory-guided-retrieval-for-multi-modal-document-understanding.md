## 摘要
长文档理解需要在数百页中定位稀疏且异质的证据，然而现有系统仍然受限于静态检索和脆弱的跨轮记忆。主流单轮方法一开始就固定top-k页面集合，难以从早期检索错误中恢复；最近的迭代方法允许多轮证据获取，但未研究跨轮状态的传播机制，难以跟踪页面相关性的动态变化。为解决这些局限，我们提出DocMemo，一个记忆引导框架，将长文档推理形式化为动态证据探索。DocMemo维护三级别检索状态，包括文档模式记忆、页面信念记忆和问题情景记忆，分别捕获结构先验、动态相关性估计和查询特定的推理轨迹。在推理过程中，DocMemo通过贝叶斯页面信念更新、汤普森采样、空间邻近传播和结构感知的自适应粒度证据访问，不断细化跨轮页面选择，同时用细粒度视觉区域补充页面级证据。在3个基准上的实验表明，DocMemo取得了最先进的性能，并验证了结构化记忆和动态页面信念更新的有效性。代码可在https://github.com/Harrygof/DocMemo获取。

## Abstract
Long-document understanding requires locating sparse and heterogeneous evidence across hundreds of pages, yet existing systems remain limited by static retrieval and fragile cross-round memory. Mainstream single-round methods commit to a fixed top-$k$ page set at the outset and struggle to recover from early retrieval errors; recent iterative approaches allow multi-round evidence acquisition, but they do not investigate the propagation mechanism of cross-round states, making it difficult to track the dynamic changes in page relevance. To address these limitations, we propose DocMemo, a memory-guided framework that formulates long-document reasoning as dynamic evidence exploration. DocMemo maintains a tri-level retrieval state consisting of Document Schema Memory, Page Belief Memory, and Question Episodic Memory, which respectively capture structural priors, dynamic relevance estimation, and query-specific reasoning trajectories. During reasoning, DocMemo continuously refines cross-round page selection through Bayesian page belief updating with Thompson sampling, spatial proximity propagation, and structure-aware adaptive-granularity evidence access, while supplementing page-level evidence with fine-grained visual regions. Experiments on 3 benchmarks show that DocMemo achieves state-of-the-art performance and validate the efficacy of structured memory and dynamic page belief updating. Code is available at https://github.com/Harrygof/DocMemo.

- **核心挑战**：长文档 DocVQA 要求模型在数十至数百页的文档中定位**稀疏、异质、分散**的证据，且证据可能以文本、表格、图表、视觉布局等多种模态呈现。受限于上下文窗口，模型的关键能力不是"通读"，而是**在有限证据预算下动态定位、更新并整合相关页面**。
- **现有方法的两大缺陷**：
  - **单轮静态检索**（如 RAG、多模态索引方法）：在推理前固定 top-k 页面集，一旦初始检索漏掉关键证据，后续推理无法修正，属于"刚性单次流水线"。
  - **迭代检索方法**（如 SimpleDoc）：虽允许多轮检索，但**缺乏跨轮状态传播机制**，跨轮信息仅靠上下文累积，本质上是"重复独立检索"，难以追踪页面相关性的动态变化。
- **核心洞见**：长文档证据获取应被建模为**结构化记忆引导的动态证据探索**过程，而非静态上下文累积。受认知科学中"互补学习系统"（稳定与快速变化信息分离）启发，DocMemo 将检索状态显式建模为三级别记忆，并引入贝叶斯不确定性建模，实现检索—推理—记忆更新的持续闭环。

## 2. 方法论：DocMemo 框架

### 2.1 核心思想
将长文档推理构建为**"检索—推理—记忆更新"**的动态循环，通过三级别文档记忆显式解耦**持久文档知识、动态页面状态、查询局部经验**，实现跨轮证据发现。

### 2.2 三级别文档记忆（Tri-Level Document Memory）
记忆状态表示为 ℳ(t) = (ℳ_schema, ℳ_belief(t), ℳ_epi(t))：

| 记忆级别 | 建模对象 | 具体内容 |
|---|---|---|
| **Document Schema Memory** (ℳ_schema) | 持久、查询无关的结构先验 | 文档类型τ、结构索引Σ（页面区间+主题标签）、全局摘要σ；**离线构建**，推理期间固定 |
| **Page Belief Memory** (ℳ_belief(t)) | 动态演化的页面相关性置信度 | 每页用 **Beta 分布** Beta(αi, βi) 建模；α/β 分别累积正/负反馈证据；随推理轮次在线更新 |
| **Question Episodic Memory** (ℳ_epi(t)) | 查询特定的推理轨迹 | 记录中间证据摘要、信息缺口分析、精化查询 { (nk, q̂k) }；仅在当前问答会话内更新 |

### 2.3 关键技术细节

- **页面信念初始化**：使用 ColQwen2.5 的 late-interaction 机制计算查询与页面的视觉相关性得分 ci，按 α(0)i = Sci + 1, β(0)i = S(1 − ci) + 1 转换为 Beta 先验（S=5.0 控制先验强度）。
- **贝叶斯页面信念更新**：基于 Beta-Bernoulli 共轭性，将推理器输出的 useful_pages（Ut）和 irrelevant_pages（Vt）转换为正负证据：α ← α + I[i ∈ Ut]，β ← β + I[i ∈ Vt]。后验均值 μi = αi/(αi+βi) 表示当前轮的累积相关置信度。
- **空间邻近传播**：对 Ut 中页面的相邻页（距离 ≤ r=2），按 γ^|j−i|（γ=0.5）衰减地增加 αj，利用证据在长文档中局部聚集的规律；负反馈不传播。
- **Thompson 采样驱动的候选页选择**：从每页后验 Beta 分布采样 θi，与当前轮查询视觉相似度 ci 按得分 score_i = (1−λt)ci + λtθi 融合（λ 从 0.0 递增到 0.6），实现**探索—利用权衡**，逐步从信任视觉相似度转向信任累积信念。
- **候选筛选与重排**：先取 top-Kc=30 候选页，LLM 结合文档模式记忆和问题情节记忆对页面摘要重排，选出最多 Kr=13 页，再按后验均值取 top-Kq=9 页送推理器。
- **自适应粒度证据访问**：对表格/图表密集页面，补充高分辨率局部视觉裁剪（最多 5 个表格裁剪/查询，长边 ≤1500px），缓解整页缩放导致细节丢失。
- **推理器决策**：三种输出——① 返回最终答案；② 返回 not_answerable；③ 生成精化查询+中间笔记+正负页面反馈，触发下一轮。最多 T=3 轮。

- **算力透明度有限**：论文未明确报告 GPU 数量、训练/微调轮数等关键资源信息，仅给出推理延迟与显存占用，难以完整评估系统总成本。

- **缺少跨语言/跨领域验证**：实验均基于英文文档，多语言场景下的检索与记忆更新表现未知。
