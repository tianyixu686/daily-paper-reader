## 摘要
现有的大多数多模态大语言模型（MLLMs）主要依赖图像-文本对进行模态对齐预训练，将全局图像表示映射到长文本描述。然而，这种图像级对齐存在指称歧义问题：模型难以从全局表示中推断多个视觉对象与文本实体之间的对应关系，导致数据效率低下和语义基础欠佳。为了解决这一问题，我们提出了多模态语码转换（MMCS），一种新颖的预训练范式，提供显式的对象级监督。受语码转换语言学现象的启发，MMCS 通过将文本实体替换为相应的视觉对象来交织视觉与语言，从而增强局部视觉-语言基础。我们进一步开发了一个可扩展的数据合成流水线，生成包含 77.3 万个样本、具有准确对象-实体对应关系的预训练数据集。实验表明，MMCS 具有很高的数据效率：仅使用 5 万个样本即可匹配甚至超越在 60 万图像-文本对上训练的模型。此外，MMCS 在不同模型规模上持续提升了视觉基础和感知能力。

## Abstract
Existing Multimodal Large Language Models (MLLMs) predominantly rely on image-text pairs for modality alignment pretraining, mapping global image representations to long textual descriptions. However, this image-level alignment suffers from referential ambiguity: models struggle to infer the correspondences between multiple visual objects and textual entities from the global representation, leading to data inefficiency and suboptimal semantic grounding. To address this, we propose MultiModal Code-Switching (MMCS), a novel pretraining paradigm that provides explicit object-level supervision. Inspired by the linguistic phenomenon of code-switching, MMCS interleaves vision and language by replacing textual entities with their corresponding visual objects, enforcing local vision-language grounding. We further develop a scalable data synthesis pipeline to generate a pretraining dataset of 773K samples with accurate object-entity correspondences. Experiments show that MMCS is highly data-efficient: with only 50K samples, it matches or surpasses models trained on 600K image-text pairs. Furthermore, MMCS consistently improves visual grounding and perception capabilities across varying model scales.

### 1. 核心问题与整体含义（研究动机与背景）

现有多模态大语言模型（MLLMs）的主流架构为 ViT-MLP-LLM，通常采用两阶段训练：先通过图像-文本对进行模态对齐预训练，再进行多模态监督指令微调（SFT）。当前预训练的主流做法是使用密集图像标注（dense captions）作为对齐信号，模型将整幅图像编码为全局表示，再基于该全局表示生成冗长的文本描述，这属于**图像级（image-level）对齐**。

然而，自然图像往往包含多个物体与背景元素（如论文统计所示，密集标注数据集中每个样本平均包含 6.8~11.0 个独立实体），而全局表示将整个场景压缩为单一特征，导致**指称歧义（referential ambiguity）**问题：模型被迫隐式地从全局表征推断"哪些文本短语对应哪个视觉区域"。这种"多对多"的隐式映射迫使模型依赖统计共现规律而非真正的语义接地，导致数据效率极低，需要大规模数据才能学习到鲁棒的对象-实体关联。

论文的总体意义在于：提出一种全新的预训练范式，将对齐粒度从图像级下探到**对象级（object-level）**，以显式监督化解指称歧义，从根本上提升多模态对齐的质量与效率。

### 2. 论文方法论

#### 2.1 核心思想：语码转换（Code-Switching）

论文从语言学中的"语码转换"现象获得启发——即在同一话语中交织两种或多种语言，且被切换的词汇必须与语境语义兼容。MMCS 将视觉对象与文本视为两种不同的"语码"，用视觉对象替换文本实体，强制模型在局部区域完成跨模态接地。

#### 2.2 方法框架

具体实现上，给定原始文本序列中一个连续的文本实体片段 e = [xi, …, xi+m]，提取与之对应的视觉对象表征 v_object（即与目标边界框空间相交的图像 token 集合），将文本实体替换为视觉对象 token，构建交织的图文序列：

- **序列构造**：X_MMCS = Concat(X_<i, v_object, X_>i+m)
- **语言建模损失**：仅在文本 token 上计算，视觉 token 作为生成后续文本的条件上下文。
- **实体重建损失**：额外在替换位置监督原文本实体的重建，即给定视觉对象特征与前置上下文，使模型还原对应的文本实体。

总目标函数为：**L_MMCS = L_LM + L_entity**，两项损失不重叠且互补——L_entity 作为语义锚点保证实体重建的精确性，L_LM 负责上下文整合。

#### 2.3 数据合成流水线

为了获得具备精确对象-实体对应关系的大规模预训练数据，论文开发了一条四阶段流水线：

1. **详细图像标注**：使用 Qwen3-VL-32B-Instruct 生成详尽描述全部可见元素及其属性的图像标注。
2. **文本实体提取**：使用 Qwen2.5-72B-Instruct 从标注中提取名词短语及属性描述（用于区分同类多实例对象）。
3. **视觉对象定位**：使用 Grounding DINO 将文本实体锚定到对应视觉区域，输出边界框、文本标签和置信度。
4. **多级过滤**：依据置信度阈值（框阈值 0.4、文本阈值 0.3）、边界框面积约束（不小于单个视觉 patch、不超过图像总面积的 50%）、以及 SAM-2.1 分割掩码面积占比（低于边界框面积 20% 的重遮挡对象被丢弃）等标准进行筛选。

最终生成包含 **773K 样本、约 514 万个视觉对象**的预训练数据集，样本平均包含约 6.65 个对象。VLM 评估与人工评估的平均接地准确率分别为 94.9% 与 94.2%。

### 6. 主要结论与发现

1. **数据效率显著提升**：MMCS 仅用 50K 样本即超越图像级基线的 600K 样本效果，验证了显式对象级监督的核心价值。
2. **视觉接地与感知能力持续提升**：在不同模型规模（3B/8B）与视觉编码器（SigLIP2/QwenViT）下，MMCS 在 RefCOCO 系列上平均提升 7.9%，在感知中心基准上平均提升约 2~4%。
3. **通用 VQA 获得较小的统计显著提升**（+1.67%，p=0.028），说明增强的视觉感知力可传导至下游推理。
4. **表示对齐质量更高**：CKA、CKNNA、Mutual k-NN 指标显示 MMCS 在大多数层上实现更好的跨模态表征对齐。
5. **注意力模式更精准**：注意力图显示 MMCS 模型的文本实体 token 能准确定位到目标视觉区域，而非弥散或错位。
6. **MMCS 优于其他细粒度对齐策略**：相比 patch 级方法（SEA、Patch Aligned）与符号化空间表示（Text BBox），以完整对象为对齐单元、以表征级绑定为手段的方法更有效。
7. **对象级监督信号可隐式传播**：虽然 MMCS 只替换名词短语，但也显著改善了动词与介词的预测（NLL 大幅降低），说明对齐信号可传播至动作与关系的学习。
8. **隐式 OCR 能力涌现**：自然对象中 10%~30.8% 含有可读文本，MMCS 的显式裁剪与对齐过程充当了隐式 OCR 训练目标。

### 7. 优点

- **范式创新性强**：受语言学语码转换启发，将"对象级对齐"融入预训练，而非依赖隐式全局表示，概念上新颖且具有很强的理论可解释性。
- **数据高效**：仅 50K 样本即可超越 600K 图像-文本对的预训练效果，大幅降低数据需求。
- **无需额外模块或坐标监督**：区别于 grounding-capable MLLMs，MMCS 不引入定位专用模块或坐标 token，直接从表征层面建立视觉-语言绑定，保持架构简洁。
- **通用性强**：跨 LLM 规模（3B、8B）、跨视觉编码器（SigLIP2、QwenViT）、跨预训练数据规模（0~1M）均保持一致增益。
- **客观的公平对比设计**：与基线和对比方法使用完全相同的图像-标注对，确保收益归因于方法本身；对抗扰动的鲁棒性分析也增强了结论可信度。
- **深层的机制洞察**：不只是报告端到端性能，还通过 CKA/k-NN 指标、注意力图、词性级 NLL 分析揭示了方法内部的工作机制；附录中提供了 4 种子统计显著性检验，强化了结论稳健性。
- **数据质量有保障**：同时使用 VLM 裁判和人工评估进行数据质量验证，两者一致性较高（94.9% vs 94.2%）。

### 8. 不足与局限

- **对象类别覆盖有限**：当前实现主要聚焦自然图像中的视觉对象，对图表理解、场景文本识别等领域的扩展尚未充分验证；对稀有、文化特定或代表性不足的对象可能存在覆盖不均，导致不同类别与场景下接地精度的不平。论文明确指出这些为未来工作。
- **复杂关系与动作建模不足**：虽然验证了动词与介词间接获得监督，但显式的对象级对齐本身不直接处理对象间的复杂关系、交互与动作，限制了语义建模上限。
- **依赖自动标注工具链**：数据合成依赖 Qwen3-VL 生成标注、Qwen2.5-72B 提取实体、Grounding DINO 定位、SAM-2.1 分割，任何环节的错误都会传播；虽做了 10%/30% 扰动鲁棒性测试，但真实标注噪声的分布与随机扰动并不完全等价。
- **资源消耗较高**：使用 72B/32B 级别模型进行数据合成，虽然训练阶段资源合理（8×A6000），但完整的数据生产管线在真实应用中的总体成本未被完整量化。
- **通用 VQA 增益有限**：与接地（+7.9%）和感知（+2.1%）相比，通用 VQA 提升较小，主要因为通用 VQA 依赖更多非视觉因素（世界知识、常识推理、指令遵循先验），这意味着 MMCS 对推理能力的贡献是间接的。
- **隐私与偏见风险**：合成数据可能继承源数据集（COCO、Flickr30K、GQA、Objects365、Open Images、SA-1B）中的人脸、车牌、位置信息等隐私要素；更强的目标定位能力若被滥用可能构成监控与追踪风险。
