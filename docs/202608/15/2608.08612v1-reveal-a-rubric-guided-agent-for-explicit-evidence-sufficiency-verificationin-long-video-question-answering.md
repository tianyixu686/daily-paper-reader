## 摘要
近期，检索增强和记忆增强方法已成为长视频问答的两种有前景的范式。然而，现有方法通常依赖刚性、固定长度的时间分块（如10秒）和静态离线记忆库，这不仅割裂了连续的事件，还无法在实时推理中适应。此外，无论是使用多尺度摘要还是多模态知识图谱，当前方法都优先考虑检索相关性，而忽略了证据充分性，常常在仅检索到语义相关线索时就停止回答，即使关键的时间、因果或细粒度动作证据仍然缺失。为应对这些挑战，我们提出了REVEAL，一个规则引导的智能体框架。作为基础，我们引入了一种基于视觉相似性的自适应预处理流水线，将视觉上连贯的相邻帧分组为自然事件单元，以构建离线-在线视频记忆——离线捕获全局视频上下文，同时在线动态维护问题条件下的记忆。在此结构化记忆之上，REVEAL使用自动构建的规则库来显式验证检索到的证据是否满足充分性标准，在验证失败时指出缺失的线索，并指导针对性的重新检索以获取补充信息。无需额外训练，REVEAL在大量实验中持续优于闭源和开源的最先进方法。这些结果表明，显式验证证据充分性，而非止步于语义相关性，能够检索到先前方法遗漏的决定性线索，并产生更可靠的长视频推理。

## Abstract
Recently, retrieval-augmented and memory-augmented methods have emerged as two promising paradigms for long-video question answering. However, existing methods typically rely on rigid, fixed-length temporal chunking (e.g., 10s) and static offline memory banks, which not only fragment coherent continuous events but also fail to adapt during real-time reasoning. Moreover, whether using multi-scale summaries or multimodal knowledge graphs, current approaches prioritize retrieval relevance while overlooking evidence sufficiency, often stopping to answer once only semantically relevant clues are retrieved, even when key temporal, causal, or fine-grained action evidence is still missing. To tackle these challenges, we propose REVEAL, a rubric-guided agent framework. As a foundation, we introduce an adaptive visual-similarity-based preprocessing pipeline that groups visually coherent adjacent frames into natural event units to construct an offline-online video memory---capturing global video context offline while dynamically maintaining question-conditioned memory online. Built upon this structured memory, REVEAL uses an automatically constructed rubric library to explicitly verify whether retrieved evidence satisfies sufficiency criteria, pinpoints missing clues upon verification failure, and directs targeted re-retrieval for complementary information. Without any extra training, REVEAL consistently outperforms both closed-source and open-source state-of-the-art methods across extensive experiments. These results show that explicitly verifying evidence sufficiency, rather than stopping at semantic relevance, retrieves the decisive clues that prior methods miss and yields more reliable long-video reasoning.

## 2. 论文提出的方法论

### 2.1 核心思想
REVEAL 是一个**无需训练**的智能体框架，由一个统一的自回归多模态大模型（Qwen3.5-27B）担任三个角色：planner（规划器）、verifier（验证器）、answerer（回答器），通过不同提示词区分角色，并通过“检索-验证-回答”循环控制推理。

### 2.2 离线-在线记忆框架
- **离线记忆（Offline Memory）**：一次性构建，供同一视频的所有问题共享。
  - 使用 **视觉相似性自适应分段**：相邻1fps帧按SigLIP视觉嵌入余弦相似度>0.8进行贪心分组，得到可变长的L1自然事件段（而非固定时长窗口）。
  - 每个L1段表示为 \( m_i^{(1)} = (t_{s_i}, t_{e_i}, x_i^{(1)}, h_i^{(1)}, v_i) \)，包含时间边界、多模态描述、文本嵌入和代表视觉嵌入。
  - 由底向上生成L2事件时间线、L3全局叙事，形成三级层次记忆 \( M = M_{L1} \cup M_{L2} \cup M_{L3} \)。
  - 文本通道使用 BGE-M3 编码，视觉通道保留L1关键帧的SigLIP嵌入。
- **在线记忆（Online Memory）**：每个问题实例化，随检索过程演化。
  - 状态定义为 \( O_t = (E_t, V_t, H_t, N_t, A_t) \)：
    - \( E_t \)：去重后的证据缓存；
    - \( V_t \)：已访问的记忆ID；
    - \( H_t \)：历史查询记录；
    - \( N_t \)：每次尝试是否贡献新证据；
    - \( A_t \)：验证器最新给出的“缺失证据分析”。
  - 提供给planner的紧凑反馈为 \( (H_t, N_t, A_t) \)，避免过长的评分细节干扰检索。

### 2.3 Rubric自动构建流水线
- 目标：从“决定性证据”和“误导性证据”的对比对中学习充分性准则，而非手工撰写。
- 对训练集中的问题 \( q \) 和标准答案 \( y \)，教师模型标注：
  - 充分证据集 \( E^+ \)；
  - 语义相关但非决定性的证据集 \( E^- \)。
- 保留候选对需满足：
  \[
  A(q, E^-) \neq y,\quad A(q, \emptyset) \neq y,\quad A(q, E^+) = y
  \]
  即：无证据时不能答对，误导证据不能答对，充分证据必须答对。
- 由LLM提练为带权重、带0/0.5/1分值边界的可复用准则，并在留出集上通过验证错误反馈迭代修正，最终合并为**统一rubric库**，推理时按问题动态选取相关子集。

### 2.4 Rubric引导的“检索-验证-回答”循环
- **Planner**：
  - 初始轮将问题拆分为2–4个自包含子查询；
  - 修复轮根据在线记忆和缺失分析生成，动作包括：
    - **定向文本检索**（针对缺失线索生成查询，覆盖L1/L2/L3）；
    - **探索式均匀采样**（在未访问的L1片段中采样，用于全局问题和定向检索失败时）。
  - 生成的查询若与历史重复度过高（Jaccard≥0.9）或与已有证据嵌入相似度过高（BGE余弦≥0.70）则被拒绝。
- **Verifier**：
  - 从统一rubric池中选出与当前问题相关的准则；
  - 对每个准则 \( k \) 给出满足度 \( z_{t,k} \in \{0, 0.5, 1\} \)；
  - 计算加权置信度：
    \[
    \rho_t = \frac{\sum_k w_k z_{t,k}}{\sum_k w_k}
    \]
  - 若 \( \rho_t \ge \tau \)（默认 \( \tau = 0.7 \)）则停止，否则输出具体的缺失证据分析 \( A_t \)。
  - 注意：验证的是“证据充分性”而非“回答正确性”。
- **Answerer**：仅基于累积的证据集、问题与选项生成最终答案，与检索控制隔离。
- 总检索轮数上限 \( K = 3 \)，若预算耗尽仍未充分，则给出最优猜测并保留缺失分析。

## 6. 论文的主要结论与发现

- 显式验证证据充分性（而非停留在语义相关性）能够检索到之前方法遗漏的决定性线索，显著提升长视频推理可靠性。
- 在5个基准上，REVEAL-27B全部达到最优：
  - EgoLifeQA 64.4，Ego-R1 66.7，LVBench 65.9，Video-MME-L 79.1，LongVideoBench 75.7；
  - 相比同backbone直接推理平均提升13.2个百分点（57.2→70.4）；
  - 在第一视角基准上显著领先强基线（最高领先14.7点）。
- 消融显示**rubric-guided verification贡献最大**（+7.8/+10.9），远超记忆组织和迭代检索。
- 证据量实验表明：验证机制用约1/4的证据（平均31段 vs 128段）达到更高准确率；继续增加相关片段反而引入干扰导致准确率下降。
- 验证器校准分析显示：判定为“充分”的问题准确率显著高于“不充分”的问题，验证结果确实对应真实证据充分性。
- 增益集中于时间推理、计数、动作识别等证据敏感类别，而全局梗概类题目变化不大。

## 7. 优点

- **方法创新性强**：首次将rubric从“评估输出”和“训练奖励”扩展到推理循环中，作为智能体检索停止与修复的可解释准则。
- **无需训练**：直接复用单个开源VLM，无监督微调/强化学习，易于复现和部署。
- **模块化设计清晰**：离线-在线记忆分离，将“视频本身的信息”与“问题相关的推理状态”解耦；verifier和planner各司其职，决策可溯源。
- **证据充分性导向**：不是单纯增加检索量，而是通过明确诊断缺失证据来定向补检，避免冗余搜索和上下文被无关片段污染。
- **自动rubric构建**：从对比性证据对中自动归纳准则，避免了人工撰写的高成本，且统一rubric池可跨数据集、跨视角迁移。
- **同时兼顾效率与性能**：在提升准确率的同时，通过早期停止和去重控制检索轮数和LLM调用次数，端到端运行时间低于部分记忆型基线。

## 9. 未来工作与潜在改进方向

- **在线→离线记忆的反向闭环**：作者明确指出当前在线记忆的验证信号不会反馈到离线记忆结构。未来可考虑将“反复检索不到的证据类型”作为新线索写回L1/L2记忆的索引，或动态调整分段边界，形成“检索-验证-记忆更新”的完整闭环。
- **更细粒度的验证粒度**：当前rubric验证在片段级进行，对“某个时间点上的具体动作”或“物体在画面中的精确位置”等细粒度证据缺乏空间/时间grounding。未来可引入带时空定位的验证信号（如bounding box或时间戳回归）来提升证据充分性判断的精度。
- **动态阈值与自适应预算**：τ=0.7和K=3为全局固定值，不同数据集的最优τ可能不同。可探索根据在线验证置信度变化率自动调整停止阈值，或在低置信度时自动延长检索轮数。
- **跨视频与跨会话长视频**：当前记忆构建针对单个视频，而Ego-R1中的周尺度问题已接近“跨会话”场景（生活日志）。未来可将记忆层次扩展为跨视频的叙事图（event graph），支持跨片段甚至跨天的证据链拼接。
- **与训练方法结合**：REVEAL的rubric库本身可作为**可解释奖励信号**，用于微调检索模型或训练专门的验证器，从而突破单一backbone的能力上限。
