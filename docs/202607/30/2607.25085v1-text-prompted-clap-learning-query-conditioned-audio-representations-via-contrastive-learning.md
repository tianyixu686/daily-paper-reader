## 摘要
对比语言-音频预训练（CLAP）在共享嵌入空间中学习对齐的文本和音频表示。然而，每种模态的独立编码限制了其在复杂音频理解和检索任务中建模跨模态语义的能力。为了解决这一限制，本文提出了文本提示的CLAP（TP-CLAP），这是CLAP的一种参数高效扩展，引入了一个基于交叉注意力的融合模块，将文本提示融入音频特征中。TP-CLAP使用音频多项选择题（audio-MCQ）框架进行训练，在该框架中，它通过对比学习将查询条件下的音频表示与正确答案选项的文本嵌入对齐。实验表明，TP-CLAP在音频问答（audio-QA）任务上取得了与显著更大的音频-语言模型相竞争的性能，同时在音频-文本检索和零样本分类基准上改进了基础CLAP模型。学习到的表示进一步微调用于属性聚焦的音频到音频检索，表明TP-CLAP在音乐检索任务中始终优于标准CLAP基线。

## Abstract
Contrastive Language-Audio Pretraining (CLAP) learns aligned text and audio representations in a shared embedding space. However, independent encoding of each modality limits its ability to model cross-modal semantics in complex audio understanding and retrieval tasks. To address this limitation, this paper proposes Text-Prompted CLAP (TP-CLAP), a parameter-efficient extension of CLAP that introduces a cross-attention-based fusion module to incorporate textual prompts into audio features. TP-CLAP is trained using an audio multiple-choice question (audio-MCQ) framework, where it learns to align query-conditioned audio representations with text embeddings of correct answer choices via contrastive learning. Experiments demonstrate that TP-CLAP achieves competitive performance on audio question answering (audio-QA) with substantially larger audio-LLMs, while also improving the base CLAP model on audio-text retrieval and zero-shot classification benchmarks. The learned representations are further fine-tuned for attribute-focused audio-to-audio retrieval, showing that TP-CLAP consistently outperforms the standard CLAP baseline in music retrieval tasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：标准对比语言-音频预训练（CLAP）模型通过独立编码音频和文本模态，在共享嵌入空间对齐它们。但这种独立编码方式限制了模型在复杂音频理解和检索任务中建模跨模态语义的能力。特别是在音频问答（audio-QA）和属性聚焦的音频到音频检索等查询依赖型任务中，CLAP无法根据文本查询动态调整音频表示，导致性能受限。

- **背景**：现有方法如多模态大模型（audio-LLMs）虽然能解决上述问题，但训练和推理计算成本高昂。因此，本文探索能否在保持CLAP高效性的同时，学习查询条件下的音频表示。受对比语言-图像预训练（CLIP）和CLAP的启发，作者提出一种参数高效扩展方案。

## 2. 方法论

### 核心思想

- 在预训练CLAP的音频编码器基础上，插入一个**基于交叉注意力的融合模块**，使音频表示能够以文本查询（textual prompt）为条件进行动态调整。通过**音频多项选择问题（audio-MCQ）** 框架进行对比学习训练，使融合后的音频嵌入与正确选项的文本嵌入对齐。

### 关键技术细节

- **标准CLAP**：音频编码器 \(E_a\) 和文本编码器 \(E_t\) 将输入映射到公共嵌入空间，使用对称InfoNCE损失训练。

- **交叉注意力融合模块**（见图1论文）：
  - 将预训练CLAP音频编码器的token级隐藏表示 \(H_a\) 和文本查询token表示 \(H_q\) 作为输入。
  - 每个融合块包含：自注意力层、交叉注意力层（以 \(H_a'\) 为查询，\(H_q\) 为键和值）、前馈网络（FFN），均带残差连接。
  - 输出融合后的token表示，经池化得到固定维度的查询条件音频嵌入 \(e_f\)。

- **训练目标（audio-MCQ监督框架）**：
  - 给定音频 \(x_a\)、问题 \(q\) 和 \(M\) 个候选答案，定义融合嵌入 \(e_f = F(H_a, H_q)\) 和答案文本嵌入 \(e_m = E_t(c_m)\)。
  - **InfoNCE损失** \(L_{InfoNCE}^f\)：对齐 \(e_f\) 与正确答案嵌入 \(e^+\)，对比当前和批次内所有候选答案。
  - **交叉熵损失** \(L_{CE}^f\)：增强同一问题内候选答案的区分性。
  - 融合嵌入的总损失：\(L_{audio-MCQ}^f = L_{InfoNCE}^f + \lambda L_{CE}^f\)（\(\lambda=0.5\)）。
  - 为保持通用音频-文本对齐能力，加入两个正则化项：
    - 标准CLAP对比损失 \(L_{CLAP}\)（基于音频-字幕对）。
    - 对未融合音频嵌入 \(e_a\) 施加相同的audio-MCQ损失 \(L_{audio-MCQ}^u\)，其中文本嵌入来自问题-答案拼接 \( \tilde{e}_m = E_t([q; c_m])\)。
  - 最终目标：\(L = L_{audio-MCQ}^f + \alpha L_{CLAP} + \beta L_{audio-MCQ}^u\)（\(\alpha=\beta=1\)）。

- **属性聚焦的音频到音频检索微调**：
  - 使用带多属性标注的音频分类数据，为每个属性预定义问题（如“这是什么乐器的音乐？”）。
  - 采用分类损失 \(L_{cls}\) 和音频到音频对比损失 \(L_{a2a}\)。对比损失在查询条件嵌入 \(e_f\) 与未融合音频嵌入 \(e_a\) 之间计算，使得数据库只需存储单一嵌入。
  - 针对单标签/多标签属性分别定义相似度目标（标签匹配或IoU）。
  - 微调目标：\(L = L_{cls} + \gamma L_{a2a}\)（\(\gamma=1\)）。

## 3. 实验设计

### 数据集和基准

- **audio-MCQ训练**：AudioMCQ数据集（声音和音乐子集，310k问题-选项对）。
- **评估任务和数据集**：
  - **音频-文本检索**：AudioCaps测试集、Clotho测试集（Recall@1）。
  - **零样本音频分类**：8个基准（ESC50、FSD50K、UrbanSound8K、VocalSound、CREMA-D、GTZAN、Beijing Opera、NSynth instrument）。报告mAP（FSD50K）或准确率。
  - **音频问答**：MMAU（声音和音乐子集）和MMAR（声音和音乐子集）。报告准确率。
  - **属性聚焦音频到音频检索**：NSynth（乐器家族、音高、音源属性，870k对）和MagnaTagATune（流派、乐器、节奏属性，24k对）。报告Precision@K和mAP（NSynth），或SoftPrecision@K和SmAP（MagnaTagATune）。

## 6. 主要结论与发现

- TP-CLAP在音频问答任务上以219M参数取得与8B级音频-LLM相竞争的性能（MMAU声音子集71.47% vs. Audio Flamingo 3的79.58%），且优于其他更小的音频-LLM。
- 在音频-文本检索中，TP-CLAP在AudioCaps和Clotho上相比基础CLAP有持续提升（R@1最高达57.2%和27.1%）。
- 零样本分类平均准确率63.0% → 63.4%（加AudioMCQ数据） → 64.1%（加融合模块），在多个数据集上取得最佳。
- 属性聚焦检索中，带提示的检索在所有属性上优于无提示的CLAP，且随着检索深度增加，性能下降更平缓，表明查询条件表示能聚焦于目标属性。

## 7. 优点

- **方法亮点**：
  - 提出参数高效的交叉注意力融合模块，仅增加约20M参数，即可实现查询条件表示，无需大型语言模型。
  - 利用audio-MCQ框架作为自然监督来源，与CLAP目标兼容，保持通用对齐能力。
  - 引入额外的未融合嵌入正则化，防止遗忘原始CLAP知识。
