## 摘要
大型语言模型（LLMs）通过利用用户历史和上下文线索，在生成个性化内容方面展现了卓越的能力。然而，现有的大多数个性化方法依赖于模型参数中的隐式表示，这使得难以解释用户特定的偏好或有效处理长上下文依赖。为了解决这些挑战，我们提出了PrefReward，一种新颖的偏好感知生成框架，通过结构化的偏好矩阵显式建模用户风格，并将其作为奖励信号整合到解码过程中。PrefReward包含两个阶段：（1）提取用户特定的偏好矩阵，总结个体风格倾向；（2）通过基于KL散度的奖励函数使用该矩阵指导生成。在LongLaMP数据集上的实验表明，PrefReward在生成质量和个性化可解释性方面均优于非个性化和基于检索的基线方法。

## Abstract
Large Language Models (LLMs) have demonstrated remarkable ability in generating personalized content by leveraging user histories and contextual cues. However, most existing personalization approaches rely on implicit representations within model parameters, making it difficult to interpret user-specific preferences or effectively handle long-context dependencies. To address these challenges, we propose PrefReward, a novel preference-aware generative framework that explicitly models user styles through a structured preference matrix and integrates it into the decoding process as a reward signal. PrefReward consists of two stages: (1) extracting a user-specific preference matrix that summarizes individual stylistic tendencies, and (2) using the matrix to guide generation via a KL-divergence-based reward function. Experiments on the LongLaMP dataset show that PrefReward outperforms non-personalized and retrieval-based baselines in both generation quality and personalization interpretability.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 将用户偏好显式建模为一个**偏好矩阵**（Preference Matrix），每个维度对应一个预定义的风格标签（如正式、简洁、生动、幽默等），并利用该矩阵在解码阶段通过**KL散度奖励**选择最符合用户风格的候选输出。
- 整个框架无需微调LLM，完全在解码过程中实现个性化。

### 关键技术细节
1. **偏好矩阵提取（Preference Matrix Extraction）**：
   - **标签选择**：定义一组可解释的风格标签集合P（论文中使用41个维度，如formal, concise, vivid, humor等）。
   - **用户画像选择**：使用BM25检索器从用户历史中选出最相关的K个样本（K=2），减少噪声。
   - **Token级偏好提取**：对每个选中的样本，在LLM前向传播时获取每个token在风格标签集上的logits（仅保留P中标签对应的维度），得到偏好向量v_i；对所有token的偏好向量取平均，得到该样本的序列级偏好向量p_y；对K个样本的p_y进行堆叠，得到用户偏好矩阵P_u ∈ R^{K×N}。
2. **偏好引导生成（Preference-Guided Generation）**：
   - **KL散度奖励**：计算用户偏好矩阵的均值向量\bar{P}_u（即K个样本的平均偏好分布）。对每个输入x，生成N_c个候选输出（论文中N_c=10），对每个候选提取其偏好向量p_y^{(i)}，然后计算候选与用户均值分布的KL散度的负值作为奖励：R_i = -KL(p_y^{(i)} || \bar{P}_u)。
   - **Best-of-N解码**：选择奖励最高的候选作为最终输出y* = argmax_i R_i。

### 算法流程（文字说明）
1. 对于用户u，从历史中挑选K个代表性样本。
2. 对每个样本，通过LLM前向传播获得token级logits，提取风格标签上的概率，得到样本级偏好向量，组成矩阵P_u。
3. 计算用户平均偏好向量\bar{P}_u。
4. 对于输入x，LLM生成N_c个候选文本。
5. 对每个候选，用相同方法提取其偏好向量。
6. 计算每个候选的KL散度奖励（负值），选出奖励最高的作为最终输出。
