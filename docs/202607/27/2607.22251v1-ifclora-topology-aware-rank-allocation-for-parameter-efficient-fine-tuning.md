## 摘要
低秩适应（LoRA）是一种广泛用于大语言模型的参数高效微调方法，但其性能强烈依赖于固定秩预算在 Transformer 模块间的分配方式。现有自适应秩方法通常依赖训练过程中收集的局部梯度统计信息，这引入了额外的内存和计算开销，并且忽略了任务条件下的全局信息流。我们提出 IFCLoRA，一种在微调前应用的拓扑感知秩分配方法。利用小型校准集和冻结的预训练模型，IFCLoRA 构建了一个稀疏的任务条件交互图，其节点代表与 LoRA 兼容的模块。它结合全局信息流拓扑先验与局部梯度敏感度，计算信息流中心性分数，从而估计每个模块在多跳传播下的自适应重要性。随后在全局预算下一次性分配秩。在多个模型、任务和低秩设置中，IFCLoRA 在匹配的训练配置和总秩预算下持续优于 LoRA、AdaLoRA 和 EVA，同时保持与标准 LoRA 相当的训练成本。在 LLaMA 3 8B 的数学推理任务中，秩为 4 时 IFCLoRA 相比 LoRA 提升 1.36%，秩为 8 时提升 1.82%。进一步分析显示任务依赖的非均匀秩分布，表明全局信息流结构为低预算参数高效微调提供了信息丰富且可解释的先验。

## Abstract
Low-Rank Adaptation (LoRA) is a widely used parameter-efficient fine-tuning method for large language models, but its performance depends strongly on how a fixed rank budget is distributed across Transformer modules. Existing adaptive-rank methods usually rely on local gradient statistics collected during training, which introduces extra memory and computation and overlooks task-conditioned global information flow. We propose IFCLoRA, a topology-aware rank allocation method applied before fine-tuning. Using a small calibration set and a frozen pretrained model, IFCLoRA builds a sparse task-conditioned interaction graph whose nodes represent LoRA-compatible modules. It combines a global information-flow topology prior with local gradient sensitivity to compute Information-Flow Centrality scores, which estimate each module's adaptation importance under multi-hop propagation. Ranks are then assigned once under a global budget. Across multiple models, tasks, and low-rank settings, IFCLoRA consistently outperforms LoRA, AdaLoRA, and EVA under matched training configurations and total rank budgets, while retaining training costs comparable to standard LoRA. On mathematical reasoning with LLaMA 3 8B, IFCLoRA improves over LoRA by 1.36 percent at rank 4 and 1.82 percent at rank 8. Further analysis shows task-dependent, non-uniform rank profiles, indicating that global information-flow structure provides an informative and interpretable prior for low-budget parameter-efficient fine-tuning.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：参数高效微调（PEFT）中，LoRA 通过低秩分解更新权重，但标准 LoRA 对所有模块分配相同秩，忽略了 Transformer 不同层和模块的功能异质性。在低预算设置下，有限的适应能力应集中到关键推理路径上。
- **现有方法的不足**：自适应秩方法（如 AdaLoRA、EVA）通常在训练过程中动态调整秩，依赖局部统计量（梯度、激活方差等），引入额外内存和计算开销，且仅关注局部信息，忽略了任务条件下全局多跳信息流结构的影响。
- **核心问题**：能否在微调前利用全局信息流拓扑与局部梯度敏感度相结合，一次性完成秩分配，从而在相同秩预算下更有效地利用有限适应能力？

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将 LoRA 可插入模块视为节点，通过轻量因果追踪构建任务条件稀疏交互图，提取信息流中心性（IFC）分数，融合全局拓扑先验与局部梯度敏感度，在全局预算约束下一次性完成离散秩分配。
- **关键技术步骤**（共四阶段）：
  - **阶段 1：任务条件交互图构建**  
    对校准集每个样本，在冻结模型上进行干净前向传播，记录目标节点激活；对源节点施加零消融（将其输出置零）后重新前向，计算目标节点激活变化范数作为边权重。保留满足深度顺序和窗口大小（默认 15）的候选边，得到稀疏有向图，其节点对应 LoRA 可插入模块（注意力投影和 MLP 投影）。
  - **阶段 2：拓扑先验提取**  
    定义输入侧锚点（最浅目标节点）和输出侧锚点（最深目标节点），计算前向可达性（从输入侧沿边传播）和后向可达性（从输出侧反向传播），两者元素级乘积后再进行最小-最大归一化，得到拓扑先验分数 \( f_i \)。公式：  
    \( a = \sum_{k=0}^{K_f} \alpha^k (T^\top)^k p_{\text{src}} \)，  
    \( b = \sum_{k=0}^{K_b} \beta^k T^k p_{\text{tgt}} \)，  
    \( f_i = \text{Norm}(a_i \cdot b_i) \)。
  - **阶段 3：局部敏感度校准**  
    对每个节点输出激活 \( h_i(x) \)，计算局部梯度敏感度 \( g_i = \mathbb{E}_{x \sim D_{\text{cal}}} [ \| \nabla_{h_i(x)} \mathcal{L}(x) \odot h_i(x) \|_1 ] \)，并在同一模块类型内部归一化得到 \( \bar{g}_i \)。然后与拓扑先验通过乘幂融合：  
    \( I_i = (f_i + \epsilon)^{1-\rho} (\bar{g}_i + \epsilon)^\rho \)，其中 \(\rho \in [0,1]\) 控制平衡。
  - **阶段 4：预算约束秩分配**  
    对模块级分数 \( S_u = I_u \) 进行 z-score 标准化得到 \( \tilde{S}_u \)，再用温度控制的 softmax 计算连续配额：  
    \( \omega_u = \frac{\exp(\tilde{S}_u / \tau)}{\sum_v \exp(\tilde{S}_v / \tau)} \)，\( \tilde{r}_u = R_{\text{tot}} \cdot \omega_u \)。  
    裁剪至 \([r_{\min}, r_{\max}]\) 后取整，贪心补偿或回收以满足总预算约束。所有秩在训练前固定，后续训练与标准 LoRA 相同。

## 6. 主要结论与发现

- IFCLoRA 在 GSM8K 上全面超越 LoRA、AdaLoRA、EVA，平均提升 1.13 百分点，最高提升 1.82 百分点（LLaMA3-8B, r=8）。

- 学习到的秩分配呈现强烈的非均匀性：中后层 FFN 模块和部分注意力投影获得更高秩，浅层模块被压缩，且分布随任务和模型变化，印证了任务条件信息流拓扑的有效性。
- 全局拓扑与局部梯度敏感度互补：单独去掉梯度或去掉拓扑都导致性能下降，验证了融合策略的必要性。
- 训练成本与标准 LoRA 相当，但预处理增加一次轻量追踪开销。

## 7. 优点

- **训练前一次性分配**：避免训练时动态调整带来的内存与计算额外开销，训练阶段与标准 LoRA 完全兼容。
- **明确引入全局信息流结构**：首次将机械可解释性的因果追踪与图中心性分析结合到 PEFT 秩分配中，提供了可解释的拓扑先验。
- **低成本校准**：仅需 128 个校准样本即可构建有效交互图，且对校准规模不敏感。
- **公平比较**：严格控制总秩预算、可训练参数数、训练协议，确保改进来自分配策略而非额外容量。
- **多模型多任务验证**：涵盖不同规模（8B/14B）和架构（LLaMA/Qwen），统一结论稳健。

## 8. 不足与局限

- **启发式分数缺乏最优性保证**：IFC 分数是经验性设计，目前没有理论证明其在给定预算下能最小化下游损失。
